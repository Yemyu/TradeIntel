状态：2026-09-24 已下载、逐月全量对账并发布 2025-08 至 2026-07 连续12个月；自然语言出口/进出口并列、页面12个月真实报告已贯通。**尚未**完成通用商品的模型解释或 MySQL 对照，不能称完整产品。首月实测见 [P4 首月验收](runs/20260923-P4-EXPORT-JULY-INTEGRATION.zh-CN.md)，扩容实测见[十二个月收口](runs/20260924-P4-EXPORT-12M-CLOSEOUT.zh-CN.md)。本文件后续方案记录了首月和扩容规则，保留作审计依据。

## 用户最终会看到什么

- 问“最近美国大豆出口有什么变化”：在出口月份足够且连续时，显示月度走势、最新月与前月、主要目的地、数据截止月及来源；不足 12 个月时只显示实际可查范围，不跨缺月画趋势。
- 问“最近美国大豆贸易有什么变化”：先让用户选进口、出口或两者。选“两者”时在同一报告中**分别**呈现进口与出口，标明不同统计口径；不把二者加总，也不直接相减称为贸易差额。
- 问“美国大豆出口到中国”：中国是**出口目的地**；问“美国从中国进口大豆”：中国是**进口来源地**。不把美国海关记录直接改称中国海关出口记录。
- 问没有出口覆盖的商品或月份：说明数据尚未接入或没有观察记录，不返回钨/光伏等其他商品案例。

## 已定统计口径

1. 普通读者问“美国出口”时，默认指标为 Census 商品贸易**总出口额**：国产出口（`df=1`）加再出口（`df=2`），使用当月金额 `all_val_mo`，展示名为“美国商品总出口额（FAS，美元）”。可在展开详情查看两部分，但不能再把总额与分项重复相加。[Census 定义](https://www.census.gov/foreign-trade/reference/definitions/index.html)说明总出口的组成及 FAS 估值。
2. 现有进口指标保持“美国消费进口额”，不改名也不回写旧表。Census 的消费进口与总出口在统计事件、估值及分类上不同；同页只能做方向分列和各自趋势，不默认计算差额、进出口比或政策影响。[Census 定义](https://www.census.gov/foreign-trade/reference/definitions/index.html)对两种统计口径分别作了说明。
3. 出口十位码用 **Schedule B**，进口十位码用 **HTSUSA**。大豆用双方均有的 HS4 `1201` 作首个同类商品组；玉米用 `1005` 作第二个非旧案例。2025 和 2026 的 [Schedule B 第12章](https://www.census.gov/foreign-trade/schedules/b/2026/c12.pdf)及[第10章](https://www.census.gov/foreign-trade/schedules/b/2026/c10.pdf)须按年份登记。具体 8/10 位进口码不能自动当作出口码；用户给精细进口编码又要求出口或“两者”时，提示换用经核实的共同 HS4/HS6 范围并重新确认。Census 说明两套分类共享 HS 前六位，但后续位数可能不同：[分类说明](https://www.census.gov/foreign-trade/schedules/b/2026/introduction.pdf)。
4. “金额变化”只表示名义美元金额变化；数量与价格未独立验证前，不归因为其中任何一个，更不归因为某项政策。

## 来源与工程边界

- 首选 [Census 月度商品贸易出口包](https://www.census.gov/foreign-trade/data/dataproducts.html)，而非临时模型搜索或把进口源改名。2026-07 的 `EXDB2607.ZIP` 已验证可访问，压缩大小 **120,709,344 字节**（2026-09-23 的 Range 响应）；文件可能更新，最终以下载后摘要为准。Census 查询 API 现在要求 API key；月包可在不新增凭证的情况下提供可复现的完整商品源。[API 示例页](https://api.census.gov/data/timeseries/intltrade/exports/hs/examples.html)。
- 原始 ZIP 存 `data/raw/trade-export/`，不能改动下载目录中的其他原件；临时下载、校验、完整落盘后再登记。首轮只下载 **2026-07 一个月**，检查 ZIP 成员、CRC、实际文件长度、日期及 SHA-256；不预先批量下载。
- 以 `EXP_DETL.TXT` 的**月度**记录为事实来源：商品十位码、目的国码、地区码、国产/再出口标记和 `all_val_mo`；不要把年累计 `all_val_yr` 混入月度金额，不要把 air/vessel/containerized 列与总额再次相加。[官方固定宽度布局](https://www.census.gov/foreign-trade/reference/products/layouts/exdb.html)。
- 先按 `(月份, Schedule B 10位码, 目的国码, 地区码, df)` 检查原记录；若有同键重复，不擅自去重或加总，暂停查明布局。再按 `(月份, Schedule B 10位码, 目的国码)` 聚合国产、再出口、总出口三个金额及各自观察状态。`COUNTRY.TXT` 用来验证并显示目的国名，不能凭记忆硬编码“中国=某数字”；未识别代码应保留原码并阻止其被误标为某国。
- `EXP_COMM.TXT` 的同月、同十位码、同 `df` 商品汇总用于独立对账。明细按所有目的国/地区求和与该汇总不一致时，**不发布该月**，先核查汇总层、统计抑制、低值估算或解析错误；不能放宽容差刷绿，也不能用一个口径替换另一个而不说明。[官方布局](https://www.census.gov/foreign-trade/reference/products/layouts/exdb.html)。
- 加工文件应保留所有商品和目的国（不是只抽大豆），以便后来按准确 Schedule B 码查询其他商品。商品中文名库仍是独立的产品缺口：本包只承诺已核实的大豆、玉米名称及官方编码查询，不宣称支持任意中文商品名。
- 出口独立登记 `dataset_id=census-us-export-scheduleb10`、来源 URL/摘要、分类年份与来源、目的国字典版本、加工文件摘要、处理脚本版本、可查询月份。发布版本由实际内容摘要决定；月包重新发布产生**新版本**，不静默覆盖旧报告。文件快照是复现依据；MySQL 仅作同版本查询副本，不能因服务暂时未启动而冒称已经完成 SQL/文件对照。

## 实施次序与停止门

1. **最小数据验证**：检查剩余磁盘空间和官方来源链接；首轮只取 2026-07。压缩包若超过 200 MB、ZIP 声明解压总量超过 2 GiB、下载不完整或来源/布局不符，停止并重新估算，不自动扩大限额。对大豆 `1201` 和玉米 `1005` 分别核对 Schedule B 明细、国产/再出口及 `EXP_COMM` 汇总；验证中国目的国码来自同包字典。完整原包保留。
2. **独立出口适配器**：固定宽度流式解析，独立 CSV/清单、受限查询；`flow=export` 只读核验后的出口版本。非法码、缺月、未观察、记录值为 0、来源摘要不符应分别处理。独立 MySQL 出口表不覆盖进口或历史政策表；同版本 SQL/文件对照需在 MySQL 可连接后单列验收。
3. **网页接线**：保留进口及旧政策案例路径；出口问题进入出口范围确认，`both` 只有两方向在同一连续窗口均可查询时才生成并列报告。若首轮仅有一个出口月份，不能假装已有“最近一年趋势”；页面展示真实覆盖并提示等待扩容。
4. **逐月扩容**：最小样本通过后，按用户当前默认的最近 12 个月目标处理 2025-08 至 2026-07；逐月校验、失败可恢复，先完成的月份不重复下载。新月份发布时不改动先前报告绑定的版本。更早年份和全部中文商品名另列后续任务。

本包不调用大模型，也不变更旧模型评测题包或结果。
