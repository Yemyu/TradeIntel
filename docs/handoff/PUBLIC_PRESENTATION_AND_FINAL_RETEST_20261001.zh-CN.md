### 英文 README.md 与中文 README.zh-CN.md

两份采用同一结构和事实；中文自然讲解，不逐字翻译英文。

1. **Introduction / 项目介绍**：美国商品贸易研究助手，能自然提问、取数、阅读登记政策、看图表和追问。说明适合了解商品贸易变化；不写成实时资讯或投资服务。
2. **Examples / 案例**：四个案例分别展示用户问题、查询过程和报告内容。只有实际核实的公网地址才叫在线演示；未发布就链接仓库案例，不造网址或截图。可以使用真实界面截图，不能用设计图冒充运行结果。
3. **Features / 功能**：商品名/编码、进出口、多月比较、上下文追问、政策检索、报告和打印、无模型模式。具体解释，不堆名词。
4. **How it works / 工作过程**：模型选工具→程序取数和计算→核验→网页报告；解释为什么不是让模型凭记忆给金额。主摘要来自程序，不声称模型自由写出了深度经济报告。
5. **Run locally / 本地使用**：环境、独立数据包、启动、模型设置、首次提问，链接详细安装说明。普通克隆缺数据包、目前没有公开下载地址须清楚说明，不假装三条命令即可完整运行。
6. **Model tests / 模型测试**：当前表或简短摘要和评测入口；不在首页重复全部失败历史。
7. **Data coverage / 数据范围**：美国报告方；进口48个月（2016-01—2018-05、2025-01—2026-07）；出口2025-08—2026-07；伙伴为全部和中国；政策为本地登记并启用的文档。最新收录月不是实时月。
8. **Documentation / 文档与目录**：安装、当前功能、数据、评测；解释 src/scripts/web/tests/evals/docs/data 各放什么。开发交接和历史研究只留一个低优先级入口。

## 4. 前端文案

沿用组件和双语机制，不新增文案模块或前端框架。公开构建目前限定十四个资产；没有必要为文案扩大部署范围。

| 位置 | 需要解释 | 中文示例 |
|---|---|---|
| 首页 | 这是什么、能看什么 | 美国贸易研究助手；查询商品进出口，比较不同月份，查阅相关政策。先看案例，或在本地运行后自己提问。 |
| 本地聊天 | 怎样开始 | 用商品名称或编码提问，例如“最近美国大豆出口怎么样？”。使用助手前，先在模型设置中填入自己的 API Key。 |
| 案例 | 各展示哪个能力 | 大豆：从进口追问出口；豆油：区分原料与加工品；政策：一起阅读公告与数据；缺月份：说明为什么不能查询。 |
| 模型设置 | 字段、保存和费用 | 服务商是你取得密钥的平台；型号填写该平台支持的模型名。密钥由本地服务保存，不发布到展示网站。连接测试也可能收费。 |
| 数据报告 | 图表对象、日期、单位、变化含义 | “较上月变化”；保留“环比”时首次解释为与前一个月相比。来源和方法放折叠说明。 |
| 错误/澄清 | 原因和下一步 | 没有收录该月份；请选择已有月份，或等待补充数据。保留受控错误信息，不只露出内部状态码。 |

英文采用普通说明句，例如 “Ask about U.S. imports and exports” 和 “Browse example reports”，不用广告短句拼接。HS/HTS/FAS 首次出现有简短解释。中文不用“赋能、闭环、打通、全链路”等内部表达介绍功能。

详细不等于冗长：主要图表有读法和与实际数据有关的解释；解释金额与数量不同、来源份额意味着什么、还缺什么信息，不添价格/供给依赖/政策效果等无据结论。错误提示改文字不改状态或重试规则。
