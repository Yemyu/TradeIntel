# 通用贸易报告 v3：独立内容审阅交接

请在**新的、未参与本轮模型调用与初筛的任务**中使用本页。审阅者只读下面这个匿名包，不读同目录的 API 首轮结果、模型账本、匿名映射或此前对话评价：

`tmp/trade-model-eval-v3/review-packet-20260924/packet.json`

匿名包有四题，每题包含用户问题、程序报告、逐月复算参考和匿名原答。T1/T2 各有两份原答，T3/T4 各有一份；没有原答的模型不在包内。审阅者无需调用 API，也不要修改原答。

对每个匿名标签分别交付：

1. `factual_fidelity`：解释有没有说错商品、进出口方向、金额走势或原因；尤其区分**最新月环比**与**整个窗口首尾**。
2. `answers_the_question`：有没有回应用户实际问的内容；程序报告已经显示的数字不要求模型重复，但不能只说“有数据”而不提供任何解释。
3. `helpfulness_and_readability`：对普通人是否有具体帮助、语言是否自然，而非只重复表格或堆叠限制。
4. 每项给 `true`/`false`，附一两句能从包内材料核实的理由；注明评分是独立人工、AI 辅助还是其他方式。没有答案的题不打内容分。

评分完成后先锁定评语和时间，再由主任务读取本机私有映射 `.local/trade-model-eval-v3/review-packet-map.json` 汇总；映射不能提前给审阅者。结构合同和接口结果另由执行账本负责，审阅者不需猜模型，也不评价哪个服务商更强。
