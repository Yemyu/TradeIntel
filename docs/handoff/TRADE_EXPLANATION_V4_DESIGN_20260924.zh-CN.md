# 通用贸易报告 v4：让模型解释有具体增益

日期：2026-09-24。状态：**离线最小实施已完成；一次开发 API 调用技术通过，但未显示明确解释增益，按停止门不进入正式横评。** 实施记录见[v4 离线记录](runs/20260924-TRADE-V4-OFFLINE.md)，单次开发结果见[canary记录](runs/20260924-TRADE-V4-DEV-CANARY.zh-CN.md)。下文保留原始设计与预先设定的门槛。依据：[项目当前目标](../PROJECT_CONTEXT_REFERENCE.zh-CN.md)、[v3 首轮 API 记录](runs/20260924-TRADE-V3-API-FORMAL-FIRST.zh-CN.md)、[非盲内容初审](runs/20260924-TRADE-V3-NONBLIND-CONTENT-CHECK.zh-CN.md)和[现有数据能力盘点](TRADE_V3_AI_EVIDENCE_INVENTORY_20260924.zh-CN.md)。v3 的冻结题、原答、账本和停止结论保持原样；本文件不能当作 v4 已通过。

## 目标先说清

产品仍面向普通读者：问美国某类商品的进出口情况，确认官方商品范围，读真实月度金额、图表、来源和必要的解释；不提供投资建议，也不把政策时间与金额变化直接写成因果。**数字和可检验结论由程序负责；模型负责挑出值得讲的关系并写成自然、简短的说明。**用户不必知道数据版本或编码才会提问。

v3 的问题不是“格式跑不通”：Flash 四题都通过结构门，内容却主要复述程序已有事实和限制。现有模型输入只给摘要观察和一个泛化回答示例；系统要求每题都讲金额不能说明数量／政策，还禁止额外数字。更换更贵模型不保证能从缺失的关系中写出好解释。v4 优先修**给模型的任务与证据**，不是继续刷 v3 题或扩大模型清单。

## 路线选择

不选“把完整 12 个月原表直接交给模型自行计算”：它容易混淆最新月环比与整个区间，也会让精确金额和分类口径失去程序校验。不选“继续只换提示词”：没有新的可用关系时，漂亮措辞仍可能是套话。不选此阶段引入多智能体或整套 RAG：当前缺口是贸易报告的解释价值，额外框架不能替代数据与验收。选择**确定性关系卡 + 可选模型编辑**：程序先算并固定可说的关系，模型只能引用卡片，人工审阅其表达与事实。

## v4 的最小关系卡

从服务器已保存的同一份报告逐月行计算；每张卡包含稳定 ID、中文事实句、方向／商品／伙伴／指标／月份范围、来源报告摘要、计算器版本和可用状态。无法满足前提就产生 `unavailable` 理由，不补零、不猜测。

| 卡片 | 可发布的前提 | 可说什么／不能说什么 |
| --- | --- | --- |
| 最近月变化 | 相邻两月均为已观察、月份连续，商品和统计口径同版可比较 | “末月比上月增加／减少／持平”；不能由此推出“整个区间一直涨／跌” |
| 连续变化 | 最近至少两次相邻变动同方向，不能跨缺月或未观察值 | “连续若干个月逐月减少／增加”；不称政策效果或长期趋势 |
| 最近转向 | 最近三个月连续、已观察，前一次变动与最新一次反向；跨年度分类变化未核验时不出卡 | “上月下降、最新月回升”或反向；不称全期反转或预测未来 |
| 双方向同向／不同向 | 同商品的进口、出口各自最近月变动可比较且范围均已确认 | 可以说“本月两方向都下降”或“一升一降”；**不可相减**、不可称贸易差额，不能比较两方向金额大小的经济含义 |
| 区间最高／最低、期间合计 | 沿用现有程序的观察与完整性守卫 | 由图表和事实卡展示；模型可引用，不必再说“有合计值”或逐项复述数字 |

首月—末月差、同比、来源国结构、数量／单价和政策关联**不进入 v4 最小实现**。首尾比较尤其需先核查跨年度分类口径；同比虽有部分进口月份可对照，现有查询入口仍拒绝，不能偷偷让 AI 生成。出口国家明细、进口原包等未来可以另外验收接入，但不以此拖住最小 v4。若只有最近月变化、没有连续或转向等可解释的关系，数据报告本身就足够；**跳过模型调用**，页面说明“目前没有额外的关系可解释”，不把它记成模型失败。

## 输入、输出与用户看到的报告

新协议名 `trade-data-explanation-v4`，只作用于**新建**通用贸易报告。服务器在创建报告记录时固定关系卡快照，绑定原报告摘要与计算器版本；旧报告没有 v4 标记，继续用各自原协议显示，不重新解析或重算原答。领取一次模型调用时在锁内确认协议、报告和卡片摘要，保存请求摘要；原答先落盘，未知结果不自动重试，原有逐项审阅门不变。

模型请求给：用户原话、已确认范围、当前图表中相应的关系卡、卡片间允许的比较、禁止的推断，以及报告／卡片摘要。**不放可模仿的泛化解释样例**；只给 JSON 字段形状。输出保留现有页面可用的 `interpretations` 数组，每项有 `observation_ids` 和 `text`，但 ID 指向 v4 关系卡；允许引用程序已提供的跨方向关系卡，不允许自行拼接进口与出口金额。每项必须至少引用一张“连续、转向或双方向关系”卡；纯金额和最高／最低卡不能单独构成一条 AI 解释。正文不新造数字、日期、来源或因果判断；程序把对应卡片的精确金额和来源放在文字旁边。普通变化问题不强制每段附上“金额不等于数量、不能判断政策”的套话；问原因或政策时，报告另给一条明确、一次性的边界说明。

读者先看到程序的答案卡、图表、数值和来源，再看到**仅在有实质关系时生成**的一小段“值得注意的是……”。例如小麦的已知开发材料，程序可卡住“前月下降、最新月回升”，模型可以写“最近一个月回升了，但上个月还在下降；这不是连续上涨。”这只使用最近三个月的已核查关系，不让模型猜数字或擅自概括整段期间。上述句子只是目标写法，不是实测答案。

## 实现边界与验收

1. 独立新增 v4 关系卡计算器与协议解析器；v3 的 `messages()`、`parse()` 和冻结包保持不动。关系卡的数值、状态和引用由程序复算，不依赖模型。对缺月、未观察、零值、并列极值、单月、跨年分类与双方向分别测“能说／不能说”。
2. 报告存储新增版本标记和不可变关系卡快照，绑定来源报告摘要；旧记录缺标记时按旧协议读取。`public_state` 根据版本返回对应事实卡，页面继续显示旧 v1/v2/v3 记录；双击只领一次、刷新恢复、损坏或换版拒绝等现有安全边界不放松。
3. 模型输出仍走一次请求、原答保存、结构和引用校验、人工逐项审阅。审阅页同时展示原话、关系卡和来源；模型没有关系可讲时**不调用 API**，程序报告照常可读。模型的文字必须回答原问题中的非数字部分，不能把程序已给出的合计值硬写成“存在合计”。
4. 保持首页／工作台／报告同一产品，不为 v4 另造第二套网站。前端仅增加对应卡片及解释的阅读布局；不在这个阶段引入政策 RAG 或多智能体。打印、MySQL 同版和部署仍是独立发布门，不能因 v4 通过而视作完成。

## 试验协议：先小样本证实价值再扩展

**假设**：在同一报告和同一 DeepSeek Flash/high 配置下，v4 的关系卡与新任务能比 v3 的摘要解释更常给普通读者提供可核查、非重复的信息，且不增加事实错误。对照只改“证据卡＋解释合同”，不同时换模型或数据来源。

- 开发题：使用已经暴露问题的小麦 T2 和／或已见大豆样本，只作离线与**最多 1 次** v4 真实开发调用；两者均不进入 v4 正式成绩。先 fake 和页面验收；开发原答若仍无具体增益、出现不支持的全期走势、结构失败或结果未知，停止，不消耗正式题。**本门已使用：小麦开发题已完成一次，结果没有明确增益，因此停止条件已触发；除非另行设计并批准新实验，不得继续执行本设计中的正式请求预算。**
- 正式题：开发后再从已发布月份与未用于 v4 提示调试的商品选 **5 个**自然问法，事先固定用户话术、人工确认范围、数据版本、原报告、v3/v4 请求、参考卡、评分规则和代码摘要；其中 **4 个**应有可解释关系（含至少一个双方向和一个近期转向／连续变化），**1 个**预先判定应跳过 AI。已用于本轮问题定位的茶叶、小麦、乘用车、原油四题不充作 v4 的新盲题。参考答案和旧原答不送入模型。
- 比较：同一 Flash/high 对 4 个可调用新题的 v3、v4 各**最多 1 次**请求；第 5 题的 v4 应不发请求，产品链照样计分，模型输出栏记 `not_applicable` 而非失败。最多 1 次开发调用 + 8 次正式调用；每题分开留账本，不重试，不为成绩改题或改门槛。未知费用不估价，记录实际用量和耗时。
- 指标与门槛：产品链先核对商品、方向、月份及程序金额；模型分别记请求完整性、合同、事实忠实、是否切题、**相对程序报告的解释增益**。独立审阅者隐藏 v3/v4 与模型身份，比较同题的“仅程序报告／程序报告加解释”阅读效果。采用 v4 至少需：5 题产品链正确、无严重事实错误、4 个可调用题中至少 **3/4** 被独立审阅判有具体增益，且不比 v3 同题更差；跳过题必须确实不调用模型且报告仍回答用户。若冻结后数据条件使可调用数不足 4，则只按实际分母报告，**不通过本轮采纳门**，另版补题而不临时换题。五题仍是小样本，不称总体准确率。任何严重事实错误、合同失败、未知调用或预算超门，按冻结停止规则停该配置余题。
- 防泄漏：开发题可以用于修改 v4；正式题锁定后，不能再看其结果改提示或挑对自己有利的样本。v3 旧四题保留历史诊断地位，不被重评分“刷绿”。v4 若不过门，继续用程序报告并可选保留 v3，但不宣传 AI 解释已改善。

上述实施前步骤已完成；随后的小麦开发调用也已完成，并触发了预设停止条件。当前不继续执行本文件中的正式调用预算。若未来重开 AI 解释实验，须先提出与“复述图表旁已有关系卡”不同、可被读者验证的增益假设，另行设计材料、对照和停止门；不要原样重跑本设计的正式题。
