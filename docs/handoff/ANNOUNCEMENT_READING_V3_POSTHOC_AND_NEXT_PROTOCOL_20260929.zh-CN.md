## 一、把两个问题分开看

技术层：服务商返回 `stop`、型号和 usage 正常，JSON 与来源身份正确，但正文的三种格式未过冻结校验：`items` 用了对象而非数组；7 个 `claim_id` 用语义名称而非 `C1`；3 个 `addressed` 写了非空备注。冻结提示没有明确这三项硬要求。内存里只把三处格式转成解析器要求后，原答能过结构门；这**只说明协议不一致，绝不表示事实正确**。其他潜在但本次未触发的隐含要求包括双向 claim/check 链接、`incomplete` 的空主张、500 字符及 16 KB 限额。`json_object` 只保证 JSON 语法，不保证业务 schema。

## 二、为什么不只给 v3 提示补三句

连续两份未见公告的正式调用都因**提示没交代解析器硬限制**而格式失败；v2 另有重要内容遗漏/错误，本次 v3 又漏旧期限、立案日和申请日。只在 v3 提示补数组、`C1`、空备注可以减少一种格式失败，却保留多余的 claim ID 与双向链接，也不会自动补事实。把原答事后整理到合法格式，只能用于诊断，不能改变这两案结果。继续拿同案改提示重试会把“已见材料开发”伪装成“未见验证”。

## 三、下一版独立协议：少让模型做没有业务价值的编号工作

建议新建 `announcement-reading-suggestions-v4`，**不改 v2/v3 冻结源码或账本**。模型答复改为十个检查点的对象映射，由检查点 ID 作键，且只保留一次主张链接：

```json
{
  "schema_version": "announcement-reading-suggestions-v4",
  "doc_version": "<逐字复制请求值>",
  "source_sha256": "<逐字复制请求值>",
  "checks": {
    "policy_action": {
      "status": "addressed",
      "claims": [{"text": "合成示例：机构将甲项截止日由某日延至某日。", "anchors": ["P1"]}],
      "note": ""
    }
  }
}
```

示例仅示单键形状；**真实回答须恰有事前定义的全部十个键**，不能只交示例键。每条主张只含 `text/anchors`，不再让模型自造 `claim_id` 或重复维护 `claim_ids/check_ids` 双向关系；服务器按固定顺序生成内部展示 ID，并从同一份检查点定义派生三栏 UI 分组。这是面向**未来新版本**的设计，不用于修复旧原答。输出仍严格核顶层身份、恰好十键、状态集合、P 锚点存在及去重、原文哈希、重复 JSON 键、长度预算、未知额外字段与跨案污染。

状态与主张规则从**同一份声明**生成系统提示、校验器和测试样例：`addressed` 至少一条主张，允许非空补充说明但其内容也须人工核对；`partial` 至少一条已知主张且说明缺口；`conflict` 至少两条分别有据的相冲突主张且说明；`not_stated`/`not_applicable` 无主张并说明为什么；`incomplete` 说明未完成并使本次不可展示为完成。检查点的标题、归属、状态约束及上限在提示中完整可见。程序只能证明**形状和引用位置存在**，不能自动判法律含义或“全文没有”的负面断言。

事实覆盖增加**通用时间轴**要求而非抄本案答案：若公告改变期限/措施，分别标原状态与新状态、发起/申请/生效日期及各日期角色；明确当前行动与被提及的伴随调查、法定备选或将来决定是不同层次。该要求用于下一份材料，不能在本公告重跑报未见。超出 32 KB 完整输入、34 KB 完整 POST、16 KB 可见答复预算时记为不支持，不删原文凑门。

## 四、实施与停止门

1. **只做离线核心和现有页面适配**：独立 v4 模块、离线包、解析器，以及把合格的十检查点映射成现有三栏只读笔记的受控适配；不把 v4 伪装成 v3，不自动填写或启用政策。保留 v3 的旧界面与冻结案例可读。
2. 用完全合成公告及假服务做正反例：完整时间轴、不同国家/措施/日期、局部已知、无税率、全文缺项说明；遗漏十键、重复键、错版本/来源、错锚点、超长、截断、`incomplete`、未知字段都被拒或明确不就绪。真实请求与假服务须走**同一合同**；发送前仍先记账，并发/超时/HTTP 异常至多一次。
3. **先停在离线门**。本轮不自动选第三份公告、不请求新 API。若确实要做下一份未见试验，先固定官方筛选顺序、新来源和答前原子事实，重新核当日费用/模型及单案许可。技术门须完整合同通过；语义门是该案所有事前关键事实与子条件正确、额外主张零严重错误/无据引用。失败即诚实停止，不同案循环试到好看。一次通过也只能称一案验证，不称稳定准确。
4. 产品主线仍是**普通读者的美国商品贸易研究助手**：商品查询、真实数据/图表、可选模型解释和逐项审阅。公告阅读只是可选的实验性辅助，不应阻塞现有数据报告、前端和本地交付。没有真人对照用时/补查/改写记录，不宣传 AI 省时；不将贸易金额变化写成政策因果或投资建议。

本步结果：v3 的协议失配与 11 项事实缺口分开定位；正式失败不变，下一版最小协议和离线停止门已确定。
