# 公告阅读辅助：一次开发调用的放行方案

日期：2026-09-28。**结论：值得准备一次真实调用，但现在还不能直接发。** 这一调用只检验已见 R2 公告的三字段阅读笔记是否能读对七项关键事实，不检验省时、新公告准确率或 13 字段自动填写。本轮只是设计和只读核查，新增 API 请求为 0。

## 为什么只做这一件事

R2 v2 与旧的 13 字段抽取不是同一任务：输入是保存的整份原文、33 个连贯段落，输出只含税率性质、适用条件、例外三类逐条要点和原文位置；`parse_reading_answer` 会拒绝缺字段、无出处、版本不符及畸形 JSON。它**仍不能判断引文是否支持解释**，必须逐条人工看全文。

目前[七项人工参考](../../evals/policy_extraction_v1/r2_reading_reference_v2.zh-CN.md)和[无模型核对](runs/20260928-R2-READING-NO-MODEL-BASELINE.zh-CN.md)已具备，但真人从空白表单的补查/用时对照为 `not_measured`。所以一次开发回答有诊断价值：看是否能生成可读且不误解公告的笔记；即使七项全对，也不能声称“AI 让用户省时”。这份 R2 已参与开发，绝不拿来报陌生公告成绩。

选择高推理不是重跑旧失败：旧 **13 字段**实验用 `high + 4096`，4,096 输出 token 全用于思考，正文为空；现在任务缩为三字段，输出上限事前提高到 12,288。它仍可能返回空正文；若发生，记录为本配置的技术失败，不给语义能力打分，也不原样重试。[官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)说明高推理参数及 `temperature` 在思考模式下不生效；[官方 JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)也提醒空内容和截断仍可能发生。JSON 模式只帮助语法，不证明条款理解正确。

## 预算与停止门

[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)在本次核查时列出的 Flash 峰时缓存未命中输入价为 **$0.30/百万 token**，输出为 **$1.20/百万 token**。以 30,000 输入 token 和 12,288 输出 token **保守预留**，一次估算为 `30000×0.30/1000000 + 12288×1.20/1000000 = $0.0237456`，设本地计划门 **$0.03**。现有消息实际为 23,208 字节，旧 R2 一次不同合同的请求曾使用 4,705 输入 token；这些不等于新请求的确切 token 数。计划门**不是服务商账单硬封顶**；实际扣费、缓存命中及异步未知结果须以服务商记录为准。真正发请求当天要重新核官方价格并预检已累计用量；价格或请求参数变化时先停、另立版本，不悄悄调上限。

下面任何一项发生都停止本版，不在同一题上重试：

1. 原文、位置图、v2 消息、阅读模块、评分表或请求体的摘要不一致；本机配置不是预定服务商/型号，或价格与预算未复核。旧 `.local/experiments/policy-extraction-*` 账本与本试验完全隔离。
2. 请求一旦开始就先记账。HTTP 错误、超时或进程中断保守记失败/结果未知；**未知结果不得自动再扣一次费用**。响应只在完整原答保存、`finish_reason=stop`、`content` 非空、用量可核对、`parse_reading_answer` 合同通过后进入人工语义审阅。
3. 按七点参考逐项记 `covered/missing/wrong`，每条引文由人看完整上下文；任一严重 `wrong` 或引文不支持要点，立即判未通过。任何一项 `missing` 都不能报七点齐全。不得改参考、提示或旧成绩让同一份 R2 “通过”。
4. 若 **7/7 covered、零严重错误**，只报“已见 R2 开发案的三字段语义门通过”。人工补查和改写仍是 `not_measured`，不放行页面自动填表、公告启用、模型横评或公开的“省时/准确率”宣传。下一步应在不同政策家族的未见官方原文上，先锁独立人工参考，并另做人机同口径操作对照。

## 下一执行包：先离线做好，不发送请求

新建阅读 v2 专用的请求冻结件和一次性执行器（例如 `scripts/run_announcement_reading_dev_once.py`），**不要调用旧 13 字段执行器**。它可复用旧执行器的锁、先写账本、私有原答、未知不重试机制，但不得复用其旧 schema、`4096` 参数或旧账本；通用 `model_adapter.py` 会附带 `temperature`，也不适合未经修改地承担本次冻结请求。默认入口只能预检，真实路径须显式双开关及单独调用授权。
