# 通用贸易解释 v3：单次开发验证协议

日期：2026-09-24。当前状态：**只完成离线准备和替身测试，真实 API 调用 0 次；未获本次调用许可**。这是开发题，不计入正式四题横评。

## 为什么试这一题

假设：对同一份已发布的大豆出口数据报告，当前产品的 `trade-data-explanation-v3` 消息能让 DeepSeek `deepseek-flash` 返回完整、可解析、保留已计算下降方向且对普通读者有帮助的短解释。对照是**程序报告本身**：真实金额、图表和走势由程序给出，模型只增补文字，不能把模型回答当成数据来源或因果证明。

数据和代码锁在当前候选 `tmp/trade-v3-development-canary/20260924-d/MANIFEST.json`：美国大豆出口 Schedule B HS4 `1201`，全部目的地，2025-08 至 2026-07 连续12个月，出口数据版本 `4308e4a820cd86bb6a19e223b4ae887fe0a030eef4a8af0c1ce96cb8c30a4b9f`，目录版本 `a758a0236d12bea52cae670b99b05997a1b1c14d8442bcda7ea05bb3b436a632`。报告摘要和涉及的代码摘要以清单全长值为准；任何一项改变即拒绝继续。模型唯一可见材料是 `requests/messages.json`（3316字节）；`reference.json` 是从报告逐月金额重新计算的核对卡，不放进请求，也不包含其他模型原答。它不是对官方原包的二次独立下载核查。

## 一次调用的固定边界

- 只从本机受保护的产品配置读取凭证。预检必须确认为 DeepSeek `deepseek-flash`、`thinking=enabled`、`reasoning_effort=high`、温度0；向接口发出的 `max_tokens=2048`。返回的 `model` 字段、`finish_reason`、用量、耗时另记；别名不能证明底层模型快照。
- 最多**一次 v3 大豆开发调用**，不是每个重建题包一次。全项目固定账本在 `.local/trade-v3-canary/dev-soybean-export.json`；调用前先落盘领取记录。中断或结果未知也占用这一机会，绝不自动重试。旧 v1/v2 调用另记，不冒充这次。
- 单次调用及本地原答保存/解析由进程内计时器限制90秒；网络等待也不超过90秒。若计时器或请求异常，结果记为未知，后续先查服务商账单或记录，不自动发第二次。单次输入不超过60,000字节，原答不超过20,000字节；费用事前无法可靠估计，不能编造。输出上限是服务商参数约束，不承诺最终实际用量。
- 原答先以受限权限保存，后由**现行 v3 解析器**检查 JSON、报告摘要、观察引用、方向、字数和新增数字。`finish_reason` 非 `stop` 不计通过。解析通过只标 `needs_review`，不自动写“已采纳”。HTTP 4xx 等明确拒绝记失败，超时/网络异常记未知；两者都不重试。

## 采纳与停止

机械门：必须有完整原答、`finish_reason=stop`、v3解析通过并正确提到程序算出的“减少”；否则本开发验证失败或未知，停止，不运行正式四题。人工再看：解释是否具体回应“大豆出口变化”，是否只是换词复述数字或堆叠限制；不能编造价格、数量、政策原因或投资判断。用户未审阅前只能写“待审阅”。若只发现可复现的合同/接口错误，先离线修复并另版核验；本协议不授权用 T1—T4 调提示，也不授权再次调用这道大豆题。

开发验证若完成且证据充分，下一步才冻结四题及正式模型参数。四题仍是小样本，正式结果须按渠道、实际模型名和推理设置分列；不能拿开发题算分。
