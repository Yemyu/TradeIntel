# 现在该不该再跑四题模型测试

## 当前裁定（2026-09-28 更新）

原定自行车追问已经被程序新增的同年峰值事实直接回答，不再适合作为 AI 增益题。旧 T1—T4 绑定 v3，F1—F4 未接入现行产品；两套都不直接重跑。新的现行 v4 评测方案见[TRADE_MODEL_EVAL_V4_PLAN_20260928](TRADE_MODEL_EVAL_V4_PLAN_20260928.zh-CN.md)，先做四题离线冻结和一次开发价值门，再决定是否横评模型；本更新仍未调用模型。

日期：2026-09-28。结论依据是现有代码、冻结材料和已保存的运行记录；本轮不调用模型、不重判旧答案、不修改冻结件。

## 结论

**暂不启动新一轮多模型四题横评。**现在有几套名字相近的“四题”，但它们测试的功能不同，没有一套能够单独证明当前产品“会自动读新公告并生成可靠的 AI 报告”。新公告四种报告路线是人工核对字段及关联范围、程序查询或整理原文；最近两份公告验收均为零模型调用。普通商品的新报告则使用 `trade-data-explanation-v4`，只有读者另外点击试用入口，且报告有合格关系卡时，才会调用模型；模型文字还需逐项审阅。

已验证的本地数据/公告工具可以按其真实范围继续交付，不必为了给它贴“AI 项目”标签而凑一次模型排行榜。反过来，不能因工具链跑通就宣称 AI 解读已经稳定。若作品展示要把 AI 放在核心，下一步先证明它比现有数据报告多帮读者解决一个具体问题，再花钱比较模型。

## 正式测试何时放行

下一次只选**一个真实会在产品中出现的 AI 任务**。优先核对“读者看过商品报告后的具体追问”，因为它可能要求从多个已核验月份中挑出相关事实；这仍是候选，不预设 AI 比程序更有价值。新公告三字段阅读建议是另一项人工辅助实验，不能用商品追问题替它验收，更不能把政策四路的零调用回放算作模型成绩。

先做一份**不调用 API 的开发材料**。候选原话固定为：先问“最近美国自行车进口有什么变化？”，在页面显示的候选中确认进口 HS4 `8712`（另一个 `8512` 是车用照明/信号装置，不能默选）后，读者追问“七月比今年进口额最高的月份低多少？这是连续下降吗？”它未出现在上述 T/F 正式题与小麦开发答中。只读调用当前产品确认流程得到 `2025-08` 至 `2026-07` 的 12 个已观察月；2026 年内最高为五月 `81,378,250` 美元，七月为 `75,059,483` 美元，差额 `6,318,767` 美元；五月→六月→七月连续两次逐月下降。这些是本轮开发选题的程序核对值，仍需在独立材料中绑定数据/目录/代码版本并复算，**不是模型答案或准确率**。问题中的“今年”只在已经确认的报告里指 2026 年，不能拿电脑日期猜。

离线材料还要保存“只看现有报告”的对照和不送模的事实参考，并核对当前页面是否已经直接写出**同年峰值差额**。代码层面看到的是 12 个月整段最高/最低和最近连续变化，没有同年峰值差额；仍须按实际页面核对。若页面已直接写出，这个候选没有新增价值，停止并回报，不自动换题。现有追问事实目录也没有这条同年峰值差额，不能让模型自己算；若页面确实没有，应先由程序增加经核验的同年比较事实，再决定是否值得模型调用。计算、商品匹配和缺数据判断始终由程序负责，模型只选择证据并用自然语言回答。不得使用已冻结正式题的答案调提示。

放行一次受控**开发调用**前，必须写清假设、对照、模型精确 ID/渠道/推理参数、输入与输出上限、版本摘要、费用上限、不重试及停止条件。原答要保存并过现行解析/引用守卫；事实由参考卡核对，阅读增益由未见模型身份的审阅者比较“报告”与“报告＋回答”。事实严重错误为零，而且能指出回答比原报告具体节省了哪一步理解或查找，才算有初步增益。仅仅复述关系卡、格式合格或短连接成功都不算。开发题不报准确率。

只有开发题显示具体增益，才另版冻结**未用于开发的**正式场景、评分表和相同输入，再考虑每配置最多四题的一次性比较；每题记录接口、结构/引用、事实、切题、阅读增益和实际用量，严重错误或未知结果按事前规则停止。完整同版同渠道的四题才能并列；Codex 对话与产品 API 分栏。小样本只写“通过几题”，不写产品普遍准确率。评测应贴近用户任务并结合自动检查与人的判断，这也符合[OpenAI 的评测设计建议](https://developers.openai.com/api/docs/guides/evaluation-best-practices)；这里继续用本地可复核文件，不依赖即将退役的 OpenAI Evals 托管平台。

## 不把以下事项混成一个放行结论

- **本地交付**：代码、另附数据包、页面和人工公告报告的复现及边界说明；已有相应验收，模型增益不是其运行前提。
- **可选 AI 解读**：当前只能标试用/待审阅，不能无人审阅自动发布；旧 v3 成绩不证明 v4。
- **新公告自动阅读**：13 字段一次性抽取已暂停，三字段阅读建议只有离线原型；要恢复需独立人工基线、单独题包和调用许可。
- **公网在线产品**：还涉及托管、鉴权、密钥、持续数据更新及外发决定；四题模型分数不能替代这些工作。

下一个固定执行包：只做上述自行车追问的**离线开发材料与现有页面对照**，复核数据版本与数值，判定页面是否已直接给出答案，并指出当前协议缺少的事实字段；不在该包改产品、旧冻结件、发模型 API、写 MySQL、提交或推送。若页面已直接回答或事实不能安全构建，就停止该候选，不顺手找下一题刷正面结果。
