# 报告追问：下一轮 AI 价值验证方案

日期：2026-09-26。状态：**F1—F4题目、实际请求、真实报告、程序参考与评分表已封存；小麦开发答的内部价值审阅未过闸门；正式模型横评仍未放行；页面入口未开始**。封存包见 [`evals/trade_followup_v1/frozen/20260926-v1/`](../../evals/trade_followup_v1/frozen/20260926-v1/) 和[封存记录](runs/20260926-TRADE-FOLLOWUP-FREEZE.zh-CN.md)。最新判断见[价值闸门核对](runs/20260926-TRADE-FOLLOWUP-VALUE-GATE.zh-CN.md)；本段以下保留原设计和预设规则，不倒改题目或门槛。

## 为什么换一项任务

通用贸易报告的 v3 T1—T4 已冻结并跑过首轮 API，不能再拿来当新题。[现有回答复核](runs/20260925-TRADE-AI-VALUE-REVIEW.zh-CN.md)发现，v3 回答大多重述图表，v4 小麦开发回答也重述了页面已有的转向卡。继续用同一批题给更多模型打分，不能回答“模型到底帮读者多弄明白了什么”。旧题、原答和成绩保留，不重算。

下一项尝试是**对已生成的报告追问**。读者先确认商品、方向和月份，看到数据报告，再问一个具体问题。程序负责核对月份、计算差额和排序，模型负责从已核对事实中挑出与追问有关的内容，用普通话说明，并指出当前资料确实回答不了的部分。模型回答先作为试用草稿，保留来源和逐项审阅。第一版只追问同一份报告；换商品、换时间范围或索取新政策，回到范围确认，不暗中扩大查询。

这项任务的增益必须由读者检验：与只看原报告相比，附上追问回答是否更快、更准确地解答了同一个问题。格式通过、语句流畅或者重复图表，不算增益。

这是可停止的后续 AI 实验，**不作为现有本地数据报告发布的前置条件**。如果开发题没有增益，现有报告仍可按已核验的能力交付。

- 现有报告仍从已发布文件生成；本机 MySQL 镜像不作为本次运行依赖。正式包要记录每题的用户原话、确认选择、数据和目录版本、完整报告摘要、程序事实、模型消息、评分规则与相关代码文件摘要。**代码仍在修改，不能把本设计文件冒称已封存的正式请求包。**
- 程序从报告逐月行预先计算候选事实：同年且连续、已观察月份的相邻月差额；2026 年相邻变化的绝对幅度排序；最近几个月的升降关系；进口和出口各自的变化及口径。缺月、未观察值、零分母或跨年分类可比性未核验时，相关比较标为不可用，不补零、不猜测。
- 报告没有数量、单位价值和经统一估价的贸易差额时，程序明确登记“缺什么”，不能让模型把金额解释成数量、价格或已核实差额。参考值从已发布报告逐月行重新计算，仍依赖此前的数据工程核验，并非独立向官方原包二次取数。

## 模型能做什么、不能做什么

模型收到同一份已确认报告、读者追问、可引用的程序事实和报告摘要。它最多给出两条简短答复，每条必须列出支持它的事实 ID；缺数据时选择明确的“当前不能判断”及所需资料。页面在文字旁显示程序生成的月份、金额、口径和来源链接。模型文字不得自行计算数字、创造日期或来源、把金额当数量、推断政策因果、给出价格或投资预测。事实 ID 不在本报告内、引用与文字不符或报告摘要变化，均不得进入已审阅结果。

模型应当真正回应追问：F1 分清一次回落与连续下降；F2 比较限定范围内的变动幅度；F3 解释两方向同升为何不能直接推出差额；F4 说明金额证据的边界和下一步需要的具体资料。只说“需要更多数据”“不能判断”，或把已经醒目展示的关系卡原样改写，不算完成这项任务。

第一版每份报告只试一条追问。请求、原答和审阅记录绑在原报告摘要及追问摘要上；一次领取后不自动重试，不覆盖旧 v1—v4 原答。当前报告与现有解释入口继续可用，新增回答独立显示“试用／待核对”。

实施用新的 `trade-report-followup-v1` 协议：请求只给报告、追问和程序事实目录；每条事实含稳定 ID、商品/方向、涉及月份、统计口径、来源和报告摘要。模型只返回严格 JSON：相同的报告及追问摘要、`mode`（`observed` 或 `cannot_infer`）、至多两条 `text + fact_ids`，以及从固定清单选出的 `needed_data`（数量、单位价值、商品组成、同口径差额资料等）。正文合计不超过 400 个汉字；精确数字和月份由页面根据引用的事实卡显示，模型自由文字不得新写数字、日期、编码或网址。服务端拒绝额外字段、未知或跨报告事实 ID、摘要不符、空答与超预算；文字是否误说方向、是否真正回答追问仍由人核对。输入上限 24,000 UTF-8 字节，原答上限 8,000 字节。当前开发执行器输出上限为 4,096 tokens（先前2,048出现空正文后提高）；总请求时限最多 90 秒；实际用量与费用只记录回传值，不估算。

## 对照、判分与停止条件

**假设**：在相同数据报告上，针对读者实际追问挑选证据并给出说明，比只看原报告更容易回答该追问，同时不增加严重事实错误。对照为“报告本身”；处理组为“同一报告＋模型追问回答”。同一模型配置和同一四题材料固定后不改提示、事实池或门槛。

每题分别记录：①用户初问是否确认到正确商品/方向/月窗、报告是否可复算；②接口是否收到原答；③格式、摘要和事实引用是否通过；④内容是否忠于数据并回答追问；⑤与原报告相比有无可指出的帮助。重大错误包括错商品/方向、把最近月变化扩大为全期、跨年未经核验仍比较、编造价格/数量/原因、错误相减进出口金额。接口无原答单列为故障，不给内容分；拦住坏答案算产品守卫有效，不算模型答对。

审阅者先看完整的原报告回答追问，再看隐藏模型名称的“原报告＋模型回答”，逐题记“更清楚／差不多／更差”，并写出具体依据；还要对照不送模的逐月参考卡核事实。当前线程的意见只能叫已见材料的开发审阅。**采纳门槛**：四题产品范围均正确、四题模型回答无重大事实错误，独立审阅至少 3/4 认为追问回答提供了具体帮助；任何一题出现严重事实错误，该配置按预设顺序停止余题。四题的小样本只报告“这四题中的结果”，不声称普遍准确率。

开发题固定使用已有小麦出口报告，追问原话为“最新一个月回升了，那今年以来是不是一路上涨？”；2026-01 至 07 的逐月金额显示中途有涨有跌。此前一次结果未知；后续在4,096输出上限下另发的一次回答通过协议和引用事实核对，但它是否比原报告更有帮助尚未独立确认。**不要重发旧尝试，也不要把这条开发样例记作模型成绩。** F1—F4评测材料现已封存，材料与模型执行分开；封存包状态为 `frozen_materials_execution_not_authorized`。正式阶段仍需先确认开发题增益，并冻结准确服务商/模型ID、推理设置、Codex与API渠道、每配置调用上限和总预算。经单独放行后，每个确认可用的配置按 F1→F4 顺序每题至多一次、最多四次，不自动重试；出现严重事实错误则停止后续题。每次记录实际返回模型名、推理设置、输入/输出用量、耗时与可核实费用；未知费用不填零。正式四题只描述四题内的表现，不宣称普遍准确率。
