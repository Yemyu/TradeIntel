## 验收结果

从空白临时目录启动本地服务，经真实 HTTP 接口完成：导入原文为 disabled → 读取 13 字段模板 → 用此前人工审过的逐字引文提交候选 → 摘要绑定确认并启用 → 确认 18 个完整 HTS8 / 2025-08 至 2026-07 的范围 → 生成并保存统计报告 → 停止、重启服务 → 读回同一报告与公告状态。浏览器实际打开了该新报告，检查到月度柱形图、最近月 71,062,824 美元和 16/18 项细码完整提示，未见排版阻断。预览标签和本地服务在检查后关闭。

阻断反例也通过：disabled 时不能生成报告；提交后的字段被改动不能沿用旧摘要启用；确认范围被篡改不能生成报告；超过 256 KiB 的公告导入仍拒绝，普通统计请求仍保持 16 KiB 上限。启用后贸易覆盖继续标记 `not_checked`，报告中的观测金额不被称为政策影响额。

首跑发现网页接口将约 21 KB 的真实公告正文拦在统一 16 KiB 限制之外，后续完整逐字引文提交也被同一限制拦下；此前绕过 HTTP 直接调用内部函数的测试未发现。现只对公告导入和字段提交/确认入口提高到 256 KiB，并保持普通接口上限。公告校验失败原被通用异常处理误报为 HTTP 503；现对公告接口返回 422，前端能区别“输入或状态需修正”和“服务暂不可用”。
