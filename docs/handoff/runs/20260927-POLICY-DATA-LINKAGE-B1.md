# 政策—贸易关联包 B1：上层商品背景只读报告

日期：2026-09-27。范围仅为包 B 的第一步：已经人工确认 `parent_context` 的公告，按确认的 HS4/HS6/HTS8 上层编码查询已发布的美国自中国大陆进口月度数据，生成并保存 `announcement-context-report-v1`。没有接国家背景、事实卡或网页入口。

## 本步做了什么

- 查询前后重建关联确认单，核对原公告、候选、关联判断、数据和分类版本。报告同时保存“政策对象”和“实际统计对象”，金额字段仅叫 `whole_parent_value_usd`，`policy_amount_status` 固定为 `not_determined`。
- 逐月用官方分类目录的子编码清单，独立核对已发布 CSV 和现有只读查询。子编码缺行或中国大陆进口未观测时，不显示该月金额、不补零；仅完整观测且相邻、同年、同编码及名称时才给月差。
- 报告快照走已有本地存储与摘要核验；新类型固定为无模型解释，不从此入口调用模型。旧严格公告报告合同未改。

## 验证

- 合成测试包含完整上层编码、HS6 上层编码、缺子码、未观测子码、确认单被改及错误路线。连同旧贸易报告、分类目录和网页相关回归：`69` 项通过。
- 本地已发布 `2026-07` 只读实数核对：`84139190` 目录有 16 个十位子码，CSV 匹配且观测 16 个，上层整体进口额 `57,474,068` 美元；报告仍明确**不是**排除公告的政策覆盖额。
- `git diff --check` 通过。没有调用模型 API、写 MySQL、改原始数据、提交或推送。

## 尚未完成

这不是完整包 B，更不是产品收口。国家背景路径还须逐月核对原始 ZIP 与分类/已发布 CSV；无统计事实卡和页面显示尚未接线。上述公告为开发中已见案例，不能计作新的独立法律或产品验收。下一步先实现国家背景的只读逐月复算及无图拒绝门，再接页面。
