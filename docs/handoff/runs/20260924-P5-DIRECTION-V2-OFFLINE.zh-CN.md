# P5：月度方向解释合同 v2，离线修订

日期：2026-09-24。此记录接续[第一次真实调用](20260924-P5-TRADE-EXPLANATION-REAL-SMOKE.zh-CN.md)，不改那次原答、用量、审阅状态，也不把新规则追溯计入旧成绩。本轮真实模型 API 调用为 0。

## 发现与假设

旧输入把月度差额写成带负号的数字，示例解释却只说“金额变化”。DeepSeek Flash 的那次真实回答虽然通过格式门，也只写了“出现金额变化”，没有点出已算出的下降方向。本轮假设是：由程序直接标出方向，要求模型解释引用该方向，可以减少这种笼统回答。仅凭离线验证还不能证明真实模型的文字会变好。

## 改动

- 新生成请求使用 `trade-data-explanation-v2`。月度观察根据已算出的差额明确标为“增加”“减少”或“持平”，金额以绝对值展示；缺少相邻月份比较时不造月度观察。
- 问题明确问变化、趋势、涨跌或环比且有可比较月份时，模型必须引用该方向的月度观察。进出口都查时，两套月度观察分别引用。
- 月度解释文字必须包含与观察相同的方向词；未说方向或引用错观察的回答会被拒绝。提示示例写明本次商品和进口／出口方向，并要求不同观察不要反复复制同一句限制。
- 审阅门仍在。方向词检查只能筛掉明显遗漏，不能证明整段经济解释正确。

## 离线核对

固定输入为之前保存的大豆出口报告：2026-07 相比 2026-06 少 3,500,150 美元。新请求包含 `export.month_change` 必选项，观察文字明确写出“减少了 3,500,150 美元”；生成的请求约 5 KB，低于 60 KB 门。构造的增加、减少、持平、缺值、双方向与错漏方向反例均按预期处理。针对合同和 HTTP 调用链的 9 项测试通过，脚本编译及 `git diff --check` 通过。

## 下一次真实验证的固定门槛

若继续验证，用同一已发布数据版本生成**新报告**，DeepSeek `deepseek-flash` 最多调用一次，输出上限 2,048 tokens；记录输入版本、实际请求、原答、用量、结构结果及逐条人工判断。超时或未知结果不重试。只有回答正确指出“减少”、没有新增无证据事实，且人工审阅认为文字比旧答更具体，才采纳本次改动的质量结论；否则保留失败记录并先诊断。两次已见题结果只能作开发诊断，不能声称模型总体准确率提高。
