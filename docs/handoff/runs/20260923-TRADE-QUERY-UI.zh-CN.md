# 2026-09-23 通用美国进口报告首条真实路径

## 本轮做了什么

- 核对美国国际贸易委员会公开 HTS 目录：2025 年版与 2026 年 7 月版均将大豆列为 HTS 1201，包括种用大豆 `1201100000` 和其他大豆 `1201900005/10/90`。本地 2025-01 至 2026-07 的 19 份已加工月文件，每月均出现这四个统计编码。玉米列为 HTS 1005，作为第二个非旧案例的测试商品。分类依据：[2025 HTS](https://www.usitc.gov/sites/default/files/tata/hts/hts_2025_revision_32_csv.csv)、[2026 年 7 月 HTS](https://www.usitc.gov/sites/default/files/tata/hts/hts_2026_revision_11_csv.csv)。本轮没有声称逐月核定所有 HTS 修订或现行税率。
- `TradeDataRepository` 现在可按有出处的 HTS4 商品组查询，保留原有 HTS8/10 查询；仍只允许美国消费进口额，伙伴粒度仅“全部来源/中国”。原始 ZIP 和旧政策案例不动。
- 新增 `trade-query-v1`：问题→商品/方向/时间判断→范围确认→版本绑定文件查询→统一的数据报告对象。无方向的问题须先选；出口、豆粕/豆油、未支持伙伴、同比/环比、缺月、较早年份未核定的商品组均不会被冒充成现有大豆进口报告。用户明确输入 HTS8/10 时可按该编码查询，不限于登记的两个中文商品名；编码不存在不会显示假零值。
- 工作台接入通用报告：12个月横向图、结论、逐月金额表、折叠来源与计算说明。仅纯数据报告，不冒称AI解释；报告刷新可恢复，不强制将用户从工作台跳走。固定钨/光伏政策案例继续单独使用旧通路。

## 实测

- 浏览器输入“最近美国大豆贸易有什么变化”→先确认方向→选择美国进口→显示 HTS 1201、全部来源、2025-08 至 2026-07→确认后生成报告。2026-07 为 **46,041,287 美元**；比 2026-06 多 **13,163,460 美元**；12个月合计 **354,295,547 美元**。刷新后仍是大豆报告，而不是五商品示例。
- 浏览器输入“最近美国钨进口情况怎么样”仍进入旧案例，提案只含三项钨商品。
- `tests.test_trade_query_flow`、`tests.test_trade_data_repository`、`tests.test_product_scope`、`tests.test_product_model_config` 共 17 项通过；`tests/session_flow_ui.test.cjs` 2 项通过；`node --check web/design-preview/live.js` 与 `git diff --check` 通过。
