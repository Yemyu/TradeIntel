# 贸易 Agent 第二题多报告范围修复（2026-09-30）

## 原问题与边界

第二题真实追问“出口呢？”返回了大豆 `1201` 的全部目的地与中国目的地两份报告。全部目的地 2026-07 FAS 为 **889,379,312 美元**，中国目的地为 **141,197,240 美元**；两者不是同一统计范围。旧程序把最后一份中国报告写成会话主范围，公开摘要又未标伙伴，页面刷新后打开中国报告。原始第二题因此仍记为**未完全通过**，旧私有账本和评分不改。

## 修改

- 服务器依据用户本轮明确指定的伙伴、否则依据上一轮伙伴，选择主报告；用户未指定新伙伴时，不以模型工具调用顺序覆盖“全部目的地”范围。每份程序摘要的金额标注对应伙伴。
- 公开会话加入主报告 ID 与可切换报告列表。读取已保存的旧第二题会话时，在公开视图中重新从已核验报告生成标签和主范围，不改私有审计文件。
- 页面默认打开主报告；同时保留另一份报告的清晰切换入口，切换查看不改变后续追问的主范围。实际 GET 状态端点与页面刷新均走同一公开投影。
- 增加双报告、明确中国目的地、旧记录恢复与下一轮范围继承的回归测试。
