## 准备与停止条件

假设：已核验的 124 文件数据包，加当前工作区的 `src/`、`web/`、`requirements.txt`、`scripts/run_web.py`、`scripts/trade_demo_data_bundle.py`，足以在独立目录和新虚拟环境运行普通商品报告。对照为当前项目的既有本机运行记录；本次不把相同源码副本视为 Git 克隆。数据固定为 `trade-demo-data-20260925` 清单中的进口 `dd980149…`、出口 `4308e4a8…`、分类 `a758a023…` 三版；复制品必须再次逐文件通过摘要和版本校验。若数据不符、商品选择不能确认、三类报告或刷新恢复失败，即停并报告，不改验收口径。预算为 0 次外部请求、0 次模型调用和 0 次数据库写入。

在系统临时目录新建随机隔离目录，将上述文件和数据包复制进去；没有复制项目原始 ZIP、`.local/`、凭证、课程参考源码、测试结果或历史运行记录。在该目录运行 `python3 -m venv .venv`，解释器为 Python **3.13.3**；本轮没有安装 `requirements.txt` 中的可选分析依赖，因此只证明这条普通商品网页路径可在独立虚拟环境以标准库运行，不证明所有项目命令都不需要依赖。
