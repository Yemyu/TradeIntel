# 美国重测：独立报告评分基础

新增 `scripts/score_us_agent_retest.py`，只属于评测侧，不进入模型上下文。

check_report 独立核对美国报告方、商品、方向、伙伴、连续月份、最新月/固定窗口、逐月整数美元、未知状态、最新值/变化/完整期间合计。标准来自此前独立CSV参考，不调用产品查询生成答案。未知不补零；bool不作为整数金额。核对结果只称数值/范围检查，不冒称全产品或政策通过。

count_results 分开计划/执行轮数；只有实际供应商响应轮进入模型分母，响应后失败仍保留；程序零响应单列，未运行不算成功。重复案例拒绝。发布门始终未评价，必须待完整引用、政策、原始决策与存档审计才能判断。

新增4项反例测试：正常与错范围、错变化/重复月份、未知金额、分母及部分批次。组件累计17项通过，git diff --check通过。0API，旧成绩未改。

剩余：评分器连接实际会话/报告读回，双方向报告与政策引用完整性、边界原始工具决策审阅、案例依赖、冻结/金额许可。当前不是完整可执行评测；不能用17项脚本测试替代模型效果证据。
