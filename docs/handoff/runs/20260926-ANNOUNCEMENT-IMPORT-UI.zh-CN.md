## 本步做了什么

- 模板接口现在返回服务端已保存的原文段落编号和文字，页面可展开查看并从列表中选择段落；不是让用户猜 `section_id`。
- 每个字段可以添加多条逐字引文；`known` 至少一条、`conflict` 至少两条，段落与引文必须一起填写。仍由服务端按原文复核，不把文字匹配当成语义正确。

- 修改字段后，页面取消旧候选的启用状态；需要重新提交才能启用。
