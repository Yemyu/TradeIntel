# 公告字段建议：固定案例离线适配

日期：2026-09-26。依据 [固定案例设计](../POLICY_ACCEPTANCE_DESIGN_20260926.zh-CN.md) 的五步清单实施；本阶段没有模型/API 调用、数据库写入、提交或推送。

## 已完成

- 十位商品税号引文现接受连续10位、4.2.2.2和标准4.2.4点分；截短、拼接数字及将十位前缀冒充整八位仍拒绝。
- 通用提示写明：简单税率键须对应已知商品候选，百分比须在引文中按字面出现，文字豁免可由 `rate_meaning` 说明且 `rates` 保持未知；`reason` 可为字符串或 `null`，商品码不重复。提示没有放入 H1/H2 的答案。
- 官方 H1 木材/家具、H2 农产品原文纳入既有 prepare/verify。题名、公告号、发布日期、原文 SHA256 和完整提取文本 SHA256 均核对；正文任何变化会停止，不能静默更换。角色固定为 `acceptance_design_seen`，不是盲测。
- 逐事实评分表在 `scorecard.json`，和唯一要送给模型的 `request.json` 分开。H1 为46项关键、5项普通；H2为25项关键、4项普通。每条列原文整段、起止位置和保存段落 ID；两项正文缺项以整篇摘要与“无肯定引文”记录，不伪造引用。评分栏预留空白，尚无模型成绩。

## 下一步边界

若要实际试跑，先核定供应商准确型号、支持的推理参数、每次/总金额上限和最终 HTTP 字节，再按既定开发题 R2→D2 的停止门执行。开发题不合格就停止，不消耗 H1/H2；任何首答与失败记录原样保留，不改题、不自动重试。H1/H2 即使通过，也只能称这两份设计已见固定案例的内部验收，不能称独立泛化正确率。
