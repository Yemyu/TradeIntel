# v3预算复核

结论：预算协议实现经补充修复和集成验证后，可用于下一份候选实验的准备。尚不代表模型通过验收。本轮0次API，未提交推送。

## 审查发现与处理

1. Luna的30项通过是6项新增预算测试加24项既有相关测试，并非新增30项；主要覆盖预算函数，缺少v3实际执行路径。本轮补充6项集成测试及多组子案例，覆盖执行器→生产解析→原答/运行文件→账本→汇总。
2. v3解析通过后若预算超门，validation.json被整体运行结果覆盖，结构成功证据丢失。已保留原解析产物和运行内的结构摘要。
3. 汇总器原来的结构通过条件同时要求进入语义审阅状态，预算失败会隐藏已完成的结构验证。已补充独立的structure_result、budget_result、budget_reason字段和逐题表；证据仍核对原答摘要、账本绑定及预算终态，不据此直接增加整题分数。

## 验证范围

36项相关离线测试通过，包含2000/2001正文字符实际解析、usage未知/布尔/超预算、字节门与异常finish不调用解析器、重复JSON键拒绝、旧v2估算门、协议降级/删除/未知版本拒绝。集成测试读现有本地报告作为数据fixture，provider为注入函数，无网络。历史冻结测试未重新刷绿。

正文字符依据生产解析后字段计算（含既有strip行为），每条350字/观察事项200字等原合同仍有效；2000字符总门不取代这些约束。API usage为厂商报告，不声称独立认证计费。
