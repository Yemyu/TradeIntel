## 实际结果

- 问“上个月”时，工具端以服务器日期绑定目标月。固定 2026-09-29、最新可查 2026-07，模型错用 `latest_contiguous` 或正确选 `calendar_relative(-1)` 均以 `needs_clarification` 结束，告知缺少 2026-08、最新可用 2026-07；不生成错期报告，也不继续发送模型回合。固定 2026-08-29、7 月可查时，单月请求可完成。复合比较允许基期查询，但 `finish` 必须引用覆盖目标月的报告；“最近”和明确否定“不是上月，查最新”不触发此锚。
- `finish.explanation` 的自由文本不再成为公开 `message`。模型故意写“这证明政策已经奏效”，不论 `source_ids` 为空还是含有效来源 ID，公开结果只由已存报告的商品、月份、金额及限制句组成，仍可正常完成数据报告。模型继续负责商品／方向／查询工具选择；**并未因此获得自动写出可靠经济解释的能力**。
- GET 会话、重复请求和新轮次统一使用公开投影。旧磁盘会话保持不变，公开读取会隐藏其未经新规则审核的模型文字，原数据报告仍可读。实际已保存首题会话只读核对为 `completed`、`legacy_unreviewed_hidden`、1份报告。
- 网页 Agent 报告标题改“数据摘要”，不再把程序摘要标为模型草稿；独立的旧模型解读与逐项人工审阅入口不变。
