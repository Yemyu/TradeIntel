# 政策—贸易关联包 B2：中国大陆贸易背景原包复算

日期：2026-09-27。范围是已人工确认 `country_context` 的只读报告路径；只认已发布并留存原始 ZIP 的月份。不含网页接线，也不以全国进口额推断政策覆盖额。

## 实现与拒绝门

- 对每个月从官方 ZIP 重新读取 `COUNTRY.TXT` 与 `IMP_DETL.TXT`，只允许唯一的 `CHINA` 国别码；按十位商品码独立合计金额与行数，和已发布 CSV **逐商品**核对金额、观察状态、来源与年月，再核月度总量和官方分类目录。
- 原包缺失/摘要变化、处理文件变化、某商品金额或国别状态不一致、分类目录缺码、月份未发布时拒绝生成，不画看似连续的图。公告原文/候选/人工判断/数据与分类版本在查询前后重验。
- 报告快照沿用本地存储与内容摘要。报告明确写“美国自中国大陆进口的贸易背景”；香港没有合并，`policy_amount_status` 固定为 `not_determined`。原公告税率不是报告月份实际税率。此类报告不走模型解释入口。
