# 商品搜索与动态双语修复（2026-09-24）

## 范围

针对前一轮产品验收发现的四项明确问题做局部修复：稻米别名漏召回、稻谷/英文 rice 的候选噪声、工作台仍称只支持大豆玉米、切换英文后动态候选与报告仍为中文。没有改动原始贸易数据、分类目录文件、旧模型结果或冻结评测；没有调用模型 API、提交或推送。

## 改动

- 中文检索增加“稻米/稻谷/大米”到 HS4 1006 的搜索别名。别名只用于寻找候选，不代替美国官方商品定义；用户仍须查看官方英文描述并确认。
- 英文单一商品词与官方 HS4 标题完全一致时优先只返回该标题，避免 `RICE PAPER`、`EXCEPT RICE` 之类共有词造成噪声；“wild rice”这类多词问法不适用该收窄规则。补齐常见英文问句动词/时间词停用表。
- 统一工作台的中英文能力说明；不再暗示商品仅限大豆和玉米，也不宣称自然语言已覆盖所有商品。
- 商品候选、方向选择、范围确认、数据报告、图表说明、来源/口径、模型设置及主要状态提示跟随语言切换。英文报告的走势描述由同一批已发布月度数值在页面计算；原报告和观察数据不变。语言切换不会触发模型请求或重算服务端报告，未保存的解释勾选会保留。
- 修复英文语言设置在页面刷新后被动态脚本覆盖成中文的问题。

## 验收

- 真实目录搜索：`美国稻米进口最近有什么变化？`、`美国稻谷进口最近有什么变化？`、`How have U.S. rice imports changed recently?` 均只返回 `1006 RICE`。这不是商品名称的全面准确率测试。
- 独立本地浏览器 `http://127.0.0.1:8897/preview/`：英文提问 → `RICE` 候选 → 确认美国进口、2025-08 至 2026-07 → 英文报告。2026-07 为 114,725,468 美元，比上月多 3,401,390 美元，十二个月合计 1,355,497,265 美元；有月度图表和来源入口。切中文后同一报告中文显示；英文工作台刷新仍为英文。
- `tests.test_trade_classification_catalog` 与 `tests.test_trade_query_flow` 共 16 项通过，页面 Node 测试 6 项通过，JS 语法检查与 `git diff --check` 通过。未运行全量历史冻结套件。

## 尚未通过的发布门
