# 新公告→通用进口数据：只读服务层首轮验收

日期：2026-09-26。目标是验证已确认的新公告能否查到现有通用进口统计，而不沿用只覆盖少数商品的旧固定政策案例。**本轮不接网页或 A3 报告，不调用模型，不声称政策影响金额。**

## 实施与边界

- 新增 `src/tradeintel_ai/announcement_trade_bridge.py`：只接受已启用、13 字段候选与人工确认摘要仍一致的公告；先重新核对候选和逐字引文，再要求中国原产地、明确月份和当前已发布数据版本。只查询已确认的 whole HTS8 税号，可选其子集，每次最多 100 项。
- 使用已有 `TradeDataRepository` 的 `CHINA` 美国消费进口查询，逐码返回 `observed / not_observed / no_record / not_processed`、**已观测细分行的金额**或 `null`、命中/有观测的 HTS10 数、分类年份、Census 原包/加工文件摘要和完整数据版本。已观测的 **0 美元**保留为 0；未观测或无记录不补零。总览还分别计数“每个所选 HTS8 至少一行有观测”和“各 HTS10 细分行是否全有观测”，两者不能混为一谈。
- 输出 `statistical_status` 与 `scope_status`，但 `policy_amount_status` 始终为 `not_determined`。`ex`、文字限定、HS6、部分 HTS10 不会被升级为完整 HTS8；若公告混合完整和部分税号，只核对明确所选的完整税号并列出未处理的部分范围。响应摘要绑定查询结果，但不写入旧 `trade_coverage`、不改变旧 A3 生成许可。
- 检查时没有把网页用户提交的 URL 当作“已核实官方来源”；本轮只复用了此前保存并人工确认的 R2 公告。引文字面存在仍不能代替法律语义审阅。

## 最小验证设计与结果

假设：旧案例的 `2/18` 主要是查询入口范围过窄，而非通用进口数据缺失。对照：旧案例覆盖记录原样保留，新桥独立查询同一 R2 的 18 个 HTS8；不把这次已见材料当 AI 未见评测。数据：当前 `census-us-import-hts10` 版本 `dd9801492e80268e51480b08c2edcbf495aba3ce01b7ee64739566f67a151ef8`、月份 `2026-07`、中国来源；公告取此前临时迁移目录中的已启用 R2 版本，**没有写入生产公告库**。代码基线 `main @ a87554c`，工作区有既存未提交修改；本轮新增服务文件 SHA256 `7cd840009026f2be21a15523c4fe809869a7cfb7e4224360f631fde52a4a76ff`、测试文件 `cfb3519ad76d009ec50a2fc6eba1b88d31b682e676a3673316f2127a754651c3`。

结果：R2 的 18 项 HTS8 均为 `observed`，但其下 68 条匹配 HTS10 中只有 **67 条有中国来源观测**；38180000 的 8 条细分行中有 1 条未观测。返回 `subcode_observation_status=some_matched_hts10_not_observed`、`policy_amount_status=not_determined`，结果摘要 `79c31f8b4cc0274fd2f8fa1c85a01aa7dede7d254f3491be9c2d553451cc9bb6`。这仅说明每个税号至少存在一条对应统计观测；不证明 18 项的统计总额完整，更不证明法律适用范围、综合税率、税款或政策效果。

反例覆盖：合成临时文件验证无记录与未观察不补零、真零保留、部分 `ex` 不冒充全税号、非中国来源拒绝、未启用公告拒绝、错误/重复子集拒绝、候选篡改拒绝、数据版本变更拒绝、未发布月份显式 `not_processed`。新桥及旧公告/通用仓库相关共 **55 项 Python 测试通过**；旧 A3 生成路径没有修改。未运行全量仓库测试或浏览器测试。

预算/停止条件：本阶段模型/API 0 次，MySQL 0 次，网络 0 次；若真实对照出现来源摘要、版本、状态或候选确认不一致，应停止后续报告接线，而不是默默改成 `exact`。本轮未碰原始文件、历史冻结结果、旧任务账本、密钥、旧公告报告或 Git 远端。

## 尚未交付

这只是**服务层只读查询**，尚未接公告导入页、范围确认、报告图表或导出；旧 A3 依然只能使用固定案例。下一包先修人工公告页面的段落 ID、多引文及来源标记，然后设计新桥结果如何进入报告，避免把 `all_selected_observed` 直接等同于政策敞口 `exact`。自动发现新政策、独立未见公告的 AI 字段抽取验收和跨年分类对应都未完成。
