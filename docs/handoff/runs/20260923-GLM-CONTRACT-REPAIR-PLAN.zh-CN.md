## 实验定义

- 假设：把“解释文字不能出现数字/日期/税号”等格式约束前置，并给出一条合格示例，可能减少 GLM 把编码和日期写进正文的情况。
- 对照：已保存的 GLM-4.6V v2 Q1 原答；不改原答、不改原冻结。
- 干预：建立新的候选题包和新的冻结，只有 Q1 的消息加入更明确的格式示例；数据报告、问题、模型、思考开关、总输出上限和截止时间保持不变。
- 评价：原始响应能否直接通过现有解析器；随后检查事实、相关性、可用性四项。格式失败或响应截断立即停止，不运行 Q2—Q4。
- 采纳门：Q1 结构/预算通过，且四项内容审阅全部通过，才记录为“修复诊断通过”；只通过格式不能说明模型质量改善。
- 预算与停止：最多一次 API 请求，沿用单题 8192 总输出、读者正文上限和九十秒截止；超时、未知结果或格式失败均停止且不重试。
