# 公告填写与报告标题：页面收口

日期：2026-09-26。接续[R2 全新导入验收](20260926-R2-FRESH-HTTP-QA.zh-CN.md)，只改页面与页面测试，不改变公告候选、人工确认、贸易查询或报告数据合同。

## 改动

- 13 字段表改用中文字段名；原字段键仍可在悬停时查看，提交给服务端的键不变。段落下拉项显示编号和原文开头，减少在数百个编号中盲找。
- 选定段落后可以点“填入整段原文”，系统只把**已保存的该段原字**放入引文框；用户仍须填写/检查字段值，必要时可以删为该段中的准确原句。已提交的候选若改了引文，就失效并要求重新提交；没有自动启用。
- 导入页现在原样提交输入框正文，不再先 `.trim()` 去掉首尾空白。R2 官方正文以前导换行开头，删空白会改变用户粘贴的原文。
- 公告统计报告主标题改为“公告所涉商品的美国进口情况”；很长的官方英文原题仍列在标题下，并在公告内容里保留。英文界面同步显示对应标题。

## 验证与限制

Node 页面测试 15 项通过，其中新增“段落原文一键填充后修改必须重新提交”和“导入正文首尾空白原样提交”。再次从官方 R2 生成隔离报告，在浏览器中目视核对新标题、原题、最新月金额和图表；本地临时服务、标签已关闭。`node --check` 与 `git diff --check` 通过。R2 HTTP 全流程脚本再次通过：18 个商品、12 个月、2026-07 已观测金额 71,062,824 美元，重启恢复一致。未跑全仓测试；没有调用模型、外部 API 或 MySQL，未提交推送。

一键填原文**不是自动理解政策**，13 字段的判断仍由人完成。现有确定性解析器针对旧 CBP 公告，不能未经新材料验证就替 R2 或任意公告自动填字段。若下一步要用 AI 帮忙提字段，应另取未见官方公告，先锁定人工参考、错误代价和判分标准，再做有限调用；R2 不能算未见成绩。
