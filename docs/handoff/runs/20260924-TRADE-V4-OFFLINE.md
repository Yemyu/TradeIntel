# v4 关系卡与协议隔离：离线实施记录

日期：2026-09-24。范围：通用美国商品贸易报告；**离线实施阶段未调用真实模型 API，未提交或推送**。后续一次独立开发调用已单独记录于[canary记录](20260924-TRADE-V4-DEV-CANARY.zh-CN.md)，不要将两阶段合并成“零调用”。

## 本轮做了什么

- 新增 `trade_explanation_v4.py`：从服务器报告的逐月行生成最近月变化、连续变动、近期转向、双方向同向/异向、已观察极值和完整期间合计。连续关系不跨缺月、未观察值或未核验的跨年商品口径；并列极值逐月列出。可用卡附报告摘要、计算器版本及商品/方向/口径，不能形成的关系记录原因；仅连续、转向、双向关系允许触发可选模型解释。
- 新报告在存储时绑定 v4 协议与关系卡快照；读取时重算并核对摘要，调用领取时在锁内核对协议及卡片摘要。历史记录无版本字段时仍按 v3 处理；v3 模型消息、解析器和冻结包未动。
- 服务端根据记录协议选择 v3 或 v4 消息与解析；无实质关系时在调用前拒绝，不占用一次性调用状态。v4 原答仍先保存，再检查报告/卡片身份、引用和部分显著错误，并保留人工逐项审阅。页面对无可解释关系的新报告隐藏模型按钮，数据报告仍展示。
- 报告页现在在对应方向图表旁显示“最近几个月的变化”；双向报告另显示进口／出口最近变动关系。内容由程序卡片生成，不增加新的金额结论；中英文切换分别显示自然语言版本。没有可解释关系时保留普通数据报告，不出现模型解释按钮。

## 离线验收

- Python：相关查询、数据、分类、旧 v3、新 v4、HTTP 流程及网页服务共 **61 项通过**。
- 本机已有 **14 份**历史报告记录可只读加载；其中 v1/v2 原答仍保留原协议，旧事实卡缺少存档时不冒充 v3 重建卡。新增测试模拟并检验这一边界，也验证快照内容被改写时拒绝加载。
- Node 页面：**9 项通过**，包括新报告跳过模型、v4 单向和双向关系卡、中英文切换及旧 v3 单/多事实条目继续显示。
- 真实已发布数据只读核查：小麦出口最近转向、大豆进口连续变化、乘用车进出口各自变化及双向关系均形成卡片。测试中发现进口 `ALL_ORIGINS` 与出口 `ALL_DESTINATIONS` 不能按字符串相等判断，同属“全部”范围时现已正确对齐。
- 使用独立 Edge 页面实测自然问题“小麦出口有什么变化”→选择官方 `WHEAT AND MESLIN` 商品范围→确认 2025-08 至 2026-07→生成真实12个月报告；页面显示 2026-07 出口 453,063,847 美元、比6月增加49,597,132美元、最近三个月先降后升。中文/英文切换正常，控制台无错误；没有点击模型调用按钮。浏览器页已留给用户查看。
- `git diff --check` 通过。未运行全量历史冻结测试，未做 v4 模型调用或人工内容评分。
