## 关键观察

- Flash 四题都返回 `finish_reason=stop`，请求模型和回传模型均为 `deepseek-flash`；输出通过 v3 JSON／引用／长度合同。T1 茶叶最新月增加、T2 小麦最新月增加、T3 乘用车进口及出口最新月均下降、T4 原油进口下降且不能据金额归因政策，均与参考卡不冲突。但解释多为概括与限制重述；尤其 T2 只说“有合计值”，没有给读者提供额外解释。这里的“4/4”仅指技术合同，不是内容通过率，更不是总体准确率。
- Pro 返回的 `model` 字段确为 `deepseek-v4-pro`，可与本轮 Flash 回传名区别。T1 结构与方向正确但解释很短。T2 同时说“本区间呈增加走势”和“近期月度较上月上升”：后一句属实，前一句与本报告 2025-08 的 677,539,511 美元、2026-07 的 453,063,847 美元相矛盾。**首尾实际下降**，故登记为严重事实错误；依冻结停止规则不做 T3、T4。此结论只针对这一版材料的这一次回答，不推断 Pro 整体弱于 Flash。
- GLM 的 HTTP 401 是服务商访问拒绝，不是生成质量分数；无原答时既不能算答错，也不能把用量写成零。智谱[官方参数说明](https://docs.bigmodel.cn/cn/guide/start/concept-param)称 `glm-4.6v` 可使用默认开启的思考模式，但 `reasoning_effort` 仅支持 GLM-5.2 及以上。因此这次候选只能标“默认／自适应思考”，不能写成“高推理”。
- DeepSeek [官方接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)列出这两个请求名及 `reasoning_effort` 参数。本轮 ledger 记录了请求名、回传名、思考参数、响应和服务商回报用量；没有可靠费用回报，不推算费用。

## 评分边界与产品问题

冻结评分卡还要求分别审阅事实忠实、是否回答用户问题、是否有具体解释增益且自然可读。上述严重错误筛查是**非盲 AI 辅助初筛**，尚未完成隐藏模型名的独立内容审阅，用户也未采纳答案；所以本轮不公布“通过题数／已答题数”。后续审阅需把原答与程序报告合看，不能因模型未复述程序已显示的金额就机械扣分。

T2 用户问了“合计金额是多少”，冻结系统提示却禁止模型正文新增数字。程序报告实际给出 6,051,458,529 美元，因此**整份产品报告能回答数值**；但模型一句“有合计值”对用户几乎没有解释增益。这是报告排版与模型职责的配合问题，不能为了让正式题表现好而中途改提示。若要变更模型职责或说明方式，须另建 v4 题包，保留本轮 v3 原答与结果。
