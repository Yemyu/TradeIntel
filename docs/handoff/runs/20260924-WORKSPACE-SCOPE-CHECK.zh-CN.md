# 工作台真实提问范围核验（2026-09-24）

## 本轮目的

核对独立工作台页面是否使用真实贸易查询入口、大豆问题是否仍落到旧钨案例，以及本机模型状态如何显示。只做范围预览和确定性数据报告检查，不请求模型服务。

## 核验方式与结果

- 在隔离临时输出目录启动本机服务，使用新的独立浏览器标签打开 `/preview/` 和 `/preview/#workspace`；没有使用用户原有活动网页。浏览器中只核对页面控件与文案；真实提问由 HTTP 请求直达页面同一后端接口验证，没有在页面输入框实际点击提交。
- 首页把“已接入商品数据查询”和“下方为示例报告”区分开；工作台说明先查范围、确认后生成数据图表，模型解释另行选择调用。
- 工作台输入“最近美国大豆出口有什么变化？”后，服务端返回 `ready`：美国、大豆、出口、2025-08 至 2026-07、编码组 `1201`。没有路由到钨/光伏旧案例。
- 同一已发布数据版本生成确定性报告：12个月序列，区间总额 18,789,570,646 美元；2026-07 为 889,379,312 美元，较 2026-06 减少 3,500,150 美元。报告中的 `ai_status=not_requested`，本轮没有发起模型解释。
- “最近美国玉米出口有什么变化？”识别成功（`1005`）；“最近美国小麦进口有什么变化？”及“最近美国咖啡进口有什么变化？”均返回 `needs_product`。
- 数据目录核对：进口 HTS10 目录包含48个月（2016-01 至 2026-07）；出口 Schedule B 数据已接入12个月（2025-08 至 2026-07）。自然语言名称注册表当前只列大豆和玉米，明确编码输入是另一条查询入口。
- 页面模型状态显示 DeepSeek `deepseek-flash` 已配置，短连接此前成功，完整报告解释尚需验收。本轮未读取或显示任何密钥，没有点击“测试连接”或“生成解释”。

## 结论和边界

这不是“数据库只有两个商品”：底层明细范围更广。但当前自然语言商品识别只有大豆、玉米两个组名，其他商品需要用户给出准确编码；对普通用户而言，这仍是明显的可用性限制。进口 HTS 与出口 Schedule B 的商品细码不应机械互换，跨年分类变更和组码覆盖也必须在查询范围里明示。

本轮没有修改代码、没有触发持久报告写入、没有模型 API 调用。数据报告写入仅落在临时目录；本机测试服务随后已停止。浏览器两个独立标签是本地临时页面，服务停止后刷新将不可访问。
