# P5：通用贸易报告的模型解释，离线接线验收

日期：2026-09-24。对应设计：`docs/handoff/P5_TRADE_EXPLANATION_DESIGN_20260924.zh-CN.md`。本轮没有调用真实模型 API，没有提交或推送，也没有改动旧政策实验和冻结记录。

## 结果

- `trade-query-v1` 与 `trade-query-both-v1` 的程序报告先保存于本机 `.local/trade-reports/`，绑定报告摘要；模型调用不是生成数据报告的前提。
- 独立的 `trade-data-explanation-v1` 只给模型已计算观察和来源，让它解释金额变化的含义与局限；不准增加新数字、来源、政策因果或投资结论。进口消费额与出口总额（FAS）分别解释，不直接相减。
- 用户在报告页明确点击才领取一次模型调用。原答先保存后解析；HTTP 明确拒绝与未知结果分开记录，未知结果不自动重试。服务端锁与报告状态阻止同一报告并发重复领取。
- 解释草稿必须逐项人工核对，未经采纳不能标成已核实解释。刷新后从服务端恢复报告及审阅状态，不以浏览器缓存冒充审核记录。
- 页面实际操作：提问“最近美国大豆出口有什么变化”→确认大豆／出口／2025-08 至 2026-07→报告出现12个月图表与逐月金额→手动触发**离线模型替身**→勾选解释及事实确认→保存审阅→刷新，采纳内容仍在。本次替身文字只验证流程，不能当作真实模型质量成绩。

## 验证

- 38项相关 Python 测试通过，覆盖解释合同、篡改、双方向、并发领取、已知失败与超时、审阅和 HTTP 路由。
- 3项相关 Node 页面测试通过；`live.js` 语法检查及 `git diff --check` 通过。
- 浏览器在独立新标签页验收；离线服务拦截外部网络连接，新增真实 API 调用为0。

## 尚未完成、不可误报

真实服务商对完整通用报告能否按合同返回、返回内容是否有用以及实际费用，均未通过本轮验证。旧短连接测试不能代替这一项。真实调用应先限定一个已发布数据问题和一次预算，保留原答；若出现超时或结果未知，不重复收费请求。完整打印分页、MySQL与文件同版对照、公网多用户部署也未在本轮验收。
