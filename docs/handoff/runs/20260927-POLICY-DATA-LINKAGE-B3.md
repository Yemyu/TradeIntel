# 政策—贸易关联包 B3：无统计关联时的公告原文事实卡

日期：2026-09-27。范围：已人工确认 `no_statistical_link` 的公告，不调用贸易查询或模型，只保存和读回公告事实卡。此步未接网页。

## 实现

- 服务端在生成前后重建关联确认单，重新核对已启用原文版本、候选字段、逐字引文和人工判断摘要。确认内容变化时旧准备单失效。
- 事实卡包含 13 个已确认字段的 `known/unknown/conflict`、原文引文与未知理由，以及不能从月度商品表核对的邮寄方式、单件价值、企业资格或用途条件。原公告税率只标原文事实，不当作现行税率。
- 固定 `context_type=source_only`、`chart_status=not_available`、`monthly=[]`、`policy_amount_status=not_determined`；来源与金额都不从贸易数据库推断。快照沿用报告摘要存储，模型解释入口拒绝该类型。

## 验证和边界

- 邮政、药品两种合成案例可生成、保存并读回事实卡；反例验证了请求月份、硬转国家图、旧确认单、模型调用均拒绝。关联与旧贸易报告/网页相关回归共 73 项通过，`git diff --check` 通过。
- 仍属开发测试，不代表新公告的法律判断已正确；引文能在原文中找到，不等于人工对适用范围的解释已经独立验证。无模型 API、无 MySQL 写入、未提交推送。
- 包 B 后端三类新增输出（上层背景、国家背景、无图事实卡）现已具备，但空白页面录入、关联确认、报告显示、刷新/打印/双语和旧 R2 回归仍待接线。
