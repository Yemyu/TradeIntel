## 实施边界

- 总输出与正文分别计限；正文采用固定估算器、usage缺失明确未知，不伪称精确计费。
- 冻结同时校验max_tokens、thinking、reasoning_effort、正文预算，并绑定评分/审阅代码。
- 发送前一次读取消息和主机报告、核验该批字节，再使用内存中的消息，不重新从可变文件读取。
- 原子领取内检查前题审阅；同配置四题绑定同一冻结，不能中途换参数。真实API账本固定项目目录，改输出路径不能重跑。
- 审阅逐项保留结构、事实、回应需求、解释价值四项结论及理由。继续后题前重验前题原答，变动即停止。
- 正式调用逐题；重大语义错误/格式失败/超预算/未知结果停止该配置。禁止无限调题和选择性重试。
