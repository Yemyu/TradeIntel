# 2026-09-15 审阅与导出页面离线回归

## 阶段目标

验证 AI 解释必须经过逐条人工决定和事实核对；完整审阅可以生成“只含采纳项”的本地审阅稿，但任何待修改项都必须阻止导出。

## 环境与安全边界

- 执行模型：Luna 最高。
- 页面：`http://127.0.0.1:8766/review/interpretation?...`，由 `scripts/serve_browser_qa.py --seed-review` 提供离线 fixture。
- 仅使用临时输出目录和固定 fixture 模型；没有真实 API key、外网请求、Docker 或 MySQL 写入。

## 验收步骤与结果

1. 空表单点击保存，页面拒绝并提示必须填写审阅者、每条决定和理由。
2. 为三条解释选择“采纳”、填写逐条理由并勾选“已对照来源资料”，保存确认后页面显示“审阅状态：recorded；审阅版本：1”，提供“人工审阅稿”链接。
3. 读取导出端点，返回稿件标题为“人工审阅稿（v2，待进一步复核）”，内容只含被选择的素材，并保留“不是案例发布批准/不构成因果结论”等边界。
4. 进入修订，令第二条为“需要修改”，填写修订原因并保存；页面显示“审阅版本：2”及“不满足审阅稿导出条件”。
5. 再次读取同一导出端点返回 HTTP 409，并提示审阅稿尚未具备导出条件；没有绕过待修改项。
6. 浏览器控制台错误/警告：0 条。

## 结论

审阅与导出门槛在页面、HTTP 路由和本地文件层均保持一致：AI 只能产生待审阅素材，人工决定绑定具体回答指纹；修订会保留历史，待修改项会撤销导出资格，且不会改变案例发布状态。
