# 贸易 Agent 本地页面离线验收（2026-09-29）

## 范围

在独立的本地浏览器标签中，以临时脚本模型驱动真实 `/preview/` 页面及本地 HTTP 路由。脚本模型只按预设问题选择商品、查询方向和工具，故本次证明页面—服务端—报告链路与服务器边界，不衡量真实模型理解能力。未调用收费模型、未写 MySQL、未提交或推送。

## 页面实测

| 输入/操作 | 页面观察 | 判定 |
| --- | --- | --- |
| “上个月美国大豆进口额是多少？” | 明确提示缺少 2026-08 已核验数据，最新可用为 2026-07；未生成报告 | 不能偷换成最新可用月，通过 |
| “最近美国大豆油进口有什么变化？” | 报告锁定豆油 `1507`，2026-07 进口消费额 27,503,913 美元，较 2026-06 减少 3,340,380 美元 | 未误用大豆 `1201`，通过 |
| 新对话：“最近美国大豆进口有什么变化？” | 报告锁定大豆 `1201`，2026-07 进口消费额 46,041,287 美元，较 2026-06 增加 13,163,460 美元 | 通过 |
| 同会话追问：“出口呢？” | 保留大豆 `1201` 范围并切到美国出口；2026-07 FAS 总额 889,379,312 美元，较 2026-06 减少 3,500,150 美元 | 通过 |
| 刷新报告及工作台 | 出口报告金额、进口与出口两轮对话均恢复 | 通过 |

脚本模型在每次 `finish` 都故意写入“这证明政策已经奏效。”，公开报告与对话均只显示程序根据已发布数据生成的摘要，没有发布这句无据因果判断。这是硬边界验证，不表示真实模型能正确分析政策。

## 页面文案与回归

工作台原先仍写“模型解释请对照图表核查”，与现在的程序摘要机制不一致。已改为“助手会用本机配置的模型选择查询步骤，可能产生费用；数据摘要由程序生成。”并同步英文。浏览器刷新后核对新文案；`node --test tests/trade_explanation_ui.test.cjs tests/trade_agent_ui.test.cjs` 为 16/16，随后全套 Node 30/30、`git diff --check` 通过。
