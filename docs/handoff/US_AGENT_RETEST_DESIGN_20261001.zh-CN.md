# 美国版 Agent：修复后有限实测方案

日期：2026-10-01。设计版本：v1。状态：设计完成，执行器、参考文件、代码/数据冻结与政策前置尚未完成，真实调用未放行。

本方案接续 `US_PORTFOLIO_EVAL_PREPARATION_20261001.zh-CN.md`。目标是检查当前修复是否真的改善实际工具使用，不扩国家、不重做前端、不修改旧成绩。它不是全模型排行榜，也不是12轮就能证明普遍可靠的盲测。

## 1. 本轮要回答什么

假设：现行工具Agent能在有限预算内，把自然问题转换为正确商品、方向、伙伴和月份，完成报告与追问；缺数据和不支持范围时不交错报告。政策检索必须找到登记的真实原文及完整依赖，而非只拿到标题。

对照分开保留：

- 旧真实API开发记录：错误类型与修复前行为参考，不直接计算前后准确率差，因为代码、日期、场景不完全相同。
- 独立CSV参考与固定政策原文：核数和引用的标准，不由Agent生成。
- 现有脚本模型回归：工程通路对照，不算真实模型成绩。

只跑一个实际API模型、一个推理设置、每轮一次尝试。聊天窗口手答可以另存诊断，但不能替代这条API/工具/存档链的结果。

## 2. 已核实的实现事实

- 入口是 `TradeResearchAgent(data_root, code_root, model, today=..., max_rounds=..., max_tools=...).turn(question, request_id, session_id)`。`code_root`也承载政策目录，隔离会话时必须同时准备政策输入。
- 网页目前用默认每用户轮最多6次模型响应、12次工具；产品请求 `max_tokens=8192`。本批保持这些值，不拿旧pilot的4/8/4096冒称当前网页效果。
- 公开金额、图表、摘要和因果边界说明由程序生成；本批测模型工具选择与产品完成度，不测自由报告写作/经济解释能力。
- 现行trace只有工具名与状态，不能直接判断错误参数。新评测需要记录原始工具决策，但不保存私有推理正文。
- 旧pilot硬编码题目、2026-09-29日期、数据版本与旧账本；旧followup会追加旧会话。禁止直接调用旧preflight/run_live完成本批。
- 当前主根 `.local/announcement-docs/`只有停用测试记录，没有可检索的已启用官方公告。固定展示报告及 `policy_corpus.json`不会自动进入Agent政策检索。这是政策实测前置未接好，不是一次新模型失败。

## 3. 固定场景：12个用户轮，7个会话

系统日历固定 `2026-10-01`，独立数据包最新月 `2026-07`。“最近”不是日历上月。该冻结日期只用于可复现验收，不假装网站实时更新。

同一会话只沿表内顺序执行；全部用户原话事前固定，不给模型附加答案或编码。R组是已见失败类型回归；T组是未用于当前Agent修复的场景扩展，商品可能在旧数据分析中出现，不叫真正盲测；P组是已见官方公告的检索联动，不是陌生公告理解。

R01/R02/R03/R04/P01“最近”的可接受窗口：以2026-07结束，连续且在当前覆盖内，至少含2026-06和07；精确窗口与所有图表值必须一致。不得事后按某个模型选的窗口改单一答案。T01/T02/T04窗口精确固定。R04的两方向均须满足窗口与口径要求。

正常任务9轮：R01—R04、T01—T04、P01。边界任务3轮：R05、R06、P02。若首轮失败，同会话后续标 `not_run_prerequisite`，不拼接别人已有成功会话或塞入正确scope来救分母。各会话独立，其余会话可继续，除非触发整批停止门。

中文天然橡胶/可可豆/葡萄酒目前不是小型直接同义词表中的条目。模型可自行使用英文官方名称检索后查数，允许发现相关候选后重新搜索；错误候选不得代查。仅提出不必要的商品澄清记“安全但未完成”，不能当完全通过；不在实测前为这四轮补答案别名。

## 4. 政策正向题的前置，不能跳过

P01/P02只使用一份既有CBP公告，不增加全网搜索。已存原文：`data/raw/policy/review2025/cbp-63577329.html`，SHA256 `be5b9ba0e9091e171731c878ed4d7e1bf57d210565631883212787982fe9f6f9`。既有语料位于 `data/processed/policy_exposure/policy_corpus.json`；依赖映射见 `scripts/run_policy_search_eval.py:build_eval_store`，是已见开发资料。

离线实施时：

1. 核对原HTML、来源元数据、正文片段及段落标识；在新评测root准备一份独立政策库，不修改主根或启用旧停用测试记录。
2. 依赖必须逐字可核：p8生效/入境事件；p12钨原产地、税率与三个子目/商品条件。保留原始source_id，不能把p12重编号成别的来源。p9硅税号不是钨范围。
3. 例外未载明的判断仅针对已登记语料范围，不能推广成全部法规无例外；若既有映射与完整原文不一致，停止P组准备并交Sol Max判断，不用删条件降预算。

5. 离线核验能返回p12命中与p8/相关依赖，引用稳定、读回正文/hash一致，默认不污染2018旧政策；保存来源与确认记录摘要。

## 5. 独立参考与防泄漏

数据根：`tmp/handoff-runs/trade-demo-data-20260925`；只读，不补采、不重建目录。核验进口/出口/分类版本及实际文件摘要，而非只核Git提交号：当前HEAD `b639f2bc04b7a65270512a08190a632d8d58d60a`加未提交工作区才是现行代码。

参考生成器必须独立用CSV筛选/加总，不调用Agent、query_trade、report builder或repository.query得到“标准答案”：

- 进口按hts10前缀，金额分别取all_origin/china的消费进口字段，仅纳入observed=1；没有观测为null，保留细码观测/缺失计数。部分观测须继承真实覆盖说明，不冒充全税号完整额。
- 出口按scheduleb10前缀，全部伙伴合计；中国筛partner_code=5700，取total_export_fas_usd。无行是未知，有已观测记录且和为0才是零。
- 逐月整数美元核对；只有实际报告窗口各月均有可用观测时，才把加总称完整期间总额，否则保留覆盖限制/未知，不把缺月补零。月变化为本月减前月；只有两期均可用时给出数值。若报告带百分比，零分母/未知保持未知，舍入按事前固定规则，不额外要求百分比才能通过。

## 6. 两套评分与公开表

每轮保存以下结果，不把所有情况压成一个模糊准确率：

**产品层**：正常任务完全完成/安全未完成/不安全输出/未运行；范围、逐月数字、变化、报告存档读回、引用/条件分别核。边界任务看是否诚实说明，不返回替代范围，不编数据；它们不进入正常业务完成率分母。

**模型层**：有至少一次实际供应商响应的用户轮才进入n，预算耗尽或未完成的已响应轮仍保留，不能只挑完成轮做分母。看原始工具决策：商品/方向/伙伴/窗口/finish选择正确，错误查询企图是否发生，是否纠正、是否有不必要澄清。搜索绕路、不同合理工具顺序不是错误；覆盖或搜索返回不足时合理澄清单列。原始工具参数明显错但被程序拦，模型该轮不能计完全正确。正确请求缺失月份后工具报告不足不等于错月份。没有实际模型响应的程序预检为N/A，不按模型答对算；纯传输失败无响应单列，不归为模型答错。

归因至少分：`program_precheck`、`model_clarification`、`model_action_correct`、`model_action_corrected_after_guard`、`program_guard_after_wrong_action`、`budget_stop`、`transport_unknown`。现行终态不能直接推出归因，必须结合录制的原始工具调用、工具反馈与最终记录，无法确定就标unknown。

金额和固定因果警示正确不能证明模型会算数或理解因果；当前不测开放式经济原因、推荐或自由撰写政策解释。旧闲置explanation即使被忽略，也可记录为协议偏离，但不冒称已影响公开报告。

第一版展示门（不是普遍可靠性承诺）：

## 7. 首批模型与预算

首批：DeepSeek官方 `https://api.deepseek.com`，请求型号 `deepseek-flash`，`thinking={type:enabled}`、`reasoning_effort=high`，`max_tokens=8192`，不并发、不自动重试。2026-10-01官方说明该请求型号对应DeepSeek-V4.1-Flash；仍记录每次实际response.model与运行当天官方版本说明，不把请求别名当永久快照。其他模型不在这一批。

沿用实际产品适配器 `create_trade_agent_model`，不改其提示/工具schema；思考回传只在内存中，完整预算核查要涵盖回传后payload。temperature字段即使现有配置为0，在此思考模式也不代表确定性，不宣称固定种子重复结果。

预算按用户轮与供应商请求区分：

| 项目 | 上限/行为 |
| --- | --- |
| 用户轮 | 12，7会话，每轮一次领取；不自动重测 |
| 单轮模型/工具 | 6次模型complete、12次工具，保持产品默认 |
| 整批模型请求 | 最多48次；达到上限保留not_run，不扩大额度 |
| 单请求输出 | max_tokens=8192，包含思考生成的供应商输出上限按API定义记录 |
| 单请求输入 | 所有轮实际HTTP JSON body ≤65,536 bytes；不是token数，不仅查首轮 |
| 单请求超时 | 使用配置值且不超过90秒；不通过重试获得更长总时长 |
| 全批时间 | 累计120分钟墙钟；每次发送前检查，已在途最多等本次HTTP超时；不杀请求冒称0费用 |
| 金额 | 拟执行预算不超过2美元；发送当天核账户币种/价格并锁许可。输入字节不能保证精确token或账单，未获得收费许可前不live |

当前官方美元峰值单价为Flash未缓存输入0.30美元/百万token、输出1.20美元/百万token；只作规划依据。执行前用当天最高适用价，缓存优惠不预先计入。按48请求×8192，输出配置额度最多393,216 token；输入按真实返回usage核算，缺失为unknown。48×64KiB是传输字节上限，不冒称严格token或金额上限。金额门须在每次发送前为下一次请求保守预留，价格/币种无法确定或无法满足预算就停止，不借免费余额放宽次数。

程序账本中的估算费用与服务商实际扣费分开。HTTP错误、超时或未知结果可能收费；保留预留额度，停批核对，不按0计也不自动重发。除明确免费/赠送扣减经核对外，不声称花费为0。服务商若没有可验证的token预估/金额硬限，明确金额为受控预算目标而非绝对账单保证；不凭byte/4换算伪造硬上限。

官方依据（已打开核对，运行当天再核）：[型号与价格](https://api-docs.deepseek.com/quick_start/pricing/)、[思考与工具回传](https://api-docs.deepseek.com/guides/thinking_mode/)、[max_tokens及API参数](https://api-docs.deepseek.com/api/create-chat-completion/)。
