# 阶段 A：政策范围与贸易暴露报告实施契约

日期：2026-09-14；状态：方法与首个开发案例已选定，2026-07 单月已下载、校验并生成首份确定性暴露报告；多月窗口、AI 入口和网页仍未完成。产品目标以 [长上下文](../PROJECT_CONTEXT_REFERENCE.zh-CN.md) 为准。

## 用户要得到什么

“这份钨制品、硅片和多晶硅关税调整涉及哪些商品？按最新可得的美国进口数据，各类商品的进口规模、中国份额和主要来源分别是什么？给我可核查的简报。”

回答帮助分析人员确定优先调查的商品和依赖，不估计政策造成的损失、不提供现行报关税率。

## 选题与真实来源

首个开发案例为 2024 年 12 月公布、2025 年生效的五税号 Section 301 调整。它是项目未接入的新案例，不是 2026 年刚发布的新闻。选择理由：有清晰商品附件、多个税率组、具有供应来源分析用途；可以检验从原文到数据的完整连接，而不依赖历史 List 1 固定答案。此案例不能单独证明系统已支持所有新政策。

- [USTR 公告](https://ustr.gov/about-us/policy-offices/press-office/press-releases/2024/december/ustr-increases-tariffs-under-section-301-tungsten-products-wafers-and-polysilicon-concluding)：2024-12-11。
- [Federal Register 正文与 Annex A/B](https://www.federalregister.gov/documents/2024/12/16/2024-29462/notice-of-modification-chinas-acts-policies-and-practices-related-to-technology-transfer)：2024-12-16，文件 2024-29462；[USTR 官方 PDF](https://ustr.gov/sites/default/files/Section%20301%20Tungsten.pdf) 留待下载核对。
- [CBP 实施说明](https://content.govdelivery.com/accounts/USDHSCBP/bulletins/3ca1cf1)：2024-12-31。

附件的五个 HTS8：28046100、38180000（该项 Section 301 税率 50%）；81019400、81019910、81019980（25%），实施日期 2025-01-01。这些数字不是相对上一税率的增幅，也不是全部叠加后的总税率。本文尚未验证各代码在后续统计版本的连续性或当前豁免。

正文、Annex B 对具体时区存在 standard/daylight 文本差异；CBP 使用 EST。第一版只输出共同确认的生效日期；保留原文差异说明，不自行消除冲突或为此重新开启多轮时刻翻译实验。同一文件的医疗手套技术修正不混入这五项商品范围。

以“该次公告列明税号对应的贸易规模”命名金额，不声称等于实际征税基数。后续叠加税、豁免、其他政策可能改变法律适用；未建模的部分明确列出。

已验证的首张结果见 [2026-07 中文暴露报告](../../data/processed/policy_exposure/report_2026_07.zh-CN.md) 与其 [JSON](../../data/processed/policy_exposure/report_2026_07.json)。五项税号全部出现；美国消费进口合计 $193,774,871，中国原产 $10,251,657，占 5.29%。这些是程序从明细逐行汇总的结果，不是模型生成的数字。

## 数据获取与截止日

数据源沿用 Census 月度美国消费进口口径。[变量文档](https://api.census.gov/data/timeseries/intltrade/imports/hs/variables.html) 区分 CON_VAL_MO、GEN_VAL_MO 与年累计值，三者不能混用。商品细目优先 HTS10，不扩大成 HS6。

[官方发布日历](https://www.census.gov/foreign-trade/schedule.html) 显示 2026-07 于 09-03 发布，2026-08 计划 10-06 发布。因此截至本阶段，候选最新月是 2026-07，但必须取得并验证商品明细后才称数据已准备好。初始目标窗口 2025-01—2026-07，用于 2026 年同期累计与 2025 年同期比较；不为因果分析向前补多年。

本地无密钥 API 探测返回 HTML `Missing Key`，不是 JSON 数据，未得到金额。不要向用户索要 GLM 密钥解决 Census 认证。优先沿用无需新增凭据的官方月度 ZIP 路线；API 仅在有相应授权配置时可选。先检验最新单月 ZIP、字段布局、记录年月、国家表与统计口径，再扩到其余月份；原包保留。HTTP 200/HEAD 成功不等于完整数据验收。

已完成只读 HEAD 探测：[2026-07 ZIP](https://www.census.gov/trade/downloads/2026/Merch/im_m/IMDB2607.ZIP) 返回 HTTP 200、application/zip，Last-Modified 为 2026-09-03；该包已下载并通过解析，详见下方报告。2025-01 ZIP 的 HTTP 下载可完成，但四次完整包校验均发现缺少旧布局成员 `IMP_DETL.TXT`，临时文件已删除，未进入数据目录；这说明跨年份格式必须重新确认，不能批量继续。

每个来源保存 URL、抓取时间、SHA-256、统计月、来源修订标识（可得时）；与 FT900 公布日区分。报告按当前取得的统计版本展示，不宣称历史发布当日回测。

## 输入输出契约

- policy_record：id、公告/出版/生效日期、原产国、措施类型、来源、法律范围限制。
- scope_mapping：原文 HTS8、说明、来源位置、统计期、有效 HTS10、映射依据、匹配状态。相同前缀但定义变化需审阅；未查编码表不能把“没贸易行”写成“税号无效”。
- trade_rows：month、hts10、origin_code、consumption_value_usd、source_id。每键唯一；重复统计汇总层不得叠加到明细。
- metrics：五税号分别及合计的中国/世界金额、中国在美国该商品进口中的份额、主要来源国及份额、同月/同年累计对比。全部是美元名义值，非数量变化；首版不计算价格或跨不同单位总数量。
- coverage：所需月、已验证月、缺失/无记录、未映射代码、法律覆盖限制。零分母返回不可计算；缺少整月不得静默补零。世界总额与各真实来源汇总的差异单列，不把区域合计重复相加。
- report：政策事实、贸易表格、关注项及排序依据、可能路径、未知、数据截止日和引用。不得将支持/反对政策的公众意见当作已验证经济事实。

只凭美国进口数据能算中国在美国进口中的份额，不能算中国出口对美国的依赖。后者需要中国对全球出口的另一分母，首版不做。

## 验收和停止条件

1. 单月文件结构/完整性通过后再批量；最新明细无法取得则准确报告缺口，不用 2018 年数据替代。
2. 五项范围逐项有来源，映射缺口显式暴露；金额独立复算到整数美元一致，份额按两位小数允许 0.005 个百分点舍入差。
3. 合成测试覆盖错年份、HS6 扩大范围、重复键、缺月、零分母和国家汇总重复。测试只证明工程行为。
4. 数据工具稳定后冻结一次开发演示：同一模型主流程最多两次调用（规划、回答），直接问模型基准一次；合计最多三次尝试、每次输出上限 4096 tokens、单次超时 180 秒，不自动重试。模型配置、输入、成本和首次结果留档；不得把该开发案例当保留测试。
5. 主流程拿原始证据和计算结果，不能拿人工参考答案；直接模型拿同一用户任务。因输入资源不同，只作产品工作流对比，不称 RAG 单因素消融。后来保留案例另冻结，不现在扩大题库。
6. 任务成功须交付正确范围、可复算数字和受引用支持的报告；安全拒答不算正向成功。参考值可由助手复核，但不称独立人工金标。

## 学习参考答案

**为什么政策五个税号，数据库却用十位？** 政策规定八位类别，贸易统计在更细的十位记录；要把有效细目正确归到政策类别，不能随便截成六位扩大范围。

**这轮 AI 真正做什么？** 理解用户范围，选择已登记的政策资源和计算工具，再依据结果解释；税号和金额不能由它自由猜测。

**现在取得了哪些金额？** 2026-07 已有中文报告；2025-01 也已完成五税号提取。它们是数据库汇总结果，不是 AI 猜测；其余月份尚缺，不能宣布已完成多月同比分析。
