## 2. 不可默默改变的目标

贸易政策AI研究助手：问题 → 官方条款 → 商品范围 → 真实贸易数据及计算 → 有依据的解释与未知 → 可核查中文研究初稿 → 后续资源及报告更新。

数据库不是只为调通AI：它提供实际贸易规模、来源份额、商品差异及可复算证据。AI应解释这些观察的意义，不是只改写表格或泛泛要求继续调查。

T1当前范围是已登记政策单月结构解读（中国原产金额、中国来源占比、两者对照）。原目标仍包括T2新政策候选接入及受控更新；19个月案例不是产品全部完成。
