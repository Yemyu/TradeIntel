# G2唯一修订决策：指标解释边界与连续预算

## 决策和假设

仅针对首次development B的严重越界：用中国来源占比推断全球供应多元化。给B/C共同业务输入增加metric_limits，明确China share不能识别其他来源分布、多元化、国内供应或可替代性。假设是明示指标不可识别范围能减少该推断；没有预先声称有效。

这不是模型训练，不增加HHI、因果或新数据方向。原政策条款、数字、观察、限制、问题/月份、独立参考文件和正式采纳门槛不变。新边界是一般指标含义说明，不是正式题的答案。冻结包保留完整恢复验证。

## 公平对照与预算

旧B已失败且停止，不重新请求B。唯一修订首先运行development C（这是第一次C调用，不是通过改写旧答案获胜）；旧B与新C提示不相同，绝不能作公平胜负对照。正式四题的B/C均使用相同新业务说明，仍按原门槛逐题评价。

预算为旧1 + 新开发C1 + 正式B/C8 + 规划2 = 12。没有新增预算。新计划只有11槽位，本地slot0对应旧计划development C；primary_all C移到新slot2。运行脚本按任务身份保留网页槽，不能CLI绕过。

旧包tmp/g2-preparation-20260915-runner及其state.json原失败/stop不变。正式关联的子包为tmp/g2-revision1-ready-20260915；子manifest记录父manifest和父state哈希、继承1次请求。父账本增加revision-successor.json单一关联标记（并未改写stop）。第二个子包登记被拒绝，子包不能再生下一代修订。

每次调用前检查父记录未变、修订编号仅1、继承次数和剩余任务顺序。status显示总上限12、累计已用1、剩余11，而不是显示一个新的12次余额。本地机制不是防恶意手动删文件的服务端收费系统，禁止人为重置账本。

## 离线结果

13项相关测试通过：修订继承预算、原失败不变、第二子包拒绝、slot11越界拒绝、B/C业务输入相同、所有资料能恢复、参考文件字节不变，加上原账本/视图/传输回归。数学反例测试验证“中国均占5%”时，其余一国95%与五国各19%对应不同的整体集中程度；仅作定义反例，不作为新的产品统计功能。
