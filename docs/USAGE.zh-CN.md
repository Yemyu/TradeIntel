# 使用入口

TradeIntel通过对话选择商品、贸易查询和政策检索工具，由程序核对范围、计算金额并生成图表报告。当前使用方法集中在以下入口：

- [本地运行](LOCAL_RUN.zh-CN.md)：准备源码与数据、启动服务、配置模型、提问和读取报告。
- [当前功能](CURRENT_PRODUCT.zh-CN.md)：功能、使用示例、数据范围与限制。
- [公开展示](PUBLIC_SHOWCASE.zh-CN.md)：四个已保存案例和报告阅读。
- [数据说明](../data/README.zh-CN.md)：124个数据文件、月份、统计口径、下载与核验。
- [模型测试](MODEL_SELECTION.zh-CN.md)：已测试配置、任务结果及限制。

英文安装与使用说明见 [Local guide](LOCAL_RUN.md)。
