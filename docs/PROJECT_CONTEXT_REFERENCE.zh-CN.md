# TradeIntel — 项目上下文

更新：2026-10-02。本文保存当前定位、已验证状态和继续工作的边界，不累积过期任务。

## 项目定位

作品展示与本地自部署的美国商品贸易研究助手，不是商业云服务，也不是每日新闻简报。核心流程是自然语言提问 → 商品检索 → 贸易或政策工具 → 图表报告 → 同一会话追问。AI实际选择工具，金额和报告计算由程序完成。

公开[中文网站](https://yemyu.github.io/TradeIntel/?lang=zh)和[英文网站](https://yemyu.github.io/TradeIntel/?lang=en)为同一套只读页面，提供四个案例。本地用户自配模型API；不买云服务器，日常查询无需MySQL。正式分支为main，候选分支目前仍在。

## 数据与功能

- 美国进口：2016-01—2018-05、2025-01—2026-07，共48个月，不连续。
- 美国出口：2025-08—2026-07，连续12个月。
- 商品按已发布的官方目录检索，不限于演示用的五种材料。
- 伙伴仅全部来源／目的地汇总或中国；中国是美国统计中的伙伴，不是中国海关数据库。
- 政策检索仅覆盖本地登记、启用的文档，使用关键词/BM25并补齐相关条件，不是自由联网搜索。
- 进口消费额与出口FAS分别展示，不混算贸易差额；不作政策因果认定或投资指令。
