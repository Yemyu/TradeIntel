# 固定证据、最小解释：离线原型及下阶段边界

## 为什么不是再写一遍提示词

旧C本来就禁止重写数字，但模型仍违反，不能把这次设计描述为首次想到该规则。真正变化是移除模型选择观察、fact_ids、policy_refs、limitation_ids、catalog摘要的责任。程序从已验证catalog建立固定slot；每个slot含观察绑定事实、同商品上下文事实及登记政策引用。模型只输出各slot解释，加一项缺证与研究问题。

引用代表该解释的输入上下文，不代表原文已证明推论；禁止把自动挂引用包装成“已验证有据”。全部解释仍待人工语义审阅。数值由A3展示，模型数字/比例/网址复述被拒绝，中文改写和无数字的错误仍可能漏检。

## 仍须处理的实际问题

原catalog局限包含“公告已确认的2/18”措辞，可能诱发把贸易缺口误认为政策缺口。不能只责怪模型：应先追溯新公告报告中的范围说明，区分已登记政策范围与本次贸易覆盖，修改生成源和测试，再建立新包；旧包保持历史原样。

新协议尚未接provider、持久审阅或页面。不能拿它直接送原C执行器（两者响应结构不同）。现有A3与产品链不替换，不新增数据库/Agent框架。
