# Phase 12i：现在这些商品到底能不能继续研究？

## 用一句话说

我们把之前更细的十位商品代码合并到政策清单使用的八位代码，再检查每个商品在政策前29个月是不是经常有中国进口记录。

## “通过活跃度”是什么意思？

不是说它一定是好对照，也不是说政策有效果。它只表示：这个商品在至少24个月有正的中国进口金额，数据足够连续，可以进入下一轮比较。

如果一个月没有记录，我们保留一个标记，告诉后续程序“这个月没有观察到”。不能偷偷把它当成零，因为没有记录可能是编码、报告或贸易出现方式造成的。

## 结果怎么读？

3332工业机械类别的元数据层面有56个处理候选和56个对照候选；经过活跃度检查后，剩下38个处理和24个对照，共62个主路线候选。它是最值得优先研究的类别，但62个商品还没有配对，也没有证明趋势相似。

3336没有可用对照，所以不能直接用这条路线研究它。其他行业有的处理多、对照少，有的相反，不能为了数量好看把行业混在一起。

## 为什么不马上做匹配？

因为匹配前还要写清楚三件事：

1. 谁算处理、谁算对照，政策可能通过同一个大类间接影响谁；
2. 同一大类里的多个八位商品不能当成完全独立的样本；
3. 什么结果算通过，什么结果必须停止。

这些规则如果等看到政策后结果才决定，就会变成“先看答案再定标准”。所以下一步先冻结协议，再运行计算。

## 和AI有什么关系？

这一步主要是数据和经济研究，不是训练模型。它为未来AI助手提供更可靠的查询粒度：AI可以回答“某个八位商品政策前每月金额是多少、来源是什么”，但仍必须把“描述性变化”和“因果结论”分开。
