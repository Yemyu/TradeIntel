# Phase 32：让AI把你的要求逐项列出来

本轮接上了逐项需求清单。例如你同时问“关税什么时候生效、税率是多少，再查两个月进口金额”，预览会分别展示两个政策要求和一个贸易要求。报告也会保留对应记录，让你知道哪些执行了、哪些还要核对。

## 现在怎样处理遗漏

AI提出清单时，必须给出每段内容在原问题里的位置。程序核对原文有没有整段被漏掉。如果你追加“另外列出中国进口份额”，而模型完全没把这段放进清单，程序会阻止继续执行。

如果模型把这一项列为“暂不支持”，预览会显示原文并暂停整份计划。当前统一执行入口只接受一组国家、月份、商品和金额指标；它不会自动把份额换成金额，也不会默默只完成其中一部分。

## 你需要理解的两个区别

**把文字列全，是否等于理解正确？** 不等于。AI可能把一个真实要求误标成“背景”。所以预览连背景与限制也展示出来，供你核对。后续真实评测需要专门检查这些误分类，不能只数清单条数。

**每项旁边写执行完成，是否等于回答正确？** 程序执行完成表示对应的查询/计算完成。政策草稿仍需要核对是不是回答了每个问题、引用能否支持内容；报告会保留“语义待核对”的提示。
