# 更新为什么有用，以及本次做到了哪里

你上个月已经拿到一份报告，这个月再打开助手，最有价值的问题就是：“上次之后，有什么新数据？以前的数字有没有改？”

本次用已有真实月表演示从18个月到19个月的更新。两份快照都是现在构造的，所以这是流程回放，没有宣称找回六月当时的数据库。政策是否在网上发生新变化，本次也没有检查。

## 实际结果

- 新增2026年7月，原18个月没有修订，本地政策登记没有改变。
- 七月五税号美国全部来源消费进口额193,774,871美元，中国原产10,251,657美元，占5.29%。
- 已审阅编码转移的38180000：六月192,915,687美元，七月178,183,620美元，减少14,732,067美元，即7.64%。这个范围聚合全部后继编码，避免把编码拆分误算为增长。
- 这说明名义进口金额变化；价格和数量都可能影响金额。要解释原因，需要继续补查证据。

## 你需要理解的问题与参考答案

**新增和修订有什么区别？** 新增是以前没有七月，现在有了。修订是六月原来记100，现在记105。两者必须分开，否则报告会把官方修订当成新的贸易变化。

**数字不变，也算更新吗？** 来源文件换了，仍记录版本变化并要求审阅。金额恰好相同不代表文件或商品含义完全相同。

**这一步AI做了什么？** 当前差异由程序计算，API调用为零。它为后续AI提供明确的“新增月份、修订项、可比较金额”证据。AI可据此组织简报、选择调查方向；检测文件变化和加总金额交给程序更可靠。

**这就实现自动更新了吗？** 还没有。09-14后续已补齐实际数据副本、新案例工具/AI报告统一读取副本、候选差异重算和失败后继续查询旧数据。真实数据隔离恢复验证通过。联网采集和调度尚未接通，见 [版本审查](version-binding-review.zh-CN.md)。

运行：`.venv/bin/python scripts/replay_exposure_update.py --output tmp/一个新的输出目录`。输出包含两个快照、差异JSON和中文报告，已有目录不会覆盖。
