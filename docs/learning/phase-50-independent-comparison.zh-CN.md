# Phase 50：怎样知道AI是真的做对了

> 后续复审：本页说明检查目标。首轮接线仍有缺口，已发现的错误放行得到修复；最新进度和通俗解释见[Phase 51](phase-51-review-gates.zh-CN.md)。配置相等尚不能证明真实发送相同。

假设你问“中国9月和10月进口额比较”。AI误查成其他国家，然后把其他国家的数字算得完全正确。只查算术会觉得它通过；我们现在补的独立查询条件会告诉我们：数字能对上，但查错对象了。

因此，在AI看到题目前，我们先自己写好“应该查中国、哪几个月、什么商品、怎么比较”。这份检查答案留给评分程序，不能拿去帮AI修正参数。这样才能知道AI自己理解得怎么样。

政策部分则比较同一个问题的两份回答：一份给官方文档，一份不给。两组使用同一模型和输出长度。之后按相同事实逐项检查，同时检查它有没有多编内容。

## 你需要理解的几个例子

| 回答 | 如何评 |
|---|---|
| “附加税率25%” | 核对官方来源后可判答对 |
| “附加税率不是25%” | 包含关键词，但结论相反 |
| “附加税率百分之二十五” | 写法不同，意思可以正确 |
| “我不知道税率” | 漏答，不能算答对，也不一定是胡编 |
| “税率25%，所以贸易下降全是关税造成” | 前半句可能对，后半句仍需拦截 |

现在这套规则已经接入离线运行器：贸易题会先保存独立基准再比较模型范围，政策题会比较两组配置并保存脱敏调用捕获；政策事实表会生成，但默认等待人工审核。没有训练GLM，也没有得到新的模型准确率。下一步由Astra复审接线，再决定是否扩充fixture和准备真实题前整链。
