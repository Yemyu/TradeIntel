# 如何查看这次真实研究结果

现有首页新增“查看最新真实结果”链接，地址为`/demo/research-review`。启动仍使用项目原有`scripts/run_web.py`，不需要重新提供API密钥；查看此页不会加载模型配置或调用模型。

页面分开展示：真实贸易规模、AI原话与逐项助手审阅、使用限制、原始JSON和完整来源资料包。两类商品为七月存档数据，不是实时刷新。第一条转运规避调查没有本次证据支持，不采纳为优先方向；第二条企业税负/合同限制有有限用途，仍未批准。

这次完成的是固定真实结果的只读交付，不是第二案例开放在线研究，也不是用户已能在网页选择任意政策。结构化运行仍是CLI实验入口，首页原查询仍只支持已启用案例。

构建脚本`build_research_review.py`只读取固定运行的白名单文件，校验模型回答、贸易证据及完整来源资料包哈希。审阅意见不写回原答案；原文以HTML转义后显示，不执行模型文本。HTTP只开放固定页面路径，不接受任意文件路径；网页本身没有JavaScript或模型调用。

18项聚焦测试通过，含真实记录生成、篡改拒绝、HTTP入口、路径越界拒绝、无凭证加载及相关业务回归；本轮零API。尚未浏览器视觉验收，之前本地文件访问被浏览器安全策略阻止，本轮未绕过该限制。没有把HTTP测试称为视觉验收。
