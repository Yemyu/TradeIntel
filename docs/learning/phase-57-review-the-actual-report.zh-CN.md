# Phase 57：审核的是不是你最后看到的那份报告？

## 这次做了什么？

过去审核主要看程序返回的数据对象。现在严格流程会把最终中文报告全文也交给审核者；审核提交要指出对应哪一份报告，最终文件必须保持一致。

## 你需要能解释的问题与参考答案

**问：为什么数据对象正确，还不能说报告正确？**

答：报告可能把数字、时间范围或解释写错。所以数据核对之外，还要审核最后给人看的文字。

**问：保存报告指纹就等于审过内容了吗？**

答：不是。指纹证明“是这份文件、没有换过”，不能证明里面的话正确。真实审核者仍需要读内容。

**问：现在密钥安全吗？**

答：本轮加了对当前配置密钥的精确检查，发现它在模型输入或回显中就停止。但不是所有隐私都能自动识别，所以仍不能把密钥写进题目、文档或项目代码。

**问：参考答案接下来怎么办？**

答：已经整理[中文复核表](policy-reference-review-handoff.zh-CN.md)，把两项答案、官方页码和适用限制放在一起。需要真实复核记录，不能由测试程序假装有人审过。

## 下一步

代码加固先收束，按现有规范整理一次可复现的离线演示和运行说明；然后完成实际参考复核，再决定真实测试批次。离线测试仍不是GLM准确率。
