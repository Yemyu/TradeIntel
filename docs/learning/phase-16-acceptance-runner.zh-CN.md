# Phase 16：让验收过程本身也可追溯

> 0073 审查更正：以下是历史阶段记录，不代表完整入口或正式验收已完成。旧24题已降为开发材料并禁止在线执行；当前状态见 [本轮中文解释](phase-17-integration-review.zh-CN.md)。

上一阶段已经准备了24道题。这一阶段解决另一个问题：如果运行到第7题断网，能不能知道前6题做了什么、第7题为什么停、后17题是不是根本没执行？

新运行器给每道题建立一条记录，并把模型调用分成两类：

- 规划调用：AI理解问题，最多24次；
- 回答调用：只有12道可执行题可能调用一次，最多12次。

所以整个批次上限是36次。需要澄清或越界的题不应该继续调用回答模型。

这类似数据库事务日志：不是只看最后有没有结果，而是记录哪些操作发生过、哪些没有发生、什么时候停止。运行器会保存停止原因，不会自动换模型、换Key或重试。

默认运行命令只做离线预检，结果是0次模型调用。真实执行必须显式开启，并固定模型、接口、超时和温度；这一步目前没有联网。

新增的ledger会拒绝重复题目、超预算题目和停止后的继续写入。它验证的是实验管理质量，不是AI语义准确率。
