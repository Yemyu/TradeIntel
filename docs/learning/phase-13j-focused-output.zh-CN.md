# Phase13j：回答要到点上，不是越长越专业

本轮新增两件东西，都没有调用模型：

1. 可选回答组织规则：先直接回答问题，再补必要适用范围；别主动加入无关时刻、编码和历史背景；批次与文件修订要分清。规则不包含本题日期、税率等参考答案。
2. 表述检查：遇到“上午12:01”“第一批修订”或可能多余的精确时刻，提示人工核对，不自动删改原答案。

5项针对性测试通过。三个旧真实回答完成离线检查，原始文字和成绩保留。新提示尚未真实测试，因此不能说已经让模型变准确。

## 你需要理解的问题：参考答案

### 为什么不直接把“上午12:01”替换成“凌晨00:01”？

因为替换规则并不知道每个上下文的真实时区和a.m./p.m.含义。发现可疑表达应回到引用原文确认；修改后的报告也必须说明经过审查，不能把修过的答案冒充模型原始表现。

### 检查没报错，是不是就对了？

不是。这里只能发现几个已知的可疑表达，不是完整事实检测器。日期、范围、引用是否支持以及有没有完整回答，仍需要检查。

### 让它短一点会不会漏掉条件？

所以规则不是“越短越好”，而是“直接回答+必要条件”。例如关税是否叠加是直接回答，哪些商品适用是必要范围；用户没问的历史过程则不必都列出来。

### 这些是不是训练？

不是，是应用提示和审查工具。模型参数没有更新，也没有新API调用。这些工具最终要服务于可核对的政策和贸易研究报告，而不是成为无限增加的答题规则。
