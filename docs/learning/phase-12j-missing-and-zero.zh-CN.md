# Phase 12j：没有记录和记录为零为什么要分开？

假设账本明确写了“这个月金额为0”，我们知道它报告的是零。另一种情况是账本根本没有这一条记录，此时需要弄清楚为什么没记录。两种情况如果都放一个0，后面的趋势计算会把未知的情况当成确定的下降。

上一步的数据用“金额0＋是否出现标记”保存这两种情况。这次改成更直观的方式：没记录就留空，明确记录为零才写0，同时保留说明标记。

3332工业机械仍有38个处理候选、24个对照候选；活跃度检查保留了原候选池约98.5%的处理组已观察金额和91.1%的对照组已观察金额。说明留下来的商品在这个候选范围内有一定经济规模。这些比例不能解释成覆盖了整个关税政策的九成。

这些商品的1,798个月度行中有2行没有中国记录。接下来先查清这2行，再判断怎么用于趋势比较。我们还确认了已有29个月细分表没有漏掉这些候选名下的其他观察子码，候选子码在整个政策前窗口都具有有效编码。

你现在看到的仍是实验前的数据核对。它帮助后面的计算有明确含义，没有训练GLM，也没有得到政策因果结论。原始压缩包继续保留，你不用操作。
