# Phase 29：让政策检索更准确地理解范围

“目前请分析2018年的关税”中的“目前”，是在说现在请你做事；“2018年的关税目前还有效吗”是在问现在的政策状态。以前程序只要看到“目前”就拒绝。本轮给第一类有限写法增加了入口处理，第二类仍需要现行资料。用户原话完整保留，AI回答仍围绕原问题。

这解释了为什么AI应用不仅是连接模型：检索之前的规则也可能把能回答的问题挡掉。排查失败时，需要知道是模型没理解，还是程序没有把合适的资料交给它。

## 重复证据为什么要合并

检索常会找到同一页相邻段落。向前后扩展后，两段可能包含重复正文。现在如果合在一起不超过单段长度限制，就合成一个窗口；来源页、位置、原片段和排名都保存下来，之后可以核对引用。

合并也有代价：片段变长。因此当前每段最多2400字符，总计7200字符；超过就保留分别窗口。本轮真实样例仍有1550重复字符，因为合并会超过限制。这是已实现功能的实际边界，不能把“加了合并功能”直接说成“已经节省调用成本”。
