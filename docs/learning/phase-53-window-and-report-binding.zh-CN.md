# Phase 53：检查AI有没有“比较错时间”，以及报告是不是审核过的那份

## 本轮在做什么？

例如我们要比较2018年8—12月与2017年同期，不能让AI自己选了几个别的月份后，程序只检查加法对不对。本轮让程序先从预先登记的规则取得月份，再检查报告。前后顺序颠倒、漏月，即使加法都算对，也不能通过。

另一件事是给审核前的报告保存“内容指纹”。审核完后，如果报告被修改，就必须停止，不能继续沿用原来的通过结论。

## 你需要能够解释的内容（附参考答案）

**问：为什么数字没算错，也可能答错？**

答：可能比较错了年份、国家或商品。题目范围正确与计算正确是两件事，都要检查。

**问：哈希是什么？**

答：可以把它理解为文件内容的指纹。内容变动后指纹通常会不同，用来发现审核后改动。但文件有指纹不代表里面说的事情是真的。

**问：为什么“审核通过”还要重新检查？**

答：仅有这四个字不够，还要有当时的回答、参考材料和逐项审核表。现在程序会根据保存的材料重新检查，避免只认一个通过标签。

**问：这是不是在提高AI准确率？**

答：本轮直接提高的是检查错误的能力，不是训练GLM，也没有增加真实模型成绩。只有后续用新问题调用模型，才知道它的实际正确率。
