# 回答接口简化：让模型只做需要它做的选择

2026-09-14。本轮没有API调用，没有推送。

## 改动

模型只需返回 `next_steps` 调查动作列表，不再重复固定事实ID；金额、份额和出处继续从已执行工具结果生成。

允许纯JSON或一个完整JSON代码块。只去掉代码块外壳，不从任意文字里截取JSON。围栏不完整、前后附加文字、重复字段、未知动作或夹带结论仍拒绝。解析及转换记录写入运行目录，原回答保留。

按查询范围提供动作：全部税号可选择阅读现有分项并确定深入方向；单税号不提供这个重复动作。来源分布与供需条件分别表示还需查询国别金额、补充产量库存等证据，不宣称这些调查已经执行。

## 对上次失败意味着什么

上次真实回答不仅有代码块，还在事实ID中附加数值，并为单税号选了含义不清的商品细分。现在代码块本身可兼容，但旧回复整体仍不合格。没有删掉其字段再伪装成通过，没有重新跑模型。测试覆盖该失败形式及可接受的新形式。

旧版严格固定事实ID仍可兼容读取，但不要求新模型返回，也不会用模型提供的数字替代数据。这是迁移兼容，不是将旧成绩改成成功。

## 你需要理解什么？

**为什么少一个字段反而更好？** 数字已经由程序算好，要求AI再复述编号没有新增价值，却多了出格式错的机会。应把模型任务放在选择查询、安排调查优先级上。

**是否放松了真实性要求？** 没有。兼容的是外壳格式，经济结论和数字没有因此放宽。

**51项测试通过代表AI变聪明了吗？** 不代表。它证明程序按新规则执行，新的真实模型表现仍需验证。本轮单税号程序报告已生成并保持正确金额及25.30%份额，明确标为程序生成。
