# Phase 12e：明明下载过，为什么又说缺数据？

## 你的记忆是对的

2016—2019年的48个月包全部处理过。记录中的压缩包大小合计约8.03 GB，处理后没有永久保留原包。

区别在于：**完整下载过，不等于完整明细一直保存在项目里。**

可以把原包想成超市每笔购物的小票。当时我们留下了“某些商品的逐项记录”和“全部商品按大类合计的账本”，随后删除了小票。现在想拆开另一个大类看里面每种商品，就没法从大类总金额倒推出小金额，需要重取原小票。

这不是你记错，也不是官网下载缺失。之前说“缺数据”太笼统，应当说“新分析需要的细分输出当初没有保存”。保留来源链接能帮助重取，但链接本身不能替代本地明细。

## 那以后会不会一直反复下载？

这次准备改变保留方式：把政策前每个月所有细商品的“中国金额、全部国家合计金额”留成紧凑表，再从它产生大类汇总。原始ZIP仍可在核验成功后删除。这样再换商品范围或汇总层级，就能重复利用这张表。

它不是完整保留原包全部内容：例如每个外国单独的细明细并不在这个紧凑表里。未来如果改变到这种需求，仍可能要另取数据。我们会明确边界，不再把“全商品汇总”说成“保存了全部数据”。

## 这次研究推进了什么？

17个候选都查了年度商品表：一个2016年7月才开始有效；两个2019年数量单位改变，但商品描述没变。数量单位变化不意味着美元金额一定不能比较，不过数量分析需要特别处理。

这些候选从纺织设备到投影仪都有，不能因为都属于机械行业就随便互相比。现在只是排查出错风险，不是训练AI提高准确率，也没有证明政策造成了多少变化。
