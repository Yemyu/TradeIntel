# Phase 38：让模型按程序要求交卷

这次只修正了一处指令：“直接回答”应当写在JSON的主张字段里，不能先写一段普通答案再附JSON。

**为什么不直接把多余文字删掉？** 因为多余文字可能包含与JSON矛盾或没有证据的结论。静默删除会掩盖问题，所以仍保留原始输出、拒绝不合规格式。

**现在已经解决了吗？** 已完成指令修正和离线测试，尚未验证真实模型能否持续遵守。程序测试通过不等于模型准确率。

**下一步是什么？** 使用Astra中审查固定4个真实场景，沿用最多6次调用、首错停止的规则，不再加题或扩建系统。此前失败保持原样。
