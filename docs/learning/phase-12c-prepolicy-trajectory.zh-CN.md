# 机械行业的比较组能不能跟上月度走势

这次已经把检查做完。结论是：新的加权比较明显优于简单平均，但还没有达到提前写下的全部要求，所以暂不拿它计算关税效果。

## 这次是怎么检查的

固定机械行业158个加税候选和61个对照。用2016至2017年的24个月，决定各个对照占多少比例；然后保持比例不变，检查2018年1至5月能否跟上加税商品的走势。这些月份都在政策发生之前。

这里拟合的是统计比较规则，没有训练GLM。早先选行业和筛资格看过整个政策前窗口，因此这也不能叫完全没见过的独立考试。

## 结果怎样

| 检查项 | 提前定的要求 | 本次结果 |
|---|---|---|
| 检查期平均误差 | 不超过0.100 | 0.106，未达到 |
| 最差单月误差 | 不超过0.200 | 0.198，达到 |
| 比两个简单基准更准 | 平均误差至少低20% | 达到，约低56%及71% |
| 对照不要过分集中 | 有效对照数量至少20 | 23.61，达到 |
| 去掉权重最大对照仍较稳定 | 走势变化不超过0.050 | 0.037，达到 |

误差是在处理后的对数走势上计算，不能直接说是“进口金额误差10.6%”。有效对照数量表示权重分布相当于多少个等权对照，不是实际只用了23个商品。

偏差主要集中在2018年3月和4月，4月最大。不能看到了这点就删掉这两个月，或者把门槛从0.100改到0.110让它通过。

同时，拟合期误差只有0.00056，检查期升到0.106，说明“过去拟合得特别好”并不足以保证后面跟得上。61个可调对照配24个月，需要认真防止把历史细节拟合得过好。这个差距本身不能证明唯一原因就是过拟合。

## 是不是研究彻底失败了

不是。0.100是本项目提前设定的推进标准，不是科学界认定因果成立的分界线。我们知道的是：这个配置没有通过本轮检查，而且政策前确实出现了月份偏差。不能因此宣布永远无法做因果，也不能把“只差一点”当作允许发布结果的理由。

## 现在要补什么数据

暂时没有证据表明只要多下载几年就能解决问题。额外核查发现：已经下载的、行业明确为机械制造但被排除的241个商品，都涉及其他政策、混合加税类别或政策前有贸易的月份不足；没有一个被标记为“只是缺行业名称”。这些不能直接放回对照组。

下一步应审查具体缺口：是否需要更细商品层级区分混合政策暴露，或者现有政策筛选和研究窗口是否适合研究问题。先核查已有资料，形成明确补采清单或提出有依据的新研究设计，再决定下载。不会反复微调当前权重挑一个好成绩。

这阶段没有新增AI功能。研究结果、限制和后续决定已进入项目文档，以后AI报告要遵守这些依据。政策文档检索和完整AI交互仍是产品待办。
