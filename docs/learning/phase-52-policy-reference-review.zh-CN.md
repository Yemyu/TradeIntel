# Phase 52：为什么现在还在修“判卷规则”？

## 这一轮到底在做什么？

不是训练GLM，也不是不断出题刷准确率。我们在检查负责判卷的程序：假如AI答错了，程序能不能确实把它拦下来？

这次真的找到了漏洞：题目问“什么时候生效、税率多少”，评分表却额外要求回答“818个子目”；还可以把必答清单清空，或者把回答中格式不对的部分忽略掉。这会导致错判，现在已修复。

## 你需要能够解释的问题与参考答案

**1. 官方文件是真的，为什么还需要检查？**

文件真实不等于用法正确。如果问题要求站在某个历史日期回答，就不能偷用后来发布的文件；标准答案也必须对应题目实际问的内容。

**2. 为什么不能直接丢掉格式错误的那句？**

因为那句话可能恰好包含错误信息。丢掉再评分，就像把考卷错题撕掉再算成绩。现在保存整份原回答，停止并记录格式失败，不把它当作有效对照。

**3. 为什么不让AI自己说“审核通过”就完了？**

“通过”只是一个字段。还要能核对：审的是哪份回答、用了什么依据、报告之后有没有被改。后一部分仍是下一阶段待完善的工作。

**4. 本轮通过测试，是不是AI已经更准？**

不是。测试证明的是这些已知漏洞被拦住了；真实AI准确率需要另外做模型调用和逐项审核。本轮没有调用外部模型。

## 接下来做什么？

核对贸易比较是否真的用了题目要求的月份，并让最终报告与审核材料牢牢对应。暂不需要你输入密钥、运行终端或购买课程。因果研究的问题没有因这些软件修复而自动解决。
