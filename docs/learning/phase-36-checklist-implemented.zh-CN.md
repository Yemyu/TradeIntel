# Phase 36：检查清单现在真正接入了

## 本阶段做了什么？

上一阶段只是确定方案，这次已经把它写进运行流程。

例如你问“什么时候生效、税率多少”，无论AI把问题写成一行还是两行，审查时都会分别检查这两件事。每项都要留下判断和理由，不能只点一次“同意”就算全做完。

## 你需要能解释的问题与参考答案

**政策答案怎么检查？**

指出答案中的哪一句回答了这个问题，再指出它引用了哪段资料，以及资料中的哪句话支持它。程序检查引用和摘录是否确实存在；审查者判断内容是否真的支持结论。两者不能混为一谈。

**贸易数字怎么检查？**

拿实际输出对照事先冻结的参考，检查月份、金额和比较方向。不能看见模型给了一个数，再把这个数当作正确答案。

**如果只答了一半会怎样？**

漏掉的那一项记录为missing，整题不通过，后面的题停止。已得到的回答和拒绝理由保留，不自动重试。

**为什么答对清单内容还可能不通过？**

它可能在正确答案后又附加没有依据的结论，比如声称关税导致了金额变化。所以还要检查整份回答，不只检查那几句必答内容。

**这些检查是不是AI自己完成的？**

当前是程序和审查者协作：程序处理记录完整性、数值比对和文件变化；审查者理解事实与证据。助手可以帮助查看并填写，不需要你学会这些代码。它不是一个已经训练好的自动评分模型。
