# Phase 10q：先让AI说清楚它理解了什么

## 本阶段成果

新增自然语言解析接口：接收一句问题，只请求模型整理需求，不给它任何数据工具。输出经校验后，展示中文的“任务、原产地、月份、指标、粒度”等待确认内容；格式错误、截断、缺少依据或问题不明确时，进入澄清。

目前没有调用真实GLM，没有更改旧版AI入口，也没有重新计算准确率。这是可接模型的开发接口，不是已经验证的自然语言助手。

## 你需要理解的关键问题

**1. 为什么又要确认？不是想让AI自动完成吗？**

最终希望减少不必要确认，但现在还没有证据证明新解析器能稳定保留原意。先把它理解的内容展示出来，才能发现“我要德国，它理解成中国”这类错误。确认是当前开发阶段的保护措施，不代表以后每一步都要你手动操作。

**2. 有原文引用为什么还不够？**

“不要查中国，查德国”也包含“中国”。检查引文是否出现在原文只能防止捏造引文，不能判断否定、指代和真实意图。程序因此始终保留“意图未验证”，不让模型自己声称已经理解正确。

**3. 解析接口与执行流程有什么区别？**

解析接口像填业务表单；上阶段的执行流程像按表单办事。前者负责理解，后者负责能力限制、取数与检查。本阶段没有自动把模型填的表交给后者执行，所以格式通过不意味着会立刻查询。

**4. 模型遇到不支持的国家怎么办？**

应保留“德国”或要求澄清，不能因为工具只支持中国、其他整体和全部整体，就把德国改成其他整体。后续执行层可以明确拒绝不支持范围。

**5. 测试通过证明什么？**

新增10项测试证明接口不会自行执行、不会接受额外SQL字段、会拦截重复JSON键和截断响应、不会回显异常中的密钥，并且只尝试一次模型调用。测试使用模拟模型，**不证明真实GLM理解问题的准确率**。
