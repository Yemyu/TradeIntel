# 把政策前时间改正后，项目发生了什么变化？

2026-09-11。本阶段完成的是**原研究方案的数据准备修正**，不是新的因果结果，也不是训练AI。

## 1. 为什么不能只把“5月”改成“2月”？

原来哪些商品进入候选名单，取决于它们在29个月里有多少个月实际进口、金额来自哪些政策商品。截止时间变了，这些判断也必须重新算。

本轮只使用2016年1月至2018年2月的26个月。正进口额至少22个月，沿用原24/29的比例向上取整；不是为了多找对照而临时降低要求。2018年3月以后金额没有用于新选择。

## 2. 重算结果是什么？

| 内容 | 原29月版本 | 新26月准备版本 |
|---|---:|---:|
| 处理候选（受税商品组） | 315 | 314 |
| 对照候选 | 893 | 890 |
| 活跃月要求 | 至少24月 | 至少22月 |

这两个数量仍包括行业分类不唯一的候选，不要与旧匹配实际使用的284/829混淆。

- 原处理候选1个退出：842911，旧窗口24个正金额月，新窗口21个，未达到22月。
- 原对照7个退出、原被排除商品4个进入对照候选；全部按同一规则处理，不挑行业。
- 另有7个旧被排除商品在新窗口没有面板行，记录为absent，未填成零贸易。
- 840682的受税金额纯度从混合变成纯List1，但仍因月份不足和同期政策重叠被排除。不是纯度变高就可以加入。
- 1,204个新候选都有完整26月聚合记录，四项特征均完成；94个行业分类不唯一，单列，不猜测行业。

**参考答案：**时间修正改变了少量资格，没有突然创造一大批可靠对照。现在既不能说变得更好，也不能说肯定还是不行，因为没有重新匹配或估计。

## 3. 数据质量检查到哪一步？

新窗口List1中国金额映射覆盖约99.9755%，编码覆盖约99.8535%；未映射或歧义金额保留在报告和例外表，没有悄悄并入。

独立从原面板再次计算1,204个候选的规模、趋势、波动和中国份额，与新程序最大差小于9e-16；输入与输出文件指纹核对一致。没有修改原资格、旧失败实验或因果状态。

已有聚合表里的0仍然是原表的0。候选没有缺月不代表我们已经查清每一条原始国家记录缺席的经济含义，不能把源级限制掩盖掉。

新增6项测试，全套363项工程测试通过。它们检查日期过滤、缺失不补零、异常停止等行为，**不表示AI准确率或因果可信度**。

## 4. 为什么还不能直接计算因果？

现在还有两个明确的政策范围问题：

1. **拟议征税名单还没接入旧范围表。** 有些商品最终没被征税，但企业可能先看到它出现在拟议名单里。它不能不经检查就被当成“从未受预期影响”的对照。
2. **排除清单没有全部结构化。** 已识别182个明确HTS10字符串，其中2个未映射；另外还有依照产品具体描述限定的豁免，不能靠代码或关键词全部判断。

这不意味着所有原清单意向处理研究都必须删除豁免商品。主问题仍以原始清单分配为准；但我们不能说每个商品始终缴纳相同额外税率，也不能声称已完整完成排除敏感性分析。

**参考答案：**下一步先解决政策范围的具体缺口，再设计估计；不能拿模型更聪明作为绕过依据的理由。

## 5. AI环节这次做了吗？

没有调用GLM，也没有训练、微调或做新的AI效果评测。这阶段在修正经济研究的数据依据，未来AI报告可以引用它，但它本身不是AI模型能力提升。

自然语言→确认→政策检索和贸易工具→完整报告的实施计划仍在，不会因为因果受阻而取消。
