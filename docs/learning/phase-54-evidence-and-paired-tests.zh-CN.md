# Phase 54：两组比较怎样才公平？

## 本轮做了什么？

我们把贸易查询、政策问答、两者一起问、信息不足要澄清这四条路线放进一次离线测试，确认它们能按流程走完。这里模型回答是测试预设的，不是GLM的新成绩。

## 你需要能够解释的问题与参考答案

**问：为什么同一个模型，一组给文件、一组不给，就不一定公平？**

答：如果同时换了提示词，就改变了两件事。结果不同可能来自文件，也可能来自提示词。目前不能把全部改善都算成RAG的功劳。

**问：参考答案和检索结果为什么要分开？**

答：检索结果是系统找到的材料，可能找错；参考答案是检查系统的依据。不能让被检查的内容把标准答案改掉。

**问：为什么又出现新的引用编号？**

答：检索器为了保留上下文，会把几个片段拼成较大的窗口。编号变化不一定代表伪造，所以程序要回到原始PDF核对文字和页码，而不是只认编号。

**问：现在能正式测准确率了吗？**

答：还不能。四条路线走通只是工程条件之一；还要确定公平比较方式、强制审核要求和独立参考。下一步先定这些，不让你现在输密钥。
