# 为什么“有引用”还需要检查政策适用范围？

“额外加征50%”可能摘录正确，但如果不说适用于中国原产商品，读者可能以为所有来源都适用。原文被找到、模型引用它、模型解释完整，是三件不同的事。

本轮增加两层保护：

- 给模型的任务要求明确写出原产地范围，不把额外税率当综合税率。
- 程序检查已找到的原文及AI解释，提示可能遗漏原产范围；第二案例的一般适用限定原文无论是否被AI引用，都完整展示。

这不是训练，也不是程序已经懂了所有政策。文字检测可能漏掉其他措辞，甚至把否定句当成出现了关键词。因此没有警告也只表示“仍需人工核查”，永远不自动批准语义。一般限定只展示原文，不假装已自动解释所有例外。

## 后续：第二案例综合简报改为五项必填

第二案例的brief/series_brief现在分别要求：商品限定、额外税率、生效条件、原产地范围、一般适用限定。原产地项的摘录必须出现中国原产相关原文；一般限定必须引用登记的一般限定段。找不到依据要写unknown及原因，不能少交字段。

为什么不直接判断全对？程序能判断“交了五项、引用确有这段话”，却不能单凭这些确定中文概括完整正确。例如提到一般税费不等于已穷尽全部例外。因此semantic_approval仍为false，有unknown仍标待补核。
