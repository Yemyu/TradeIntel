# 页面结构化研究入口

本轮将现有结构化任务接到首页“按明确参数创建研究任务”折叠区和POST /api/research-structured。选择案例、月份、商品，任务固定为来源资料加待审阅调查建议，不交给模型重新猜范围。

## 当前你会看到什么

光伏第二案例仍是candidate。提交会明确返回“尚未开放在线研究”，模型请求为零；下方固定真实结果链接仍可查看。没有为了展示按钮而绕过候选发布限制，也没有声称在线第二案例现在已经可用。

后端为未来正式启用准备了完整接线：检查参数、案例状态和发布窗口→固定版本→最多一次解释调用→返回程序资料/AI附件链接。同一协调锁阻止与自由研究请求并发；不自动重试。所有AI解释仍未经批准，没有实现人工审批合并。

## 文件与安全

资料读取只允许合法运行编号下的source-packet.zh-CN.md、interpretation-pending.zh-CN.md，不能读取任意文件；返回text/plain，页面文本使用textContent。候选拒绝在读取密钥之前；结构化提交复用JSON和来源检查，不自动触发请求。

16项聚焦测试通过，含HTTP候选零调用/不加载配置、跨来源拒绝、资料白名单及纯文本响应、结构化业务与解释回归；页面JS语法、git diff检查通过。本轮零真实API。启用后的协调器路径尚未做真实在线模型验收，浏览器视觉仍未验收，不绕过之前的安全限制。
