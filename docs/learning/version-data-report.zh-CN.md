# 真正更新了什么？

首页“数据版本更新”增加“打开最新数据报告”。它读取当前已登记、发布副本校验通过的数据，生成统计截止月份、全窗口月表和按同一比例尺绘制的进口规模条形图。现在实际范围为2025年1月至2026年7月。

这不是重新训练模型，也不是生成新经济结论。金额和份额由程序生成；5.29%的分母是所选政策税号的全部来源进口额。缺数据不补零，分母为零不显示虚假的0%。未核查跨期编码可比性，因此图表只展示登记金额，不解释增长或政策效果。

页面附固定版本链接。普通入口下次读取新的活动版本；固定链接始终读取指定的已发布版本，拒绝损坏的发布副本。旧报告不被覆盖，旧报告中的AI文字也不会被自动移植到七月。没有版本记录的历史报告仍无法自动判断更新关系。

本次13项报告及网页测试通过；实际HTTP200、七月193,774,871/10,251,657美元与5.29%核对成功，固定链接返回内容一致。未调用模型。静态示例位于docs/showcase/version-data-report.html；其中固定链接需通过运行中的项目网站访问。尚未做浏览器视觉验收，也未实现整篇AI报告的版本迁移。

下一步应将具体分析请求和这份固定版本数据页关联，明确哪些解释需要重新审阅；不是继续让模型泛泛解释数据更新。
