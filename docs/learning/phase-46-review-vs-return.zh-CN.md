# Phase 46：模型返回、任务完成和结果正确有什么区别

本次审查发现一个容易误会的地方：模型给出了计划，程序就可能把这道题标成“完成”。但你要的是报告，计划只是开始。

例如你问“比较两个月进口金额并解释政策”，完整流程是：读懂问题 → 你确认范围 → 查询与计算 → 生成政策回答 → 核对数字与原文。只有第一步有返回，后面的事情可能完全没做。

## 你需要能解释的问题与参考答案

- **为什么566项测试通过还会发现问题？** 测试只检查写进测试的情况。先前没有测试“只返回计划就宣布全题完成”，这个漏洞因此漏过。本轮先写能复现的反例，再修代码。
- **有引用编号为什么还可能是错的？** 编号可能不存在，也可能对应另一段话。程序先验证编号、回答和原文相互对应；人再判断原文是否真的支持这句话。
- **为什么截断失败仍要记token？** 模型已经生成了内容，也已经产生用量。回答不可用不代表免费或没有调用。
- **现在是在训练模型吗？** 没有。本次在修测试与记录程序，没有改变GLM参数，也没有调用GLM。
- **什么时候才能测试AI效果？** 把验收组件接进实际产品流程，并完成有证据/无证据对照的离线检查后，再固定实现、准备问题，运行真实模型。那时才能知道新问题答得怎样。

下一步是完成整条验收流程的接线。当前在线测试保持关闭；本轮修复不产生新的准确率或因果效果。
