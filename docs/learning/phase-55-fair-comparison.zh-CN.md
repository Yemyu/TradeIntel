# Phase 55：让“给文档”和“不给文档”的比较有意义

## 我们改了什么？

以前两组的提示词也不同，无法确定差别是不是文档带来的。现在严格测试给两组同一份说明书、同一个问题，只把一组的证据列表留空。

同时，程序会在开始前检查需要的参考答案、独立查询条件和审核者是否齐备，不再跑完才发现缺材料。

## 你需要能解释的问题（附答案）

**问：同一份提示怎么既要求按文档回答，又允许不用文档回答？**

答：两组都收到同一条条件规则：有文档就按文档回答；没文档可用已有知识，但不能假装有引用。改变的只有是否提供文档。

**问：这是不是已经证明RAG更好？**

答：不是。这只是让后面的比较可以解释。真实结果可能更好、相近或更差，都要如实保留。

**问：为什么还区分发送输入和HTTP请求？**

答：就像填写寄件单和包裹真正出库是两个环节。中间的软件可能加字段或改内容，所以要分别核对，不能仅凭准备好的输入宣称真正发送的一样。

**问：有审核回调，是不是就有人审核了？**

答：不是。回调只是程序接口。现在离线测试里用的是测试标签；真实参考答案和逐项判断还需要独立复核。
