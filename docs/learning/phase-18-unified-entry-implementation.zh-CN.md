# 本阶段学习：为什么要支持“只问一件事”

## 这次完成了什么？

之前入口把政策问题和贸易问题绑在一起：你只想问“政策什么时候生效”，它却要求同时准备月份和进口额。本阶段把它拆成三个合法场景：

1. 只查政策文件；
2. 只查贸易金额；
3. 同时查两者。

这不是把 AI 变成三个项目，而是同一条入口根据问题保留真实子任务，避免偷偷添加用户没问的任务。

## 为什么确认还要绑定指纹？

计划预览后，如果数据表、政策语料或执行规则被改过，原来的确认可能已经不再对应当前内容。指纹就是这些材料的版本号码。版本变化后必须重新规划和确认，避免“看的是旧预览，执行的是新数据”。

## “独立保存”是什么意思？

组合问题中，贸易工具可能失败，但政策文件检索仍然有结果；或者政策模型超时，贸易金额仍然可靠。现在两边各有状态，整体会标记 partial，不会把一边成功包装成全部成功。这是工程上的诚实性，不是模型准确率。

## 仍然没完成的部分

本轮还没有完成最终自然语言助手：固定默认值和用户原话的来源分类还需要更严格的宿主校验；错误、超时和中断账本还要完整保存；RAG 查询桥接和语义验收也未完成。没有在线 API 成绩，不能写“AI 已通过”。
