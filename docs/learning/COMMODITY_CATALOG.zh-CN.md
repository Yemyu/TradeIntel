# 这一阶段学什么：为什么数据很多，之前却只能问大豆？

先把两个东西分开：**数据表**存每个月各商品的金额；**商品目录**告诉程序“日常说的小麦，对应数据表里的哪一组编码”。之前数据表里有成千上万种商品，但提问入口只认识“大豆、玉米”两个中文词，所以你问小麦时进不了数据表。这次补的是入口，不是凭空新增贸易金额。

现在你可以在工作台输入“最近美国汽车进口有什么变化？”页面不会马上报一个数，而是先列出客车、乘用车、货车等候选。你选“乘用车”后，系统才把它固定为 HS4 8703，查询每个月该组下实际存在的十位商品码，再画出金额。若选错组，数字可能完全真实，却不是你原本要问的东西；所以确认范围比直接生成看似漂亮的报告更重要。

这个目录来自美国人口普查局的每个月原始包。进口用 **HTS**，出口用 **Schedule B**：四位、六位的大类有共同基础，十位细码不能直接混用。我们为每个月保留目录来源和文件摘要；报告生成时再核对一次你选的组、贸易方向、月份和数据版本。这样做的目的不是增加步骤，而是防止页面过期后拿旧范围查新数据。

中文名称参考中国财政部 2026 年税则，只帮助搜索。真正决定美国数据范围的是美国月包中的英文商品标题。比如“咖啡”可能是咖啡及代用品，也可能是咖啡提取物；只看中文短词不够。自动提取的中文标题会在页面注明，不能把它当成美国官方中文译名，更不能据此推断关税。

**AI 在这里做什么？** 找商品编码、合计金额、逐月图表都由可复核的程序完成；模型没有资格自己挑一个税号、编一个数字。以后你在报告页单独点“生成模型解释”，模型才会根据已经固定的事实写解读，仍需人工核对。也就是说，Agent 的价值不只是调用模型，而是把“检索范围—数据查询—来源核验—报告—审阅”连成可控制的流程。

你可以自己试三题，重点不是记代码，而是看范围如何改变答案：

1. “最近美国小麦出口有什么变化？”——为什么卡片写“小麦及混合麦”，而不是只写“小麦”？
2. “最近美国咖啡进口有什么变化？”——为什么会有不止一个候选？
3. “最近美国汽车进口有什么变化？”——客车、乘用车、货车各自是多大的范围？

当前边界也要记住：中文标题覆盖很多四位商品组，但日常别名并非全都认识；不能把“标题编码覆盖约98.4%”说成提问成功率。历史进口月份中间有缺口，不能跨缺月画连续趋势。页面里的动态报告目前以中文为主；模型解释质量仍要另做真实验收。
