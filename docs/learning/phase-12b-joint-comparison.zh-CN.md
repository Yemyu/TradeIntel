# 两个行业能不能真的找到合适比较对象

上次是分别检查“身高范围”和“体重范围”。这次要求同一组比较对象能同时接近，条件更完整。

结果提醒我们：上次看起来有希望，还不能当作已经成功。机械行业158个商品里，57个能在这次严格检查中同时对应；电子行业62个里只有7个。它们不等于已经合格的因果样本，也不意味着其他商品永远不能研究。

因此，我们没有把这64个商品直接拿去做回归。它们合计只占原315个候选政策前进口金额约10%，不能把它包装成覆盖大多数贸易的研究。

还有另一条值得查的路：对照商品按不同比例组合，能否对上整个行业的平均表现？两个行业都可以在既定误差范围内对上平均特征，其中机械行业比较分散，电子行业更依赖少数对照。平均值对上仍不意味着每个月走势对得上。

**下一步做什么？** 先检查机械行业：用较早的政策前月份设置比较方式，再用较晚的政策前月份检查它能不能跟上真实走势。好比先用前面的历史练习，再拿后面的历史检查；这里训练的是统计比较规则，不是在训练GLM。

**要不要补数据？** 这一步暂时不用，已有历史月度数据够做检查。如果仍找不到稳定比较，优先查是不是缺少合适的对照商品或其官方分类资料。多下载几个政策后年份不能解决这个缺口。

**因果是不是做出来了？** 还没有。现在是在验证参照物是否可信，尚未估计关税效果。这一轮的进展是排除了“简单缩小范围就会成功”的假设，明确了更值得检查的方法。

**AI的部分呢？** 政策文档检索、数据工具、完整交互和真实模型评估仍在总计划里。当前研究检查将决定以后AI能报告什么结论，不能被当成新AI能力。
