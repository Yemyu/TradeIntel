# Phase 39：终于有一题完整走通了，接着卡在哪里？

第一题问生效日期和额外税率。这次AI正确形成计划，系统检索公告，模型写出答案，助手逐项核对证据，整条流程完成。不是只有程序测试通过，而是真实模型回答也经过了审查。

但这还不是整个项目验收通过：第二题同时问政策和贸易金额，模型主要参数填对了，却把接口字段名写错、复制原文时漏了标点，所以在查询之前被挡住。后两题没有运行。

**为什么字段名错了也不行？** 对人来说意思可能看得懂，但程序按固定接口读取数据。错误字段不能直接作为有效指令执行，需要修复通用约束或另行设计明确的兼容规则，不能偷偷改答案。

**第一题是不是完美？** 不是。事实有证据、两问都回答了，但精确时刻中英混杂，而且仍用了JSON代码围栏。现有解析器允许整个围栏，因此可以交付；不代表完全遵守了提示或适合直接公开展示。

**现在的成绩是什么？** 本批4个公开开发场景：1题经审查通过、1题规划失败、2题未运行。3次真实调用，共5911tokens。不能据此宣称总体准确率。

**接下来做什么？** Astra中只针对规划接口的字段说明和原文复制要求做局部诊断，不继续扩建系统，也不反复索取已经明确授权使用的密钥。密钥不进Git，真正不用时应在智谱控制台撤销。
