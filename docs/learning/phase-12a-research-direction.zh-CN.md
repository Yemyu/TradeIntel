# 为什么先检查行业

本轮解决的问题是：有没有既值得研究，又可能找到合理参照的商品范围？这直接服务于“关税对贸易的影响”，不是为了凑一个能运行的回归。

我们拿政策发生前的数据检查了各行业。结果发现：有些行业很难找到类似商品，有些行业保留了较多值得进一步比较的商品。机械制造、计算机及电子产品制造两个行业合计占候选加税商品政策前进口金额约64%，因此有经济分量，并不是只挑一两个容易成功的商品。

**这是不是已经找到对照？** 还没有。举例说，一个人身高落在班级身高范围里，体重也落在班级体重范围里，不代表班里就有一个人身高和体重都跟他很像。我们的检查目前相当于分别看身高和体重，下一步要检查能不能同时接近。

**是不是把其他行业删除了？** 没有。原始数据和旧研究仍保留；目前只是排出哪些方向先审查。最终若只研究某些行业，会明确说明范围，不代表所有商品。

**为什么不直接拿其他国家当对照？** 关税可能使美国转向其他国家购买，同一个政策会同时改变两边。因此其他国家可以帮助研究相对变化，但不能直接假定它们没受影响。

**今天新增了什么AI功能？** 没有。这一步检查经济研究的依据。以后AI负责找政策依据、调用计算、解释结果，而这些研究检查决定它能说到什么程度。

**接下来做什么？** 优先审查这两个行业是否具备可信的联合比较条件。如果有，写清新研究规则后才能估计政策效果。如果没有，也要具体说明缺少什么。RAG和完整AI交互继续保留在总计划里，不能因为做研究就忘掉。
