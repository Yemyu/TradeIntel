# 第 2 步：把政策事件和贸易面板连接起来（中文版）

> 这一步仍然不要求你手写代码。重点是理解两个数据源如何对齐，以及结果能说到什么程度。

## 1. 两张表各自回答什么问题

| 数据 | 它回答的问题 |
|---|---|
| 政策事件表 | 哪项政策、针对哪个原产国、什么时候生效、税率是多少？ |
| 政策商品表 | 哪些 HTS8 商品属于这项政策？ |
| 贸易面板 | 每个月美国从各个国家进口这些商品多少？ |

政策表不是贸易结果，贸易面板也不知道哪一天发生了政策。只有把它们按商品、国家和时间连接起来，才可以观察政策前后的变化。

## 2. 连接的三个关键点

### 商品：统一 HTS8 格式

政策文件里的商品代码通常写成 `8411.99.10`，贸易面板里的 `hts8` 写成 `84119910`。它们是同一个八位税号，只是标点不同。因此程序先删除句点，再比较八位数字。

这不是随意改格式，而是为了让两个来源使用同一个连接键。程序还会检查格式不对的代码，避免把不同商品误连在一起。

### 国家：政策中的 China 对应贸易中的 CHINA / 5700

政策事件写的是 `China`，贸易档案使用国家名称和四位代码。程序通过名称找到唯一对应关系，并记录结果为 `CHINA`、`5700`。以后查询时既能看懂名称，也能使用稳定代码。

### 时间：按月连接，而不是假装有日数据

政策在 **2018-07-06** 生效，但贸易面板只有月度记录。因此：

- 2016-01 至 2018-06：`pre`，生效前；
- 2018-07：`transition`，生效日落在月内，不能假定整月都暴露于新税率；
- 2018-08 至 2019-12：`post`，生效后完整月份。

把 2018 年 7 月单独标记，是为了诚实反映数据的时间精度。若把整个 7 月直接算作“政策后”，就会把半个月或不同批次的情况混在一起。

## 3. 这次先做什么分析

当前只做**描述性基线**：分别计算中国、其他原产国和所有原产国在生效前后的平均月度进入消费金额，并保留每个月的明细。

这一步回答的是：

> 政策前后，数据中观察到了什么变化？

它暂时不回答：

> 这些变化有多少一定是政策造成的？

后一个问题需要合理的对照组、趋势假设和更严格的研究设计，不能从一张前后对比表直接得到。

## 4. 本次输出

- `data/processed/analysis/policy_case_monthly.csv`：48 行，每行一个月份，包含中国、其他国家和全部国家的金额、份额、商品覆盖数；
- `data/processed/analysis/policy_case_country_change.csv`：按原产国汇总生效前后平均值和变化量；
- `data/processed/analysis/policy_case_summary.json`：政策信息、窗口定义、来源路径、统计结果和“不能作因果结论”的限制。

每个输出都能沿着贸易面板中的来源字段回到具体月份的官方文件；政策来源仍然来自政策事件表中的 USTR 链接。

## 5. 目前观察到的结果（只作描述）

在这套口径下：

- 中国相关政策商品的平均月度进口金额从约 25.47 亿美元降到约 19.04 亿美元，变化约 **-25.2%**；
- 其他原产国合计的平均月度金额从约 298.65 亿美元升到约 395.21 亿美元，变化约 **+32.3%**；
- 2018 年 7 月被单独保留为过渡月；
- 48 个月的原产国并集为 232 个，不能把所有出现过的国家都解释为“受益国”。

这些数字值得继续研究，但它们同时受到季节性、总体需求、汇率、其他政策和 2018–2019 年宏观变化影响。因此项目会把其他国家列为**候选贸易转移对象**，而不是直接写成“政策导致它们受益”。

## 6. 为什么现在不直接做更复杂的模型

有三种常见选择：

1. **前后描述性比较**：最透明，先确认数据连接和口径正确；
2. **事件研究图**：展示每个月相对于事件的变化，帮助观察趋势，但仍需要解释假设；
3. **差分中的差分**：使用对照商品或对照国家，可能更接近因果问题，但必须证明对照组在政策前具有可比趋势。

当前选择第 1 种，是因为如果商品连接、国家代码或过渡月处理错了，后面更复杂的模型只会把错误包装得更漂亮。等基线结果和数据质量都稳定后，再决定是否值得加入第 2 或第 3 种。

## 7. 你需要能够解释的内容

你不需要记住函数名或 Python 语法，但应该能够回答：

1. 为什么政策商品要用 HTS8 连接，而不是商品名称？
2. 为什么 2018 年 7 月是过渡月？
3. “中国平均月度金额下降 25.2%”和“关税造成下降 25.2%”有什么区别？
4. 为什么其他国家的上升只能先叫候选贸易转移，而不是政策收益？

能回答这四个问题，就说明你理解了这一步在整个系统中的作用。下一步再把同一套结果放入 MySQL，学习数据库表、主键和可验证查询。
