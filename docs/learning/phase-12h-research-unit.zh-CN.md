# Phase 12h：现在准备怎么比较商品？

本阶段确定用八位商品代码（HTS8）作为下一条研究路线的比较单位。关税清单按八位代码列商品，下载数据中的十位代码更细；同一个八位商品下面的细分记录会先合计，再比较月份变化。

## 为什么这样选？

如果一个被加税的商品下面有十个统计子码，把它拆成十个“独立实验”会夸大信息量。按政策对应的商品层级比较，研究含义更清楚。依然需要考虑同一个大类的商品会一起涨跌。

## 那17个未覆盖代码怎么办？

它们帮助我们发现大类合并的影响，但不直接加入主要对照。它们旁边的同类商品受到关税时，客户可能转而购买它们，这会影响比较。它们适合后续观察替代现象，能否用于因果研究需要另作论证。

主要候选对照从整个大类都没有被现有同期政策表直接覆盖的商品中找。这能避开明显的直接加税混杂，但供应链和行业需求等间接影响仍需研究。

## 上一步有错误吗？

有一处文字计数错误：17个细代码中，至少28个月有中国记录的实际是10个，之前写成9个，已经更正。以前的验收主要检查数量与金额；这次增加重复代码、逐行月份、来源、观察标记检查，并重新计算29个原包的哈希，全部通过。旧面板和新表共享部分解析逻辑，对账一致不等于两套完全独立的解析系统互证。
