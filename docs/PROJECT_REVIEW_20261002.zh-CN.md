# 项目评价

日期：2026-10-02。评价对象是当前作品展示与本地自部署版本，不是面向公众的云端商业服务。分数是按已核实功能和交付材料给出的工程判断，不是统一榜单成绩，也不表示求职或申请成功率。

## TradeIntel

整体约 **8/10**：适合作为 AI 应用与数据工程作品展示。可以结束当前交付，不需要为了让所有弱模型都答对而继续改题、加轮数或扩架构。

| 环节 | 分数 | 依据和不足 |
|---|---:|---|
| 数据工程 | 8.5/10 | 商品目录、进出口两种口径、版本绑定、数据包校验和程序核数已有实现。进口48个月不连续，伙伴仅全部汇总或中国；不是全球实时数据库。 |
| Agent与工具调用 | 8/10 | 模型实际选择商品、贸易和政策工具，支持追问、换方向、换商品；缺数据和错口径由程序约束。不是只把一份表交给模型写摘要，但完成率受配置影响。 |
| AI效果与验证 | 7.5/10 | 五组十二题运行记录覆盖GPT不同推理档、DeepSeek与GLM。Sol Low/Medium正常9/9；Luna、DeepSeek、GLM分别为7/9、8/9、8/9。GLM生成的10份报告数据核验通过，但钨政策联查未交付。已有同题比较，样本仍有限，且各组并非都由独立盲测完成；具体设置见模型测试页。 |
| 政策检索与阅读 | 6.5/10 | 已登记公告可检索，附带依赖条款和引用检查。文档覆盖和陌生公告阅读还不够充分；演示政策报告明确是资料编辑稿，不冒充新Agent回答。 |
| 贸易分析 | 7/10 | 金额、跨月变化、来源份额与图表能回答具体贸易问题；不混用数量、价格、进口消费额与出口FAS。分析主要描述变化，没有建立政策效果或投资预测；这是当前范围，不是必须补做因果识别。 |
| 前端与展示 | 8/10 | 中英首页、四个案例、对话步骤、图表报告、折叠来源和PDF入口。手机390px报告无横向溢出。公网是只读展示；自由提问需本地运行。 |
| 本地可复现性 | 8/10 | 双语安装、独立数据ZIP和SHA校验，静态构建不用私有记录或第三方Python包。macOS已验证，Windows未验证；完整历史实验仍依赖未公开的原运行记录。 |
| 维护与测试组织 | 6.5/10 | 当前Agent回归与展示验收通过，旧实验保持证据。全仓历史套件尚有10失败、118错误，源码和开发记录偏多；不把当前验收通过称为全仓绿色。 |

这些分数不通过简单平均产生总分。当前最有展示价值的是：自然语言选择工具、查询可复核数据、连续追问、生成可阅读的报告，并公开不同模型在同一任务上的表现。

## 与其他作品的比较

比较依据是本机各项目现有README、限制说明及结果记录，没有在本轮重新执行它们全部实验。因此这里只比较工作内容、证据强弱和申请方向，不给其他项目虚构同标准的精确分数。

| 项目 | 相比TradeIntel更强的部分 | TradeIntel的优势 |
|---|---|---|
| 中国汽车市场分析 | 预测有明确时间切分和基线：371车系、2226车系月，滚动WMAPE29.75%，上月基线40.99%；还有配置与评论分析。数据分析和机器学习证据更扎实。 | 可以实际对话、选择工具并生成报告，更适合展示LLM应用开发。 |
| 硬盘故障提前预警 | 有冻结模型的时间外验证与固定告警预算；Q4捕获40/86，规则35/86。机器学习评价更明确，虽事件量不足且概率校准未通过。 | 面向人的交互和报告完整度更高，能展示工具协议、异常处理和模型接入。 |
| 电动车购买意愿 | 622份问卷，顺序Logit、Bootstrap、异质性与解释性分析；研究问题更集中，方法与解释更系统。 | 有真实Agent流程和可使用的本地应用，不只是研究结果的阅读页面。 |
| 商品实体匹配 | 做过监督模型适配和三种随机种子对照。它比TradeIntel更能证明训练模型的工作，但AP采纳门未通过：0.941998对0.942749。 | 对完整AI应用交付、数据工具与交互的证明更强；不依赖训练出优于基线的新模型。 |
| LoL跨赛区研究 | 数据逐场核查和交互图表更集中，作品规模与主题更容易理解；主要是描述性比较，不是训练出的强度模型。 | AI参与度明显更高，系统功能和本地使用流程更完整。 |

投AI应用、Agent或数据工程方向，TradeIntel值得放在主要项目位置；投机器学习建模方向，汽车销量和硬盘预警更适合证明切分、基线与指标；投经济或商业分析方向，电动车与汽车市场研究更能说明方法。几个项目互补，不应把每个都包装成相同类型的AI项目。
