# 第二项政策接入范围：光伏电池及组件

## 决定与用途

选择2024年9月公告中的光伏电池及组件条款，作为第二个独立公告事件；仍属同一Section 301政策体系，不代表跨国或跨制度泛化。它与现有多晶硅/硅片属于不同商品环节，可帮助分析人员分别整理上游材料与电池组件的贸易规模、来源结构和公告条件；不据两者金额推导投入产出系数、转运或因果效果。

来源：[正式公告与附件](https://www.govinfo.gov/content/pkg/FR-2024-09-18/html/2024-21217.htm)、[CBP实施指引](https://content.govdelivery.com/accounts/USDHSCBP/bulletins/3b85471)。附件A、C及note31(c)将85414200、85414300对应9903.91.02，本公告额外50%，生效门槛为2024-09-27美东夏令时00:01。必须保留note31(a)的一般适用限定，不能将此税率说成今天综合税率，也不能混入太阳能制造设备排除条款。

选择理由：两个精确HTS8的范围清晰；既有美国月包可复用；能检查不同原文结构、EDT/EST区别及跨案例证据隔离。并非因为已知模型答得好，尚未作模型测试。相比依用途细分的电池或含合同排除条件的起重机，初次多案例接入的范围核查更可控。未完成全面行业候选评分。

## 下一实施块：先多案例隔离，再批量提取

1. 建立案例配置，将政策ID、商品文件、月表目录、政策索引、窗口和版本库绑定。去掉查询/路由中固定第一案例的假设；旧案例默认行为保持回归通过。未知案例不能回退到第一案例。
2. 从官方HTML构建该案例自己的可核验原文索引，连接商品描述、税率、生效条件和一般适用限定。不得简单复制旧CBP三个段落。
3. 使用已有19个ZIP提取候选数据，保留ZIP；核验连续月份、唯一键、来源、商品范围与CONCORD。零中国进口不能当作缺资料；跨月可比性另审。
4. 通过后才独立发布候选版本并接入网页；用不同政策的相似商品问题检查串库、串税率和串日期。暂不新增2024数据，因为当前任务是事后贸易暴露简报，不是政策发生前后归因；如要展示事件当期必须另补2024资源，不能用2025冒充。

验收：两个案例均能独立查询，交叉税号/混合政策请求不偷换；金额与原文可追溯，旧发布版不变；随后预设少量真实模型任务预算，不先无限调用。0模型API，本阶段未声称第二案例已可用。
