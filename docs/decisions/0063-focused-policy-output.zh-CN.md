# Phase13j：聚焦输出与非破坏性表述审查

本轮只做离线工程实现，不调用模型、不改冻结提示词和检索器。新增可选FocusedPolicyModel，保留原系统规则并追加通用组织要求：直接答问题、必要范围、避免无关精确时刻、区分政策行动和修订、使用明确24小时制。不提供本题具体日期、税率或参考答案，不改返回的主张。

另加启发式表述检查：标记“上午12:xx”“第几批修订”及可能多余的精确时刻，只要求审查，不自动改文字或宣布事实错误。没有标记不代表回答正确；标记也可能误报，应由原文和任务判断。

验收：只改系统消息、证据原文不变、模型返回不变、输入不突变；旧真实响应离线标记不覆写，保留指纹。旧样例已知，不把检测到它们当泛化成绩。

后续若测试新提示需独立协议：固定扩窗和模型参数，以旧实际回答为背景对照，预定调用上限、忠实性/完整性门槛和停止条件，不能直接多轮改到满意。当前新提示效果未知，不能替换默认或宣布旧批次通过。

长线：下一步优先把扩窗证据、可选聚焦层、审查备注接入同一个实验性报告路径，并与贸易结果保持清楚边界。先零API集成，不再无限细分“修一词再跑一题”。
