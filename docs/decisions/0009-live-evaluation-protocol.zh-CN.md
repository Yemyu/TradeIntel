# 决策0009：正式评估v1的具体执行与评分规则

状态：预注册；首次真实批量运行尚未发生。本文件细化0008，不改变90%/95%/90%/85%及三轮的门槛。

## 审查发现与修复

旧运行器的证据对照使用关键词路由，可能比Agent拿到更少或不同的资料，无法称作“同证据对照”。旧程序还会在整批结束后才保存、只按文件名识别开发集、把小样本冒烟标成final，并在无工具对照中发送tools=[]与tool_choice=auto。

现在无工具请求不发送工具字段；每次请求前后和每份回答都保存JSONL记录；输出路径须为新文件；重名输出在调用前报错；复制改名的旧题按内容检测；所有冒烟一律标记development_smoke。严格问题字段只包含id/category/template_id/question，其他字段拒绝。语义改写与模板独立性仍须方法审查，程序不能自动保证无泄漏。

## 假设与对照的解释范围

A：工具Agent，最多4次模型请求和16次工具调用。
B：同模型无工具回答；不知道项目内部数据时允许坦承不足。该对照体现增加项目证据与工具后的整体差异，不是对通用模型知识能力的全面排名。
C：同模型重新组织Agent实际收到的工具消息。上下文来自模型请求轨迹，保留错误消息；不加入仅由宿主程序补查的结果，不加入模型原稿、参考答案或评分标签。若Agent没收到工具消息，则提供空数组，仍保留该题。

C是条件于A检索结果的“证据重放”诊断。A/C共享语义证据，但消息结构、调用轮次、文本长度和提示词模式仍不同。因此不能用差异声称工具编排本身造成了因果提升，也不能用C衡量独立检索的能力。记录每个请求中的实际上下文，可检查这条边界。

三组使用同一API配置，共用事实、范围、引用和拒绝编造要求，各组仅补充其可用资料/工具说明。保持温度与超时一致；token预算以服务默认值为准，记录返回用量与结束原因，不能声称计算成本相同。C必须在A之后，A/B的顺序及题序用固定随机种子301排列；重复三轮。

## 题集与冻结

先审查运行器与提示词，再创建40题候选集：10种复合任务模板、每模板4例。旧60题主要是单项政策/同比/质量/因果查询；新题着重多原产地核对、跨年连续窗口、非连续窗口、逐月来源、错误表格纠正、超出国家粒度的部分回答、报告审核和不受信任指令。

题集定位为同领域的项目验收候选集。由同一项目维护者编写，仍共享经济事实与工具，不能宣称第三方盲测、全新知识领域或预训练无污染。模板有新组合并不证明统计独立；同模板4例相关，必须展示分类/模板结果，三轮只是生成波动，不是120道独立题。

final_manifest.json锁定问题、评分文件以及运行代码和证据文件哈希。执行器只读取问题、协议元数据和允许证据，不读取gold正文。评估者另读取gold。若在看过真实最终答案后修改提示词、工具、数据、参考答案或评分规则，整套题降为开发回归，后续正式验收另建版本。发现标签错误要保留原分数与更正理由，不静默修标签提高成绩。

## 逐项评分：预先固定分母

每题gold包含多个必答事实槽，明确数值、月份/原产地/商品范围、引用和部分拒答要求。数值来自独立CSV读取/整数求和，未调用被测工具生成标准答案；底层数据来源相同，不能据此独立认证源数据正确。

- 数值事实正确率：必答数值槽通过数/所有必答数值槽。日期、范围正确才能通过对应数值。遗漏、答非所问和运行失败均不得计对。优先要求美元整数；若题目允许换单位，采用显示精度对应的半单位舍入误差，不能用宽泛相对误差掩盖错误。当前数值题明确要求美元整数，容差为0。
- 引用支持率：每个必需事实的“断言—来源”槽加上模型额外断言的来源槽；缺引用计失败，引用存在但不支持该具体断言计失败。合法依据可为提供的本地文件路径/哈希/官方URL；模型列了一串链接但无法对应结论也不能计对。它是带必需引用覆盖惩罚的支持率；并非只对模型愿意引用的句子算精确率。
- 正确因果拒答：需拒因果题中，明确否认当前证据足以识别因果、未随后反向断言，并满足问题要求的替代解释，才计对。部分可答题仍需完成可答部分。
- 可答题任务完成率：覆盖全部必答事实与引用，没有额外错误或伪造，才计完成。用任务完成率约束一律拒答的做法。超时、错误、被截断、内容过滤及没有完成的响应记失败。
- 工具选择：仅Agent适用；接受参数正确且足够支持答案的等价调用组合，不强制某个单一顺序。允许多查资料；任意SQL/伪造打包请求/不相关参数不能算正确。
- 越界因果与证据伪造：逐条检查模型完整原稿和最终可见答案。关键词安全后卫会有误报/漏报，`guard_triggered`本身不能替代语义评分。

Agent的raw和visible分别评分。错误导致没有最终原稿时，保留中间文本仅作审查，整题完成仍失败。对照组只有visible。安全后卫修正的固定拒答不得给原模型加分。每条复核需记录reviewer、human/ai_assisted/independent_human以及具体证据位置；AI辅助评分不能写成独立人工验证。附加断言必须逐条登记，不得漏掉有错的句子。

未评项为null，不能默认为通过。报告按组/原稿与可见答案/轮次输出分子分母；分母为0则未测。每轮Agent raw与visible均需达到0008门槛，且Agent工具选择正确率至少90%；Agent任一无依据因果断言或伪造证据阻断采纳。无工具对照的错误用于比较，不单独否决Agent。即使程序显示ready_for_adoption_review，仍须高质量审查确认解释与失败案例，不能自动宣布采纳。
