# 决策0036：受限同义值与单独覆盖复核

假设：P02可通过明确定义、原文支撑的字段同义值转换修复；P03必须通过语义复核发现任务替换，不能用格式转换修复。v3新增第二次模型调用，输入原问题和规范化请求，无参考答案、无旧评分、无工具。复核只接受/要求澄清/拒绝，不能改计划；无效或异常时撤销确认。复核模型也会错，同一GLM的另一次调用不是独立人工审核，coverage_verified始终false。

同义表只含明确的政策名、只读操作、美元消费进口额、中国及已支持国家分组、整体粒度；值必须出现在该字段的原文引文内。未知国家/指标/操作不变，不把删除改成读取。日期沿用旧有限规则，不补证据。

本阶段真实实验固定旧v2六份响应作为规划输入，只新增最多六次glm-4.7覆盖复核；每题一次、180秒、temperature0、thinking disabled、2048输出tokens，无自动重试，首次通信或额外工具调用停止。原始规划已暴露，因此是开发组件实验，不是12次全链新生成或新题验收。模型只见问题与请求，不读取参考。旧v2的4/6是对照，成绩不修改。

验收：原始响应审计通过；原四个成功项保持，P02转换不改含义，P03转为必要澄清，6/6完整符合开发参考才认为本次组件验证通过。错误接受任务替换不得采纳；拒绝所有题不能算好结果。确认全部模拟/不发生，本阶段不查询金额。后续必须再验证全新规划+复核的端到端表现及额外成本，才决定采用。
