# Phase 13a：官方政策检索与引用协议

本阶段补齐总参考文件中的“检索政策原文”，不替代已有贸易计算、确认流程或因果门槛。

## 冻结范围与验收

- 语料：已核验的 2018-06-20 初始公告和 2018-08-16 后续公告。后一份同时涉及第二批及第一批修订，不能由文件名推断全部内容属于第一批。
- 第一版只索引初始公告第 1–3 页、后续公告第 1–2 页的正文。附件、具体税号是否适用、后续豁免、现行税率均不在本版回答范围。首页可能夹带其他机构通知，必须截断到 USTR 标题开始。
- 页内固定长度切块并重叠，不跨页；保存 PDF SHA-256、出版日期、PDF 页码、提取文字字符位置及原文。日期筛选是“当时已出版的文件”，不是法律生效判断。
- 检索用 BM25；中文通过公开的小型术语表扩展为英文检索词。这是词法检索，不是 embedding、微调或多智能体。对照为相同语料和查询扩展的词项重合基线。
- 生成独立接入现有模型适配器；模型只返回逐条主张及证据 ID。校验每条主张的 ID 来自此次检索，禁止工具调用；校验通过也只证明引用身份，不证明语义忠实。
- 默认仅展示原文证据；真实生成必须显式启用。报告不得把原文预览称作真实模型回答。

## 实验纪律

假设：页码约束和术语扩展能在两份公告的小型开发题中找回对应证据，且避免把没有覆盖的事项说成已证实。

先固定 6 道开发检索题及人工核对的目标页，再运行两种排序。记录目标页命中率 Hit@3、MRR@3；这些题只用于开发，不作为独立泛化成绩。门槛为 6 题至少 5 题在前 3 个片段含目标页；即使通过，也不据此声称引用语义或回答正确率通过。没有达到门槛时只记录失败，不反复改问题或规则抬分。

指标名称复核：草稿曾称 Recall@3，但实际上按“任一目标页命中即算该题成功”计分，因此改称 Hit@3；没有改题、改排序或改门槛。这也不是完整相关片段召回率。

负例单独检查：当前税率、未入库时期、具体税号适用范围、无关问题；无证据不调用模型。模型 JSON 损坏、虚构引用、空引用和额外工具请求均拒绝发布。

防泄漏：检索开发不读取政策后贸易金额、不改变因果资格；冻结题不用于模型训练。若后续优化，应另建未见问题做一次独立验收。

停止条件：原文哈希不符、页提取失败或引用不可定位即停止；不下载新包、不删除现有 ZIP、不自动推送 GitHub、不循环 API 调用。
