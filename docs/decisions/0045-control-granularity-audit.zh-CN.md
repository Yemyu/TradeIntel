# Phase 12d：商品粒度与数据缺口审查协议

本阶段只审查既有分类和数据粒度，不再拟合权重，不读取政策后贸易金额，不修改旧因果结果。

问题：333机械制造业的已排除HS6家族，是否包含未被现有政策表直接覆盖的2018 HTS10子代码？

固定口径：仅检查行业标记恰为333的已排除家族；复用既有官方政策范围展开逻辑。将2018有效代码分为“现有政策表直接覆盖”和“未覆盖”。未覆盖只是待核查线索，不是可用对照；政策表遗漏、跨年代码变化、商品替代和贸易活跃度仍须另查。HS6兜底政策记录不擅自扩成精确HTS10覆盖。

基准：现有241个被排除家族及其原始排除原因。交付逐家族明细、分类计数、源文件哈希和具体补采判断。没有因果效果、显著性或模型成绩采纳门槛，因为本阶段不估计这些指标。缺失映射或无法展开范围须显式保留；不能通过放宽活跃度或剔除失败月份增加对照。

停止条件：盘点完成即停止；不自动重跑匹配，不先下载全部年份，不把子代码数量当作有效样本量。后续若开展HTS8/10研究，必须先冻结新的经济问题、跨年映射规则、政策污染边界与验收标准。
