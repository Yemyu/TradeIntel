# Phase 13b：一次真实政策生成的冻结协议

目标：验证模型能否依据已检索原文，用中文回答第一批生效日期与额外税率。不是训练、独立验收或整体准确率测试。

- 假设：现有3个片段足以支持2018-07-06生效、额外从价税25%的回答；模型应区分额外税率与总税率，不混淆第一批与拟议后续行动。
- 基准：Phase13a已完成的原文预览及逐题参考说明。此轮只检查模型新增的语言整理是否忠实，没有模型横向对比。
- 输入：固定问题“第一批关税何时生效，额外税率是多少？”，出版截止2018-07-06；使用已保存语料并校验语料、检索程序、题集指纹。不重新调检索排名。
- 防泄漏：不读取政策后金额，不改因果门槛；问题已用于开发，所以不得称未见题。参考答案不额外注入模型。
- 模型：沿用现有glm-4.7及原服务地址；最多一次调用，超时60秒，不重试、不换模型刷结果。
- 采纳门槛：结构校验通过；生效日期与额外税率两项完整；每项被其引用片段支持；无批次混淆、总税率误读、现行适用性或因果过度断言。全部满足也仅记“本题生成检查通过”，不能替换默认入口或宣布独立准确率。
- 停止：配置缺失、指纹不符、网络/鉴权/格式失败、超时即停。调用前独占登记attempt.json，中断后也不得盲目重发。

入口：`scripts/run_policy_smoke.py`默认只预检；加`--execute`才调用。需要时终端隐藏输入密钥，不写文件。结果保存至`tmp/policy-smoke-13b/result.json`，密钥回显做字面脱敏；不记录错误消息、配置或请求头。
