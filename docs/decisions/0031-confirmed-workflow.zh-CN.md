# 决策0031：进程内确认与只读执行入口

用户先看到解析预览，再明确确认，程序只执行自己保存在内存中的请求副本。确认接口只收一次性随机标识，不收调用方修改过的请求。重新提问使旧确认失效；取消、拒绝、解析失败和澄清均不可执行。同一确认尝试仅使用一次，执行失败也不能自动重复。

该边界适用于本地单用户进程，不宣称能防御控制本机Python进程的攻击者，也不以哈希代替用户确认。执行时仍调用既有结构化流程重新校验能力及证据。用户确认单独记为user_confirmed，不改写intent_verified或任务质量验证指标。报告保留固定只读工具证据及因果限制，不调用模型自由生成金额。

本阶段不改旧实验，不调用API做新试验。交付交互CLI：真实模式读取已有环境配置，一次模型解析；离线demo使用标明来源的已保存响应，仍需输入确认，不冒充新生成或真实用户确认。测试用模拟确认验证原生证据流程，覆盖取消、替换、过期确认、重复确认、预览篡改及拒绝。无新依赖、无GitHub推送。
