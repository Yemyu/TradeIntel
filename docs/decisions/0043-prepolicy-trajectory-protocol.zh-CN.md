# 机械行业政策前走势诊断协议

2026-09-09，运行前锁定。对象为原资格表中行业333的158个处理和61个对照，不按本轮走势再删商品。目的为检查既定行业的加权对照是否值得继续研究，不是第四轮旧匹配或因果估计。

拟合窗口固定2016-01至2017-12，共24月；检查窗口2018-01至2018-05，共5月。月份都在政策前。早先的资格和行业选择已使用完整29月特征，因此后5月仅为权重拟合的内部时间留出，不称独立盲测。

先取每个商品log(1+中国进口金额)，减去该商品2016年的平均对数值，得到相对自身基期的走势。处理组按商品等权求平均。该目标不是行业进口美元总额，不能把对数走势差直接转换成全行业损失金额。

用24月走势拟合非负且总和为1的对照权重，每项权重不超过0.10，最小化平均平方残差加0.001乘以偏离等权的平方和。固定初值为等权，SLSQP最多1000次迭代、ftol=1e-12；不调正则或权重上限，不按检查期表现选参数。

基准一为等权对照；基准二为季节性差距基准，用2017年对应月份的处理-等权对照差距修正2018年等权对照。两个基准均仅用拟合期估计修正。本轮不能独立排除季节性，第二基准用于观察复杂方法是否优于简单季节性修正。

预先设定的继续研究门槛：检查期RMSE≤0.10对数点、最大绝对差≤0.20对数点、RMSE不高于两个基准较好者的80%、有效对照数≥20。为检查集中度，删除拟合期权重最高的一个对照，按同一规则重新拟合一次，检查期预测变化最大值≤0.05对数点。阈值是本项目推进标准，不是因果识别的通用定理，不能证明平行趋势。

最多两次权重拟合（主拟合与预定删除一项检查）。主拟合或删除检查出现优化失败、非法权重、输入缺失/重复或非有限数立即停止；成功求解后一次性计算所有预定指标，无追加规格搜索。任何门槛失败则本配置不进入政策后估计，也不改检查窗口。

仅解析2016-01至2018-05金额，其他行按年月先跳过；保存输入和协议指纹。缺失商品月停止，不补零。所有源文件、旧匹配结果和因果阻断状态保持。通过只能允许进一步设计研究和检查政策暴露/同期冲击，不能自动解除因果阻断。
