# 行业联合可比性诊断协议

2026-09-09，结果生成前记录。本轮是政策前特征的几何与集中度诊断，不是新匹配样本或政策效果实验。

目标：检验333与334行业的单项范围检查是否高估可比性，判断需要什么补充信息。基准为上一轮333的151/158、334的60/62个商品各项分别处于对照范围内。

只读政策前特征表，固定2016-01至2018-05、四项既有特征、原行业及资格标签，核验输入SHA-256。不读政策后表现，不选择政策后效果好看的行业，不修改v3停止状态。

检查一：对每个处理商品，能否用本行业所有现有对照的非负权重（和为1），同时重现其四项特征？求最小最大标准化残差；按本行业对照特征标准差缩放，零标准差用1。残差不超过1e-7仅记为数值上的几何可表示。记录数量、政策前金额占比和残差分位数，不输出采纳样本。

检查二：对每个完整行业的等权处理均值，求满足四项平均差不超过行业内处理/对照合并标准差0.09倍时的最小单一对照权重上限。0.09沿用旧设计的容差数值，但分母按行业计算，因此不冒充旧v3平衡结果。报告实际最大权重、有效样本量1/sum(w²)和最大标准化差。此处可行性只涉及均值，不代表分布、前趋势或无混杂成立；所得权重不用来计算政策后效果。

假设：单项范围通过不保证四项同时可表示；完整行业均值可能只能依赖少数对照。每个线性规划最多5秒；任何求解失败、超时或残差复核失败停止整个诊断，不自动重试，不改阈值。几何检查最多220次，行业均值2次。

采纳边界：本轮不采纳任何因果方法。若全行业均值无解或权重集中，不能直接做全行业加权回归；若通过也仍须制定前趋势、有效样本量、敏感性、干扰和政策暴露检查。精确几何支持是诊断，不是所有因果方法的必要条件；不能据此断言范围外商品永远不可研究。

补采决策：根据诊断指出对照覆盖、集中度或映射缺口；只有明确缺口后制定下载清单。增加政策后年份不能自动修复政策前对照问题。后续新研究须保留原研究失败记录，并明确新的估计对象。
