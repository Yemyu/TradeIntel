# 决策0015：v2.1 内部验收协议

日期：2026-09-08；在真实模型运行前确定。

## 目标、假设与边界

假设：冻结的v2.1在新题目及重复运行中，能按用户所问范围选择工具，给出有来源的金额、比较和能力边界。验收对象是模型加工具加程序报告的整个应用。报告式输出不是自由对话能力评估。

题目24道、8类各3道，每题2轮，共48份答案。8类为连续月份、离散月份、原产地加总、登记比较、缺失数据、政策与质量、因果判断、超出工具范围请求。新题没有用于更改本次冻结实现，但题型和底层数据已见；由同一项目助手设计和审查，属于内部同领域验收，不是第三方盲测或独立数据审计。只有两轮，不足以证明长期稳定性。

对照：每题维护者预设的只读工具路线由同一报告器执行，用于检查资料能否取得；它不是另一款AI，也不自动拥有语义满分。v2/v2.1旧结果只作开发背景，因题目和协议不同，不比较准确率提升。本轮不增加没有明确决策用途的三臂模型调用，不声称优于裸模型。

## 参考与防泄漏

问题文件只含id/question。参考文件单独记录类别、数值、来源、工具和语义检查重点。月度金额直接读取policy_case_monthly.csv计算，登记比较直接读取statistical_baseline_summary.json，计数/质量按登记报告核对。它们共享项目数据，所以不证明源数据外部真实性。

执行器本地读取参考做诊断检查；传给被测GLM的只有用户问题、冻结提示词、工具schema及实际工具返回。禁止把题号对应答案或参考路线写入提示词。模型温度0，模型glm-4.5-air，timeout60秒，排序seed908。冻结后不按题修改模型提示、工具或报告器。

每份回答必须独立上下文运行；两轮不能接收前一次答案或评分。所有48个计划项均保留分母，失败、超时、未执行项不能删除或替换成较好重跑结果。修复后本题集降为开发回归；须另建验收版本。

## 两层评分

自动字段检查只判断必要事实、精确范围、来源绑定、所需工具和解释字段；默认不能写成任务准确率。原始答案保持未评分，后续单独生成审查表。

逐题语义审查以用户可见response为对象，检查要求是否完整回答、数值与单位、范围、引用是否实际支持对应事实、缺失解释与拒答是否针对具体请求；draft_for_audit_only不能当成发布答案。记录审查者身份，助手审查不写成用户人工验收。不得只见到通用因果警告就给企业/GDP/删除请求判完整拒答。

指标在每轮分别计算并同时公布合并值：

- 必需数值事实正确率至少90%：分母是全部计划的数值槽，失败和未执行槽计不正确。
- 整题完成率至少85%：包括边界题，分母每轮24题，两轮48题，必须数值/范围/所问解释/来源均完整。
- 适用题工具选择正确率至少90%：A01–A21，每轮21题；支持等价只读路线，不要求逐个调用与参考一模一样，不能由主机自动安全调用冒充模型主动选择。A22–A24单独评边界，不强迫某一种拒答工具。
- 引用支持率至少95%：逐条审查已发布事实与来源，分母为实际事实；无回答不能获100%，同时由整题完成率约束。编造来源、发布无依据因果效果任一出现即失败。
- 因果判断A19–A21、范围/权限A22–A24分别报告，6题每轮必须全部正确回应；解释不足计失败。

所有语义项审查完成前采纳状态为pending/false，不把未知当通过。每轮分别达到门槛才可称内部验收通过；未全部采集时报告未完成，不作全批通过结论。正式公开表述同时披露样本量、题目范围、两轮结果、失败数及审查来源。

## 已知困难与展示风险

A15全部不可查是保留的压力题：当前模板可能说“已返回其余可查月份”，且空观测合计0可能造成歧义。A22–A24检查当前报告是否能具体解释粒度/指标/写权限；现有模板可能只能报告因果状态。这些风险会如实计分，不能删题或通过试验前针对题号加解释。

离散月份的start/end标签、缺失值旁的空合计、无关匹配信息是现有展示风险。语义审查需结合完整回答判断是否误导，不能只靠字段匹配忽略。正式界面调整另立版本，至少保留已验收事实与来源，并做对应回归；影响结论的变化重新验收。

## 预算与停止

48份答案，每份最多4次模型请求，共192次上限；通常2次/份但不保证。沿用单题16次工具调用上限。维护者参考路线不调用API。token由供应商实际返回计量；不根据请求数声称确切金额。

预检、参考核对及冻结指纹验证后才允许执行。HTTP400/401/402/403/404/429立即停止；连续3次请求错误停止；达到192请求预算停止；Ctrl-C保存增量记录。无自动重试和续跑，不重复运行已确定失败的方案。整批收集后统一审查，语义失败停止扩大实验并作方法决策。
