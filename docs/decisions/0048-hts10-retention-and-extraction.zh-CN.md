# Phase 12f：细分提取与原始包保留决定

## 已冻结的规则

新提取层保留政策前2016-01至2018-05共29个月的通用HTS10记录，不先过滤List1、不先合并HS6、不先筛选333行业。每个月保存中国金额、全部原产地金额、中国是否出现、明细行数、来源URL、文件名和SHA-256。

原始Census ZIP在项目数据设计基本定稿前保留在`data/raw/trade-detail/`。提取脚本没有删除选项；只有后续明确审查、对账、备份策略后，才讨论删除。中断留下的`.part`文件不视为完成包，脚本下一次会重新下载并校验。

## 单月验收

2016-01已真实执行：571,722条原始明细、15,385个HTS10，全部原产地金额164,779,238,464美元，中国金额37,120,341,155美元。两个金额与独立的HS6面板原始合计完全一致；输出15,385行，细分结果约2.9MB，原始ZIP约101MB，均已保留。合成数据测试2项通过，包含中国没有记录时保留`china_observed=0`的情况。

## 批量状态

已启动2016-01至2018-05的批量提取。脚本按月写入清单，某月完成后才记录`processed`；不会把中断月份当作完成，也不会覆盖旧HS6面板。批处理完成后必须逐月核对：29个月、每月单一年月、来源哈希一致、输出行数与HTS10唯一数一致、金额重合计一致、原始包均存在。

## 边界

这张表是可复用的数据准备层，不是新对照组，不是政策暴露分类，也不产生因果估计。完成29个月也不表示17个候选通过；后续仍需先检查跨年产品定义、政策污染和经济可比性，并冻结统一分析粒度后才能设计新实验。

如果后续决定保留全部四年，需另行扩展到2018-06至2019-12；本阶段不自动读取政策后金额，也不因拥有更细数据而改变原来因果阻断结论。
