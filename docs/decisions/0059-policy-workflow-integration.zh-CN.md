# Phase13e：统一政策生成入口

目标：将已验证的GLM受限参数、整份JSON代码框兼容、原文检索及审计接到同一CLI。此阶段是零API工程集成，不是新增模型实验。

- 不改冻结检索器、题集、提示词或旧实验记录。
- 当前统一生成仅支持已用过的GLM-4.7配置：思考关闭，最多512输出tokens，60秒超时，不重试。
- 新增运行目录，独占创建；先写入attempt和检索证据，再调用。原始文本、规范化文本、格式变更、finish_reason及基础token用量分别保存。只保留白名单字段，密钥不落盘。
- 真实生成必须finish_reason=stop；截断、过滤或未知结束状态不能作为完整回答交付。旧归档缺少该字段时，只允许明确标注的离线重放，不能补造stop。
- 单次生成调用限制；无证据不调用。模型主张只有通过原有结构及引用ID检查才展示，仍注明语义待核对。
- CLI默认仅检索；--generate显式真实调用，--replay-last只重放指纹固定的旧响应，禁止同时启用，重放不得改变问题或日期。
- 验收：用模拟模型检查错误、截断、重复调用、token记录与密钥脱敏；用原真实响应离线走完整入口。原始rejected_model_output保留，不把重放视为新模型成功。
- 下一阶段的未见问题验收需要另定假设、基准、预算及停止条件，本次不自行扩大调用。
