# 决策0033：组合规划六题开发验证

运行前修正提示拼接冲突：末尾明确多任务规则覆盖旧单任务澄清规则，顶层必须使用计划结构。不是运行后改提示。

假设：GLM-4.7能在一次规划调用中完整保留1至3个明确任务，且对歧义和不支持的请求不静默替换。对照为旧单任务入口只接受单任务的契约；本轮不追加收费基线调用，也不声称量化优于旧模型。

六题仅为开发：P01三任务政策/明确比较/因果条件，P02质量+中国两月金额，P03比较窗口含糊需澄清，P04政策+德国请求整体阻断，P05排除删除指令后的政策+质量，P06同一范围两个连续月份的共享条件展开。

配置glm-4.7、temperature0、thinking disabled、2048输出tokens、180秒超时。最多6次，每题一次，无重试。首次通信异常或模型请求工具停止；有效返回的语义/格式失败继续记录。题、参考、运行代码及依赖冻结SHA-256。参考只宿主读取，模型只见固定提示及问题。

先匹配完整有序任务请求与期望状态，再逐题审查引用/否定/共享条件，不能仅凭JSON合法通过。6/6才允许进入新题验收设计，任何危险操作放行、范围替换停止采纳。未调用项保留六题分母。不自动确认或查询金额；后续离线模拟确认需单独标明。
