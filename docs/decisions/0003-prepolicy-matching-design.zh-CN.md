# 决策 0003：政策前匹配设计

- 状态：已冻结，等待执行
- 日期：2026-09-01
- 适用阶段：Phase 09

## 为什么先冻结规则

匹配的目标不是“找到政策后走势最像的商品”，而是在不知道政策后结果的前提下，给每个处理商品找到政策前最相似的未受同期贸易措施直接影响的商品。若先看政策后结果再改特征、行业或对照组，得到的效果会混入人为挑选，这叫结果导向选择或数据泄漏。

因此，本阶段在运行匹配前固定特征、距离、权重、覆盖率分母和平衡性门槛。执行后即使结果没有通过，也只报告失败原因，不根据政策后结果改规则。

## 样本与信息边界

- 处理候选和对照候选只来自 Phase 07 已通过的资格表。
- 只读取 2016-01 至 2018-05 共 29 个月的结果变量。
- 2018-06 及以后数据不得用于计算特征、选择行业、选择对照或调整参数。
- 一个商品必须只有一个 `NAICS3` 候选才进入主匹配；缺失或存在多个候选时不猜测，记录排除原因。
- 覆盖率分母仍是 Phase 07 的全部 315 个处理候选，不能先删掉难匹配商品再让比例显得更高。

## 四个连续特征怎样定义

对每个 HS6 补齐 29 个月；某月没有记录按进口额 0 处理。

1. `log_mean_monthly_china_import_value`：先计算 29 个月中国进口额的算术平均，再取 `log(1 + 平均值)`。它表示典型进口规模，并压缩极端大金额造成的差距。
2. `pretrend_slope`：把每月中国进口额变成 `log(1 + 金额)`，再对月份序号 0 至 28 做一元线性回归；斜率表示政策前每月上升或下降的速度。
3. `monthly_volatility`：29 个 `log(1 + 月度金额)` 的样本标准差；它表示商品进口是否稳定。
4. `china_share_of_all_origin_imports`：29 个月中国进口额之和除以同期所有来源进口额之和；它表示该商品对中国供给的依赖程度。使用“总额比”而不是逐月占比平均，可避免某月所有来源为 0 时出现无定义值。

## 怎样判断“相似”

先要求处理与对照处于同一个 `NAICS3`，再比较四个连续特征。因为金额、趋势、波动和占比单位不同，不能直接相加；每个行业内都用该行业合格对照的均值和样本标准差进行标准化。

标准化后使用欧氏距离。每个处理商品选择距离最近的 3 个对照；允许同一个优质对照被不同处理商品重复使用。距离完全相同时按对照 HS6 编码升序决定，保证重复运行得到相同结果。若行业内某特征的对照标准差为 0，该特征在该行业不提供区分信息，距离贡献记为 0，并在审计报告中列出。

每个匹配边的权重为 `1/3`。因此每个处理商品在总体比较中仍贡献 1 个单位；一个对照若被多个处理商品使用，其总权重会累加。这不是复制数据，而是在表达该对照承担了几个“反事实参照”的角色。

## 两个验收门槛

### 1. 匹配覆盖率

至少 80% 的 315 个处理候选必须获得至少 2 个合格对照。匹配前审计显示，284 个处理候选有唯一 NAICS3，且各自行业内至少有 3 个唯一 NAICS3 的合格对照；理论最高主匹配覆盖率为 `284 / 315 = 90.16%`。

这只是可行性检查，不代表匹配已经通过。实际输出还必须验证特征值完整、距离可计算且每个匹配关系正确。

### 2. 政策前平衡性

对四个连续特征分别计算标准化均值差（SMD）：

`SMD =（匹配后处理组均值 - 匹配后加权对照组均值）/ 匹配前两组合并标准差`

四个特征都必须满足 `|SMD| < 0.10`。分母固定使用匹配前、NAICS3 唯一的合格处理与对照池，因此不能靠匹配后方差变化美化结果。同产业匹配另行报告为 100% 的硬约束，不把分类编码强行计算成连续变量 SMD。

## 假设、基准与停止条件

- 假设：大多数处理商品能在相同三位 NAICS 行业内找到至少两个政策前规模、趋势、波动和中国份额相近的清洁对照。
- 对照基准：匹配前全部 NAICS3 唯一的合格处理与对照池。
- 防泄漏规则：政策后结果不得进入任何选择或调参环节。
- 采纳门槛：覆盖率至少 80%，且四个连续特征的绝对 SMD 全部低于 0.10。
- 停止条件：任一门槛失败，就保留特征、配对和失败报告，但状态停在 `blocked_before_pretrend`；不得进入事件研究，也不得查看政策后结果来重新挑对照。

## 本决策没有声称什么

通过匹配只能说明观测到的政策前特征更接近，不能证明处理组和对照组在所有不可观测因素上完全相同，也还不能证明平行趋势。后续仍需单独运行政策前趋势检验；只有匹配和平行趋势门槛都通过，才允许估计和解释政策效果。
