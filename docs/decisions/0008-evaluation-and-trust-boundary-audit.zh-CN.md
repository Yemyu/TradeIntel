# 0008：评估与证据边界审查

日期：2026-09-06。范围：修复离线评估与模型—工具边界，不运行第四次匹配实验。

## 先冻结本阶段判断

1. 60题已用于开发，只是开发回归集。原报告直接回答对照没有实际模型调用；撤回所有预设失败分数，记为未运行。工具结果字段通过不等于最终文字正确。
2. 证据包由程序用本次真实执行结果生成。模型只能调用五个查询工具，不能提交自己的证据包。保留内部打包函数，不扩大模型权限。
3. 每次有证据的回答都检查因果状态。错误结果不能作为成功证据；因果状态未知或读取失败时停止输出。关键词检查只作为风险筛查，不宣称能证明自然语言安全。
4. 未经最终答案评估的模型原文标为待复核草稿；自动替换的固定拒答单独标记，不能混算成模型答对。
5. 缺失月份保留空值，总计仅在完整窗口计算；部分观测合计单独命名，不能用零填充后冒充完整总计。

## 本阶段验收

旧对照没有捏造分数；开发题重跑；攻击回归覆盖伪造证据包、错误工具、非因果提问中的因果断言、带免责声明的因果断言、未知状态、过多工具调用、缺失月份。所有新增验证均使用离线桩或现有证据，不调用付费服务。

## 历史统计审查边界

v3 第一阶段带有252个最低保留约束。求解器 infeasible 只表示该联合约束下没有可行解；输出 selected_treated=0 是未产生解的占位，不能解释成真实最大可匹配数量为零。保留历史数值文件，用解释性更正和工具语义消除误读。未重新证明最优可匹配数量，也未全面重审原始贸易面板与所有统计实现。

## 下一阶段真实模型评估设计

- 假设：固定证据工具提高最终答案的事实正确性与可追溯性，同时限制无依据因果断言。
- 对照：同一模型、同一问题、相同生成配置的真实直接回答；另设同证据上下文的直接回答，以区分信息增加与工具编排的作用。工具选择仅评估Agent组，不把对照没有工具计成错误。
- 防泄漏：现有60题归入开发集。完成方案和提示词冻结后，另建按任务模板分组隔离的至少40题最终测试集；不从旧题随机改写后声称独立。测试题与答案不提供给被测模型，只有当前问题及允许的证据。公开题集无法证明预训练无污染，只能控制本项目开发泄漏。
- 评分：人工逐条对照最终可见文字的数字、方向、单位、时期、商品/原产地范围和引用支持关系；检查拒答是否适当以及是否先拒答又断言。工具中有来源不等于答案引用正确。保留模型原稿、最终输出、工具日志、后处理触发记录、模型配置、错误、耗时与可取得的token用量。
- 采纳门槛：最终答案数值事实正确率≥90%，实际引用支持率≥95%，应拒因果题正确拒答率≥90%，不支持的因果断言为0；另要求可回答题任务完成率≥85%，防止全部拒答拿高分。各项公布分母，空分母为未测；超时与调用失败计任务失败。至少重复3轮报告波动，不只挑最好一轮。
- 停止条件：出现无依据因果断言、证据伪造或关键指标不达标，不公开效果声称；修复后原测试集降为回归集，新建测试集复核。没有真实调用记录，所有真实模型指标保持未测。

方法参考：[OpenAI官方评估实践](https://developers.openai.com/api/docs/guides/evaluation-best-practices)。这里采纳其任务化评估与独立测试原则；具体分组、指标和门槛是本项目的设计选择。
