# 决策0011：v2由模型选择工具、程序展示证据

日期：2026-09-07。依据真实v1批次暴露的问题实施修复。本文件是开发决策，不是新的正式模型实验预注册。

## 决策与代价

v1源码、40题、标准答案、冻结清单和原始模型运行记录不修改。新增 `evidence_v2.py` 和独立CLI。v2继续使用原有有界工具调用循环，模型可选择五个只读工具。模型自由文本保存在 `draft_for_audit_only`；用户可见 `response` 由工具数据生成，不发表未经语义核验的模型解释。

这会牺牲自由文本总结与复杂改写能力，输出更接近带来源的证据报告。它修复“正确事实被整段删除”和“模型改写数字/引用”两种展示问题，但不保证模型选对月份、选足工具或完成整个用户任务。`task_success_verified`和`final_answer_verified`仍为false，状态为needs_review。旧关键词检查仍存在于复用的v1内部流程中，v2不再用其替代句作最终报告，记录legacy_guard_triggered仅作审计。

## 实施内容

- 因果准备工具补充315个合格处理商品分母、284个至少有两个对照的处理商品数及HS6_2017粒度；与818个HTS8政策商品数区分。
- 描述性比较工具补充三种原产地、基期与当期的准确美元总额。百分比由工具比例以Decimal乘100后展示，美元整数不交给模型改写。
- 每个展示事实绑定工具返回的已登记来源；贸易比较绑定统计摘要，匹配计数绑定匹配报告，政策商品数绑定商品文件。模型生成的链接不进入证据目录。
- 同一政策/范围/HS6/原产地的多次月份查询做去重合计；同月数据冲突则拒绝，缺失月份使完整合计保持null，不同原产地不混加。
- 数据质量总额直接显示美元整数，避免单位换算错位。来源路径和哈希直接来自仓库工具。
- 未取得任何成功工具结果仍报错；不能以模型编造的答案填补。任意SQL等权限不扩展。

## 验证与停止条件

离线测试覆盖合理否定与肯定越界、原稿隔离、计数粒度、正确来源、隔月求和、重复月份、冲突值、缺失值、无工具和五工具展示。

固定回放旧批次120个Agent槽中的111个生成完整轨迹，全部生成证据报告；9个原生成失败槽跳过。21条旧替代回答均重新保留查询事实，展示事实均有登记来源标识。回放不改变旧模型决策，也不让模型重新阅读新增字段；此结果仅支持输出模块回归，不是新的真实模型正确率或因果提升证明。

出现没有来源、同月冲突、未知字段/来源结构时停止出报告。模型接口错误由CLI明确返回失败。v2没有自动重试、自动升级模型或自动扩大请求预算。

下一次真实评估前须设计新的测试版本，明确证据报告任务与自由文本任务的区别，以及三组对照如何匹配。旧40题在修复后仅作开发回归，不能用于独立验收声明。
