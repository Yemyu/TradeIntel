## 本次修正

- validate_plan增加显式host_alignment参数，要求完整request_units信封；宿主重新从原文和原始模型units推导位置、字符及来源，再比较整份对齐产物。模型不能提供gap元数据替代宿主推导。gap没有被标为context。

- 审查前校验来源指纹；过期来源使待确认状态作废。空确认凭据不能消耗待审查计划。通过gap审查后仍展示逐项需求、范围和语义未验证标志。
- 四题开发检查增加显式host_gap_review模式，清单模板包含gap审查。先同时验证原有语义必答点与每个gap，再把批准记录传入工作流。缺记录、负面范围审查、文件篡改均在后续生成前停止。
- 开发CLI可选`--allow-host-gap-review`，快照标为development-smoke-0103，保留默认旧模式。单题CLI保存预览、原始审查提交和结果；审查理由由用户填写，拒绝记录也保留。

本轮没有改变模型提示、研究范围、因果门槛或分隔白名单。0101的失败记录仍保持原样。审查是人工/外部审查者判断，程序检查的是记录和绑定，无法自行证明语义正确。
