# 决策 0004：全局平衡的最优匹配实验

- 状态：已执行，但无可行解，继续阻断于前趋势之前
- 日期：2026-09-01
- 实验编号：`globally_balanced_optimal_matching_v2`

## 先澄清：上一次是谁“没跑通”

Luna 已经正确执行了冻结的三近邻算法。失败的是研究方法在当前数据上的验收结果，不是 Python 没有运行，也不是换一个模型重跑同一段代码就会随机通过。

Sol 高对原始面板、特征表、配对表和报告进行了独立复核：

- 1,208 个候选的四项特征独立重算后，与输出的最大误差低于 `5×10⁻¹³`；
- 政策前正进口月份与 Phase 07 资格表的差异为 0；
- 852 条处理—对照边全部唯一，全部满足相同 NAICS3，每个处理商品恰好有第 1、2、3 名三个对照；
- 所有特征和匹配记录的政策后活动使用标记均为 0；
- 配对总权重为 284，与 284 个进入主匹配的处理商品一致。

因此，首次结果 `blocked_before_pretrend` 是可信的设计失败记录。

## 首次设计为什么失败

三近邻分别为每个处理商品选择距离最小的三个对照，但它没有直接约束“所有匹配对加总后，两组的平均特征必须平衡”。单个商品的局部距离最小，不保证整体 SMD 最小。

审查还发现两个重要现象：

1. 33/284（11.6%）处理商品的中国进口份额低于本行业所有合格对照的最低值，说明这一维存在共同支持不足；
2. 852 条边只使用了 115 个不同对照。按复用权重计算的对照有效样本量约为 52.16，单个对照最多被复用 33 次，说明结果过度依赖少数商品。

其中 NAICS 335 对整体中国份额差异贡献尤其明显：处理组平均份额约 0.115，而首次匹配的加权对照约 0.329。NAICS 334 则是政策前趋势差异的重要来源。

这些诊断只使用 2016-01 至 2018-05 的政策前特征，没有查看政策后结果。

## 新实验的假设与基准

- 假设：在保持同产业、每个处理商品三个对照和可解释距离的前提下，全局同时选择所有配对，可以改善总体平衡并减少对少数控制商品的过度依赖。
- 对照基准：已冻结且失败的三近邻结果。其覆盖率为 90.16%，平均距离为 0.828732，95 分位距离为 2.199300，对照有效样本量为 52.16，最大复用 33 次。
- 防泄漏：仍只使用四个已冻结的政策前特征和唯一 NAICS3；不改变 Phase 07 资格，不读取 2018-06 及以后的结果。

## 新方法是什么

把全部允许的“处理商品—同 NAICS3 对照商品”组合一次性交给整数优化器决定，而不是逐个处理商品独立选择。

优化器必须同时满足：

1. 284 个 NAICS3 唯一的处理商品各选择 3 个不同对照；
2. 每条边必须在相同 NAICS3 内；
3. 同一对照可以服务不同处理商品，但最多复用 10 次；
4. 四个政策前连续特征的总体绝对 SMD 在求解时都不得超过 0.09；
5. 满足以上硬约束后，最小化全部边的标准化欧氏距离总和；
6. 若多个解目标值相同，按处理 HS6、对照 HS6 的字典序作确定性次级选择。

这里的“整数优化”不是 AI 模型。它是在许多允许的配对组合中寻找满足硬约束且总距离最小的组合。AI 负责帮助我们设计、实现和审计规则，优化器负责按照规则求解。

## 为什么优化约束用 0.09，最终门槛仍是 0.10

整数求解器会使用浮点数并允许极小数值误差。内部要求 `|SMD| ≤ 0.09`，为最终公开门槛 `|SMD| < 0.10` 留出余量。它不是在降低标准，反而比最终门槛更严格。

## 采纳门槛

新方案只有同时满足以下条件才允许进入政策前趋势检验：

- 至少 80% 的全部 315 个处理候选获得不少于两个对照；
- 四项连续特征最终都满足 `|SMD| < 0.10`；
- 加权对照的有效样本量至少为 100；
- 任一对照的复用次数不得超过 10；
- 平均标准化距离不超过 1.035915；
- 距离 95 分位数不超过 2.749125。

后两项等于首次三近邻基准的 125%。它允许全局平衡为部分商品选择稍远但仍合理的对照，同时阻止优化器只为了总体均值而制造大量非常差的个体配对。

## 停止条件

若整数问题无可行解，或者求得的配对违反任一采纳门槛：

- 保存可行性和失败原因；
- 状态继续保持 `blocked_before_pretrend`；
- 不生成供事件研究使用的候选面板；
- 不查看政策后结果；
- 不在同一个实验中临时提高复用上限、放宽 SMD 或距离门槛。

## 这次改规则是否算“作弊”

不算，前提是完整保留第一次失败记录，并且新规则在再次运行前写清楚。因果研究的设计阶段本来就允许只根据处理前协变量检查重叠和平衡并改进设计；禁止的是根据政策后结果选择最有利的对照或参数。

本项目会同时保留第一次三近邻的特征、配对和失败报告。第二次实验不会覆盖第一次失败证据。

## v2 执行结果

v2 已在项目虚拟环境中用 SciPy/HiGHS 执行一次，生成了求解器审计报告。问题共有 14,671 条允许的同产业处理—对照边，706 组线性约束；求解器返回 `Infeasible`，不是超时，也不是 Python 异常。

这意味着在本实验同时要求“每个处理商品 3 个对照、同产业、每个对照最多复用 10 次、四项总体 SMD 不超过 0.09”的情况下，当前候选池不存在满足全部约束的组合。按停止规则，没有放宽复用次数、SMD 或距离门槛，也没有读取政策后结果。v2 没有生成候选面板，状态为 `blocked_before_pretrend_v2`。

因此 v2 不能被称为成功方案，但它回答了一个重要问题：第一次失败不是简单地换成“更强的优化器”就能解决；数据中的共同支持和候选池结构本身可能不足。下一步若要继续，必须由 Sol 高重新设计第三个实验，或者把“可信地拒绝因果结论”作为本案例的研究结论之一。
