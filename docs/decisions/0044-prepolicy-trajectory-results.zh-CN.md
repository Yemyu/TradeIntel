# 机械行业时间检查结果

依据0043冻结协议执行。主权重拟合与删除最高权重对照后的敏感性拟合各一次，无调参、无政策后估计、无模型API。

结果：训练RMSE 0.0005591706；2018-01至05检查RMSE 0.1055459196、最大误差0.1978898955；等权基准RMSE 0.2412774599，季节性差距基准0.3685158482。主权重最大0.0712692670，有效对照23.61285；删除最高权重后的检查预测最大变化0.0365688558。

唯一未达标项为RMSE≤0.10。按协议不推进政策后效果计算。0.10是项目规则而非因果真假界线；此结果不得表述为证明不能识别或没有政策影响。

检查期逐月目标减预测差为：1月0.005918，2月-0.065038，3月0.110490，4月0.197890，5月0.008139（对数走势单位）。不删除3月/4月，不改变时间窗或门槛，不追加参数试验。

目标为158个商品相对2016基期的log1p进口等权平均，不是机械行业总进口额。行业资格使用过整个政策前29月，只有权重拟合未用后5月；不是独立留出。残差改善不等于平行趋势成立。
