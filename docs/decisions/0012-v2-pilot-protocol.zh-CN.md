# 决策0012：v2八题开发试验

日期：2026-09-07；首次v2模型试验前确定。阶段目标是检验新增字段与程序证据报告是否可用于真实调用，不是最终作品集独立验收。

## 假设与对照

假设：v2把确定性事实展示移交程序后，真实模型仍能选出足以回答问题的工具与范围；新增计数与金额字段可获得正确展示。先用8道题、单轮、同一个glm-4.5-air运行，temperature=0、timeout=60秒，固定seed=207排序。

实验路线：模型选择只读工具，v2程序展示证据。参考路线：维护者预先写好的工具与参数，由同一v2程序执行和展示，不调用模型。这是工具选择诊断的参考，不是“另一个AI”，不代表独立外部标准，也不能据此说编排带来因果提升。参考轨迹与答案不得传给模型。模型消息仅含id对应的question、原Agent提示词、五工具schema及其实际返回结果。

继续沿用原Agent提示词，变更只有既有v2代码和schema字段说明。旧40题已参与开发，本次8题也是同领域开发试验，不宣称新领域泛化或独立最终测评。更改v2后不能继续将此八题当作未见数据。

## 问题与参考来源

8题覆盖连续月份、非连续月份、多原产地、政策前比较、粒度不同的匹配计数、可答与不可答混合问题、错误政策便签、金额与质量联合查询。问题文件只允许id/question，参考文件与运行指纹分开保存。

美元参考数通过读取底层policy_case_monthly.csv独立整数计算取得；2018/2017年1—5月比较读取statistical_baseline_summary.json；政策与匹配计数分别以商品文件和v1报告为准。参考取数与被测系统共享底层数据，不是外部数据审计。离线先验证人工路线能生成所要求的数据字段；这只验证试验配置，不算AI通过。

## 自动检查与人工判断

自动检查：实际查询成功的月份/原产地集合是否精确匹配（不同HS6范围不能冒充整体）；所需工具是否由模型选择；预先指定的展示数值与对应来源是否存在；每条事实是否绑定来源；请求是否正常以stop结束。这些均为必要条件，不能算完整语义准确率。

人工检查：单位和整体范围、额外查询的无关内容、是否解释不可答部分、报告能否满足用户意图。所有task_completed与manual_semantic_review初值为null，绝不由字段匹配自动赋true。尤其V206：程序可能展示2018-11金额却没有明确解释2015缺失，必须如实判为部分回答；人工参考路线也不自动视为完整回答。

## 试验后的决策规则

只有8题均有完整运行记录、所有必要自动检查通过、人工确认所有题完整回答且没有无依据事实/错误归因，才可进入下一步的正式验收设计。这只是小样本阶段门，不代替原正式指标，也不证明准确率100%。出现失败则保留、集中诊断；不就地重跑挑最好结果。正式验收需另建版本与任务尺度；v2报告式输出与v1自由文本的结果不能直接宣传成公平模型排名。

## 运行与停止

最多8×4=32次模型请求；参考路线API请求0。每题显示开始、结束和累计次数，逐请求JSONL保存；整批结束或正常中断保存汇总JSON。无自动重试、无自动续跑；连续三次请求错误停止，配置/权限/额度HTTP错误立即停止。超时与异常保留为失败，未执行题不从计划分母删除。Key以getpass隐藏输入，配置地址与模型固定；同名输出拒绝覆盖。

在第一轮调用之前用v2_pilot_manifest.json冻结本协议、题目、参考、运行代码及证据文件。原v1冻结文件保持不变。任何运行前的文件差异先中止并审查，不静默更新指纹。
