# 0116：修复假完成路径并接通可审计的 A/B 对照

> 0117复审更正：本文后半段“完整冻结、验收绑定、事实召回”完成声明未通过审查。空审核可放行、B否定句误评分、A遗漏变化额已修复；正式验收仍未就绪。当前依据见[0117](0117-acceptance-reaudit.zh-CN.md)，以下保留为历史记录。

## 结论与证据

0115的581项测试通过属实，但覆盖不足。“A为独立计算”“A/B已完成”“合成整链完成”表述撤回。0116先撤掉占位路径，再把两条控制接回运行器：A直接读取声明的源表复算贸易金额；B使用同一政策问题和历史范围，但不发送检索证据，保存并评估模型真实回答。已有0109真实开发演示不受此结论影响。

审查直接核对了0114规范、运行代码与测试。新增`tests/test_runner_audit_0116.py`，修复前5项均未通过（4失败、1错误）。具体问题：

| 问题 | 原实现的实际行为 | 本轮处理 |
|---|---|---|
| A对照没有计算 | 直接写`status=pass`，无结构化请求、数值或复算 | `control_a:<case>`直接读取贸易源表，逐月比较series和total；不一致会停止 |
| B对照忽略回答 | 强制要求拒答；程序填`needs_scope_selection`和`verified=true`，fixture审查对fact自动通过 | `control_b:<case>`保存实际文本、解析结果和事实召回；答错记录为baseline gap，不伪造通过 |
| 无审查也能完成 | 直接mark accepted，未调用模型、无审查材料也能finalize | 只有`approve_question`能写入绑定；`finalize_reviewed`检查计划/答案审查、交付哈希和validated控制 |
| 审查时报告可变 | inspect只在审查前执行，修改报告后仍可通过 | 审查后及批次收尾重查实际交付；保存验证决定 |
| 工厂拿到金标准 | 整个SyntheticCase传给模型工厂，包含reference、expected_tasks、checklist | 工厂仅收到id和question；按实际preview.tasks选择回答阶段 |
| 快照只有题号 | 仅冻结三个代码文件和case_ids，没有完整题文及清单 | 冻结运行器、工作流、源表、政策事件、语料、完整案例和清单；调用时保存消息 |

另外，fixture标签不能阻止调用者注入联网模型；本轮测试使用的是本地测试替身，0外部API，不能将其概括为运行器具有网络隔离保证。原始响应元数据现只保留用量等允许字段，运行器仍不作为真实凭据入口。

## 验证结果

修复后相关34项通过，完整回归589项通过（约27秒）；均为本地测试替身，0外部API。新增正向A/B测试和伪造validated控制反例；旧“controls已通过”“finalize可完成”测试继续核对无绑定时不能闭合。测试数量说明回归规模，不等于模型质量分数。

## 保留的有效进度

贸易与政策fixture测试继续执行真实`build_product_workflow`和本地数据/语料，报告与交付文件保存。模型调用前预约、用量未知停止、固定未运行题记录继续有效。带完整控制的离线合成案例现在可以得到`acceptance_ready=true`；这只证明协议和数据链路接通，不是模型语义准确率。

控制组的失败不是GLM回答错误，而是我们的测试实现没有做到规范要求，应由实现修复承担，不能归咎于模型或研究数据。

## 当前边界与后续要求：审查后再决定是否解冻在线题集

本轮已经接通以下内容：

1. **计划/答案审查。** 运行器使用结构化逐项审查；提供完整旧版清单字段的案例还会调用`answer_checklist.validate_review`作为附加审计。简单fixture清单不被冒充为语义证明。
2. **A控制。** 对贸易案例冻结请求并走现有只读工作流；另用`policy_case_monthly.csv`（或明确HS6面板）直接复算，记录源文件哈希、逐月series、总额和比较结果。
3. **B控制。** 同一政策问题和日期进入模型，但消息没有检索片段或工具；保存实际回答，记录事实命中率/缺口，不要求模型先拒答，不自动重试。
4. **完整冻结与消息审计。** 快照包含运行器、工作流、源表、政策事件、语料、完整题文和清单；模型工厂仅收`id/question`，响应文件保存消息和安全元数据。
5. **绑定完成条件。** 每题必须有通过的计划审查、答案审查、完整交付哈希和适用`validated`控制；单独写`accepted`或放一个控制文件不能闭合。
6. **当前验证边界。** 589项离线测试和34项0116相关测试通过，0外部API。尚未启动新的GLM题集，因此不发布独立模型准确率，也不解冻0111在线入口。

采纳门槛：A/B控制、绑定和负向反例有代码与测试证据，但这不等于模型质量分数。后续审查本次差异、旧版清单适配和是否保留当前合成题；通过后再执行不联网预检。当前API、正式题与因果结果不变。
