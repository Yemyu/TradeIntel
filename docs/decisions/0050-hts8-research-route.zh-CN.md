# Phase 12h：确定HTS8研究路线与资格盘点口径

## 选择与理由（在新盘点前锁定）

下一条候选路线统一使用“稳定HTS8商品×月份”，研究333机械行业中原始List1分配与中国进口金额变化的关系。List1本来按HTS8列示，这比把同一税号的多个HTS10统计子码当独立政策实验更合适。后续推断至少要考虑HS6家族内相关性，不能靠拆码制造独立样本。

主路线优先使用没有现有同期政策直接覆盖的HS6家族中的HTS8作对照；17个来自混合/政策覆盖家族的线索放在机制研究备选，不加入主对照。家族内未覆盖商品可能获得替代需求，因此其变化可研究“相对变化/替代”，但直接拿来估计加税商品的总效应需要额外假设。

政策表没有覆盖不等于绝对没有间接影响。选择这条路线只是降低明显的直接污染，仍需行业需求、供应链、政策选择和预期变化的论证。也不声称因果研究只有这两条路线：贸易结构模型、其他市场比较等另有识别和数据要求。原0049“两条路线”应理解为当时细分分支的备选。

参考研究：[Fajgelbaum等，The Return to Protectionism](https://www.nber.org/papers/w25638)研究2018贸易战；[Handley等，供应链与出口](https://www.nber.org/papers/w26611)使用企业贸易关联研究关税对出口的影响。这些工作说明研究可以开展，也说明同一政策可能经多个渠道传导；不能将论文的识别或成绩直接移植到本项目。

## 本轮交付：仅年度元数据资格盘点

固定读取2016、2017、2018官方年度商品表及既有政策HS6表、List1清单。先按HTS8收齐所有子码：三个年度子码集合完全相同、每个子码描述和计量单位完全相同、行业标签稳定且同属一个NAICS4、属于333、历史有效区间覆盖2016-01至2018-05才进入元数据候选。历史有效区间在现有映射中以同一连续区间表示；不能确认的代码标记待审，不猜测补齐。

处理：原始List1 HTS8，所属HS6不存在现有其他同期政策覆盖。对照：其HS6不存在现有任何政策范围。统一按NAICS4报告候选数，不能看政策后金额挑行业。本轮不使用贸易金额、不拟合、不选择最显著行业。若某行业没有两侧候选，列为不具备本轮比较基础。

年度商品表一致只是保守的元数据门槛；年度快照无法证明每月所有有效子码均被收录，派生面板仍须检查保留ZIP中的历史代码和按月有效性。

## 后续实验进入条件与停止条件

本轮基准为旧333 HS6失败诊断；新盘点计数不与旧模型RMSE当作同类成绩比较。新模型尚未启动。接下来用已有29月明细做HTS8派生层，分别报告缺记录、观察零金额、编码不适用和汇总覆盖；维持至少24个正金额月份的既有活跃度标准作为资格盘点口径，不称其为训练。

先交付全部候选的规模、家族数量、金额覆盖及排除清单，再根据经济问题锁定唯一实验协议（处理效应定义、权重、基准、统计精度目标、时间检查与停止门槛）。缺少该协议时不拟合，不补政策后数据。2016—2018政策前数据已参与多轮开发，时间切分不能再宣称完全独立盲测。

若稳定编码/月度覆盖或同用途比较基础不足，记录具体原因，停止这条细分主分支；不降低旧匹配门槛或把17个混合家族代码救回凑数。保留已完成的描述性分析和AI产品路线。

原始29个ZIP继续保留，删除须另行与用户确认。
