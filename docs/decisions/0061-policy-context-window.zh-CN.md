# Phase13h：同页上下文窗口开发协议

假设：旧检索命中的短片段可能遗漏附近限定句。在不改变检索排名和题目的前提下，同页前后各扩600字符可以补齐部分限定条件。

基准：冻结BM25前三片段；对照为相同命中扩窗，最多3个窗口、每窗2400字符，总计7200字符。长度是字符，不是token，不宣称成本不变。

规则：仅在已索引正文范围内扩展，不越过页边界或进入首页夹带通知；保留原片段，生成独立窗口ID和精确字符位置。重叠窗口暂不合并，以保持排名和来源映射可检查。记录重复字符开销。

验证范围：已暴露的8题仅做离线开发比较，不调用模型、不称未见验收。检查原命中全部保留、原文可精确定位、长度不越界、日期和拒答边界不变。P03检查关键税费叠加短语能否进入上下文；这个定位指标不是回答正确率。

采纳门槛：全部结构边界通过，P03限定句被补回；通过也仅保留实验性扩窗模块，不替换默认检索、不修改已冻结实验。逐题观察额外内容与成本，不能保证新增文字都相关。

停止：任何边界失败即停；若600字符未补回P03，不当场调大窗口试到成功。无新API、无数据补采、无因果估计。本轮只改上下文，不同时改批次和时间提示，以免无法区分改动。
