# 决策 0006：最大基数平衡子样本匹配 v3

- 状态：已执行；第一阶段在覆盖门槛下无可行解，按停止规则阻断
- 日期：2026-09-01
- 实验编号：`maximum_cardinality_balanced_overlap_matching_v3`

## 为什么重新考虑第三种方法

用户要求用 Sol 高重新审查 v2。重新检查后发现：v2 强制 284 个 NAICS3 唯一的处理商品全部各取 3 个对照，但原始协议的覆盖门槛是全部 315 个处理候选中至少 80%，也就是至少 252 个。

这两条规则并不相同。v2 回答的是“能否让全部284个都留下并同时达到平衡”；它的无可行解不能证明“任何覆盖率达标的平衡子样本都不存在”。因此，直接终止所有匹配尝试偏保守，第三个实验有独立的方法依据。

这不是因为换成更聪明的大模型后同一个优化器会随机得到不同答案。HiGHS 对 v2 的无解判断仍然有效。Sol 高的作用是发现研究问题可以换成一个更符合原始覆盖门槛的数学设计。

## 政策前诊断

诊断仍只使用 2016-01 至 2018-05：

- 315 个处理候选的 80% 向上取整为 252；
- 284 个处理商品有唯一 NAICS3，因此最多允许政策前剔除 32 个仍可通过覆盖门槛；
- 275 个处理商品的第三近邻距离不超过 v2 预先固定的 95 分位距离上限 2.749125；
- 33 个处理商品的中国份额落在本行业对照范围之外；
- 完全处于中国份额范围内的处理商品有 251 个，刚好比覆盖门槛少 1 个。

这些数字说明可行性处于边界附近：第三种方法可能找到覆盖252个以上的整体平衡子样本，也可能仍然失败。因此需要一次正式、预注册且最后的求解，而不是凭直觉宣布成功。

## 执行结果（2026-09-01）

正式运行的第一阶段 HiGHS 状态为 `Infeasible`（status code 2），不是超时。也就是说，在至少保留 252 个处理候选的前提下，四项政策前平衡、同产业三对照和单个对照最多复用 10 次不能同时成立。因为第一阶段没有解，第二阶段没有运行，政策后面板也没有读取。

本次结果把原来的假设改写成了可检验结论：问题不只是“强制保留全部 284 个”过于严格；即使允许政策前透明剔除，当前冻结的联合门槛仍无法达到原始 80% 覆盖要求。`matching_balance_report_v3.json`、`matching_balance_report_v3.md` 和退出清单保存了求解器状态、门槛及审计信息。

### 约束归因审计（只读，不是第四次匹配）

为判断失败是否只是某一条代码或某个单独限制造成，另做了不改变主实验的可行性检查：

| 保留的约束 | 最大可行处理数 | 说明 |
|---|---:|---|
| 同产业、三对照、复用≤10，不加四项平衡 | 284 | 说明同产业边和复用容量本身足够 |
| 四项平衡、同产业、三对照，不限制复用 | 284 | 说明四项平衡单独并非无解 |
| 只保留中国份额平衡、复用≤10 | 267 | 中国份额是最明显的单维共同支持瓶颈 |
| 四项平衡 + 复用≤10，并要求至少252 | 无可行解 | 这是正式 v3 的完整规则 |

这些检查支持“联合约束冲突”而不是“没有任何对照”的归因。它们只用于解释阻断原因，不改变预注册门槛，也不产生可用于因果估计的样本。

## 新方法：最大基数匹配

每个处理商品增加一个二元变量：

- 1：进入本轮重叠子样本，并必须选择3个同产业对照；
- 0：因政策前共同支持不足退出本轮子样本。

优化分两步：

1. 在覆盖至少252个处理商品、同产业、每个处理3个对照、单个对照最多复用10次、四项总体 SMD≤0.09 的条件下，最大化保留的处理商品数量；
2. 固定第一步得到的最大数量，再最小化全部配对的标准化距离。

与 v2 相比，v3 不是放宽平衡或复用标准，而是允许优化器用政策前特征识别缺乏共同支持的处理商品，并把它们透明列出。

## 假设、基准与防泄漏

- 假设：v2 无解主要来自强制保留全部284个处理商品；至少252个处理商品可能构成满足平衡、复用和距离门槛的重叠子样本。
- 基准：v1 的90.16%覆盖但两项SMD失败，以及v2的全284样本无可行解。
- 防泄漏：只使用原来的四项政策前特征和唯一 NAICS3；不得读取2018-06及以后结果决定保留谁。
- 可追溯：所有退出的处理 HS6 必须保存 NAICS3、第三近邻距离和政策前支持诊断。

## 采纳门槛

必须同时满足：

- 保留至少252/315个处理候选，覆盖率至少80%；
- 每个保留处理商品恰好3个不同的同NAICS3对照；
- 单个对照最多复用10次；
- 四项最终绝对SMD全部小于0.10，优化内部限制为不超过0.09；
- 加权对照有效样本量至少100；
- 平均标准化距离不超过1.035915；
- 距离95分位数不超过2.749125。

## 解释边界

如果 v3 通过，后续估计对象已经不是“全部原始 List 1 商品的平均效果”，而是：

> 在政策前特征上具有足够对照支持、并进入最大平衡子样本的 List 1 商品效果。

申请材料和最终报告必须明确写出这一点，不能把重叠子样本结果外推到全部处理商品。

## 最终停止条件

如果最大可行处理数量少于252，或者最终有效样本量、复用、SMD、平均距离或95分位距离任一失败：

- 保存求解器和退出样本报告；
- 不设计第四种匹配；
- 不运行前趋势或事件研究；
- 将“当前数据无法识别可靠因果效应”作为案例结论；
- 转入已经设计好的证据约束 AI 应用层。

匹配路线在 v3 失败后结束，不再设计第四种匹配。AI 应用设计没有被删除，而是转入实现：它将把描述性结果、来源链和“当前不能做因果判断”的状态作为可验证的回答能力。
