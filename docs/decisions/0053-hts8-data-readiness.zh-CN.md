# Phase 12j：HTS8数据完整性修正与实验前置条件

本阶段在冻结新匹配之前复核0050要求的子码覆盖、历史有效性、缺失解释、商品家族数和金额覆盖。

## 修正与证据

旧Phase12i程序将没有观察到的金额写成0，依赖额外标记区分；其最终口头表述“没有直接当作零”过于笼统。新版月表将无中国记录的中国金额、无任何记录的全部原产地金额保存为空；有原始记录且金额为0的仍为0。资格汇总金额为已有记录合计，不可当作已补齐缺失的真实全期金额。

新版生成单独的`hts8_candidates_prepolicy_v2.csv`、`hts8_candidate_qualification_v2.csv`和`hts8_candidate_panel_report_v2.json`，旧文件保留。243个活跃度候选及其观察金额不变。

原程序还未实现0050要求的完整子码/按月有效性检查。现已直接读取官方历史有效区间，确认候选每个子码具有覆盖2016-01至2018-05的连续有效期；这也保证它在窗口内每月有效。遍历29月全HTS10表核对：属于这692个候选HTS8的观察子码均在冻结子码清单中，没有发现遗漏其他子码导致漏计金额。新增输入哈希，保留未出现子码数量。有效且没有出现仍不等于实际零进口。

金额覆盖分母是3332各自56个元数据候选，不是全部818项政策商品，也不是整个中国对美贸易。家族数只提示相关结构，不足以证明统计精度。两边行业代码相同也不足以证明具体用途可比。

62×29=1,798行中：1,755行观察正金额、41行观察零金额、2行无中国记录；2行存在未出现子码。尚不能把空值转为0计算趋势。下一步先依据原始包和官方字段说明确认无记录的含义，必要时将不能完整比较的商品列为明确的敏感性样本，而非暗中补零。

## 决定

采纳新版作为后续政策前分析输入。保留3332为优先研究范围；在缺失口径与具体经济用途审查完成前，不冻结最终匹配权重。旧HS6实验已经失败，不再按其条件重跑。

下一阶段Sol高：查清这2个无中国记录月份的来源与含义，同时审查38/24商品的具体用途，交付唯一的政策前可比性实验协议，包含基准、预期假设、家族权重、容差来源、时间检查和停止条件。若无法说明缺失口径或经济可比性，停止扩大这条分支。不得用政策后效果来挑商品。

本轮验证：新版真实数据缺失/零值分离、唯一键和新旧资格一致性测试通过；原始ZIP全部保留。没有新增API、下载、模型训练或因果估计。
