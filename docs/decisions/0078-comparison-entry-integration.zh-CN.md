# 0078：显式比较接入统一研究入口

日期：2026-09-11。承接0077。本轮把已锁定的比较契约接入“计划—预览—确认—取数—报告”链路，没有启动在线模型验收。

## 已完成

- 新版计划允许 `comparison` 对象。贸易计划可明确选择 `sequence`、`endpoint` 或 `registered`；旧计划仍可运行，但明确属于兼容模式，沿用旧的首末月描述性变化。
- 宿主在预览阶段核对比较方向、请求月份、粒度和登记窗口。登记窗口从本地统计摘要读取，不能由模型编造；请求月份与窗口不一致会被拒绝。
- 确认后仍先通过原有范围和来源校验，再读取贸易序列。`endpoint` 保留用户给出的基准方向；`sequence` 不再自动生成首末差额；`registered` 输出窗口合计并标为描述性比较。
- 政策与贸易组合、贸易单独入口都保存比较契约和计算结果，报告中展示比较方式。缺失金额不补零，基准为零时不计算百分比。
- 显式 CLI 增加 `--comparison-kind`，并对 `endpoint` 强制要求基准月/比较月、对 `registered` 强制要求登记ID；参数错误在读取数据前停止。

## 验证

全套 **419 项本地测试通过**，没有在线API、训练、微调、因果拟合或下载。新回归覆盖反向比较、逐月序列、登记窗口、实际贸易数据金额、缺失与零基准、计划版本2和报告输出。

一个真实离线例子：其他原产地整体，2018-10 相对 2018-09，基准 36,587,820,118 美元，当前 41,012,723,839 美元，差额 4,424,903,721 美元，变化率 12.09%。这只是观察到的描述性变化，不是关税因果效果。
