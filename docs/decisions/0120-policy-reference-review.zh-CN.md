# 0120：政策参考与对照回答的离线复审

日期：2026-09-13。模型建议：Astra中。无外部API调用、无训练、无新增模型成绩。0118契约继续有效，本轮只完成政策参考/对照解析这一工作单元，不代表整体验收通过。

## 反例与修复

先新增反例，旧实现出现12处子测试失败，再修复：

1. `case.facts`可以清空或换值，而仍携带有效参考文件。现预检必须与重新加载的冻结事实完全一致，在规划模型调用前拒绝。
2. 内存中的`source_catalog`可以替换原文。现比较整份来源目录与磁盘参考的摘要，而不只检查非空。
3. 来源出版日期晚于题目截止日仍通过。现拒绝这类未来证据。
4. B组非法JSON、缺少claims、空文本、过长/过多主张及顶层answer中的未审内容可能标为validated。现严格B组只允许claims对象数组，最多6条，非空文本最多1500字符；不得把不合法主张过滤掉后继续审查。运行器保存完整错误响应后停止，不请求事实审核，也不登记为有效对照。

另修正两个设计表述：题目仅询问生效日和税率，所以必答事实只有这两项，不额外要求818子目；818的官方出处仍保留供参考，不删除历史研究内容。参考文件的身份改成AI整理、待独立人工复核；非空reviewer字段或结构测试并不证明有真实人工复核。

适用范围：新严格路径（带policy_reference）。历史字符串claims fixture仍属于兼容测试，不得据此宣称严格验收已通过。主/B提示词及引用要求尚未完成严格配对等价性审查。程序核查不自动判定自然语言语义正确。

## 下一阶段必须处理的事项

验证：新增7项回归测试（包含错误B响应完整保留且审核回调未被调用的接线测试）；全套`PYTHONPATH=src .venv/bin/python -m unittest discover -s tests`共622项通过，32.948秒。测试中的GLM日志来自模拟调用，不是外部API成绩。未修改历史model_adapter或冻结实验结果。

以下是代码复审发现的风险，尚未全部写反例验证，更不能描述成已经修复：

- 登记窗口：范围比较使用baseline原请求（months=None），而工作流可能展开为月份列表；独立复算又从实际回答提取登记窗口，存在自我核对风险。应从调用前登记材料推导双方的预期月份，保留原始请求并禁止用输出修复标准答案。
- 审核绑定：最终批准需重算事实packet/submission的验证结果，不能仅信任保存的approved字段；实际报告字节和marker也须绑定，不只比较状态摘要。
- 来源与调用边界：主组检索证据可覆盖同ID冻结证据；实际HTTP捕获的来源真实性、消息内容敏感信息、完整gap审查材料及自定义依赖仍待核查。HTTP“自洽”不等于独立可信或全面脱敏。
- 完整场景：贸易/政策/组合/澄清四类整链共同通过，并保留失败与待审反例后，再审查真实调用资格。

下一阶段推荐Astra中，先复现登记窗口和最终绑定漏洞，再修复并验证；属于正确性判断，不宜直接交给机械批量执行。停止条件：涉及修改冻结历史结果、改变研究问题或放宽证据门槛时停止扩大修改。沿用现有开发fixture，不接触新在线题、不重刷已知模型成绩。正式acceptance_ready仍为false；因果识别仍阻断。
