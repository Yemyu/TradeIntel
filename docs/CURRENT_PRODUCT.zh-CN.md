# 功能与数据范围

[🌐 English](CURRENT_PRODUCT.md) · [项目介绍](../README.zh-CN.md) · [快速开始](LOCAL_RUN.zh-CN.md)

TradeIntel 通过对话查询贸易数据和政策资料，并将结果保存为图表报告。当前版本收录美国进出口数据，支持全部贸易伙伴汇总及中国伙伴查询。

## 查询与追问

可以按商品名称或编码提问，例如“最近美国大豆进口有什么变化？”。助手查找商品、检查可用月份并查询金额；接着问“出口呢？”时，会沿用商品上下文并切换方向。换成豆油等其他商品时，会重新检索对应分类。

回复中的报告卡片可查看月度图表、最新金额、可计算的跨月变化、完整数值表和来源。对话与报告保存在本地，可以重新打开；报告支持打印和保存为 PDF。

## 模型与程序的分工

模型识别问题中的商品、方向、伙伴和时间，调用商品、贸易和政策工具，读取返回结果，决定继续查询、询问具体范围或完成任务。

查询工具读取处理后的官方数据，核对范围并计算金额。程序生成报告摘要和图表，检查报告及引用后保存结果。当前报告以这些计算和检索结果为基础，不包含模型自由撰写的经济分析。不同模型的任务完成情况见[模型测试](MODEL_SELECTION.zh-CN.md)。

政策检索使用关键词、BM25 和编码匹配，查找本地已登记、启用的文档及相关条件。它不自动采集全网公告；具体商品是否适用政策仍需结合公告规定核对。

## 数据覆盖

| 内容 | 已收录范围 |
|---|---|
| 美国进口 | 2016-01—2018-05、2025-01—2026-07，共48个月；两段不连续 |
| 美国出口 | 2025-08—2026-07，连续12个月 |
| 商品 | 已发布的官方商品目录 |
| 贸易伙伴 | 全部来源／目的地汇总及中国 |
| 政策 | 本地登记并启用的文档 |

中国指美国统计中的贸易伙伴。当前数据源为美国人口普查局，不包含中国海关独立统计。

最新收录月为2026年7月。“最近”使用可用数据；指定未收录月份时，助手说明缺口，改查其他月份需要确认。缺失值保留为未知，不按零处理。

进口采用消费进口额，出口采用 FAS 口径的总出口额，分别展示。金额变化本身不能确定数量、价格变化或政策效果，也不能据此进行政策因果认定。

后续可扩展到中国及其他国家；新增数据源前，需要完成采集，并核对商品分类、时间范围与统计口径。

## 使用方式

- [公开展示页](https://yemyu.github.io/TradeIntel/?lang=zh)：阅读四个已保存案例和报告，可切换中英文。
- 本地应用：按[快速开始](LOCAL_RUN.zh-CN.md)下载数据包、启动服务，配置 GLM、DeepSeek 或 Qianwen API 后提问。
- 数据查询模式：手动确认商品和日期，生成同样的数据报告，无需模型密钥。

源码使用 `main` 分支。贸易数据包单独通过 [Release](https://github.com/Yemyu/TradeIntel/releases/tag/showcase-20261002)提供；覆盖和来源说明见[数据说明](../data/README.zh-CN.md)。
