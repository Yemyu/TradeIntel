# 当前功能与使用方法

[项目介绍](../README.zh-CN.md) · [本地安装](LOCAL_RUN.zh-CN.md) · [模型测试](MODEL_SELECTION.zh-CN.md)

TradeIntel 是本地运行的美国商品贸易研究助手。模型选择商品检索、贸易查询和政策检索工具，程序计算金额与变化，网页展示对话和图表报告。同一会话可以追问方向、换商品或调整时间。

## 从哪里开始

**先看案例**：展示页有大豆进出口、豆油进口、钨与光伏材料、缺少月份四个案例。不需要密钥；这些是已保存内容，不会发新请求。

**自己提问**：按本地安装说明启动服务，在模型设置中填自己的 API Key 后使用助手。没有密钥时选择数据查询模式，手动确认商品与日期。日常查询不要求连接 MySQL。

**读报告**：回复中的卡片打开图表、逐月金额和说明；返回聊天继续追问。查看已保存报告、切换语言或刷新不会自动再请求模型。报告可以打印或保存 PDF。

## 一个使用例子

先问“最近美国大豆进口有什么变化？”，再问“出口呢？”。助手保留商品上下文，分别查询两个方向；报告给出最新可用月金额、与前月的变化和所选期间的数据。换成“豆油进口呢？”时，需要重新检索豆油，而不是沿用大豆数据。

数字和主报告摘要由程序计算，不是模型自由填写。模型负责选取查询步骤和结果；可用性仍与模型配置有关，已有配置结果见模型测试页。

## 数据范围

| 内容 | 当前范围 |
|---|---|
| 美国进口 | 48个月：2016-01—2018-05、2025-01—2026-07；中间不连续 |
| 美国出口 | 2025-08—2026-07，连续12个月 |
| 商品 | 已发布的官方商品目录，不限于五种演示材料 |
| 伙伴 | 全部来源／目的地汇总及中国 |
| 政策 | 本地登记、启用的文档 |

中国指美国统计中的贸易伙伴，不是中国海关数据库。“最近”使用最新收录月；指定缺失月份则提示缺数据。进口消费金额与出口总额FAS口径分别展示，不相减当贸易差额。

金额变化可说明贸易规模的变化，不能直接确定原因、数量或价格变化，也不提供政策因果认定或投资指令。项目不是每日新闻服务。

## 安装与版本

普通Git克隆不含124个通用贸易数据文件，需要独立数据补充包，目前没有公开下载地址。安装说明中给出核验和启动步骤。当前推荐使用仓库源码；旧v4 ZIP仅是历史交付记录，不包含后续更新。

工具协议目前为v3，商品别名、双方向、政策证据合并和引用反馈已修复，并完成修复后测试。Sol Low与Medium两组正常任务9/9、边界3/3；Luna Max为7/9和2/3，DeepSeek Flash高推理为8/9和2/3（其中一题依赖跳过）。具体渠道、问题和旧v2成绩见模型测试页，不将对话桥接当成网页GPT API验证。界面有中英切换，本地安装在macOS验证，Windows尚未验证。
