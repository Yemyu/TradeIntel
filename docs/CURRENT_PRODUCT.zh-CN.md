## 使用

按[本地安装说明](LOCAL_RUN.zh-CN.md)启动服务。这台电脑使用 `http://127.0.0.1:8898/preview/`，避免与已占用的8765端口冲突；其他电脑默认使用8765，地址以启动输出为准。

- **仅查询数据**：不需要模型密钥。确认商品、方向和月份后生成数据报告。
- **研究助手（使用模型）**：在模型设置中配置服务地址、型号及密钥，再提问，例如“最近美国大豆进口有什么变化？”，随后在同一会话问“出口呢？”。模型调用可能收费；明确商品不应要求你每次手动挑选，真正有歧义时仍需确认。

数值和图表由程序计算；当前主流程的公开摘要也来自计算结果，不直接发布模型自由撰写的解释。旧流程里单独的“模型解读（试用）”不是这条 Agent 主流程，仍需审阅。

## 数据范围

| 内容 | 当前支持 |
|---|---|
| 美国进口 | 48 个已加工月：2016-01—2018-05、2025-01—2026-07；中间有缺口 |
| 美国出口 | 2025-08—2026-07，连续 12 个月 |
| 商品 | 官方商品目录，不限于早期钨和光伏材料案例；具体可查范围以目录和已发布数据为准 |
| 贸易伙伴 | 全部来源／目的地及中国；不是任意国家查询 |
| 政策 | 检索本地已登记、启用的政策文档；没有命中不等于不存在相关政策 |

“最近”使用最新已发布月；“上个月”按日历理解，缺该月就提示缺数据，不偷偷改查最近可用月。只能分析实际存在的连续月份。进口消费金额与出口总额（FAS）口径不同，分别展示，不相减冒充贸易差额。

本版本不是每日自动更新的新闻服务，不提供投资指令，也不认定政策造成了某项变化。MySQL 用于数据工程和核对；日常网页查询读取已核验文件，不要求连接 MySQL。
