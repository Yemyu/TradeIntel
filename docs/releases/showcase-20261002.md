# TradeIntel — showcase and local data

## English

This release provides the bilingual website, four saved cases, current model-test results, and the processed data needed to run the assistant locally.

- The website is a free, read-only case reader. To ask your own questions, run the Python service locally and configure your own model API key.
- Download `trade-demo-data-20260927-isolated-v2.zip` (about 64 MiB), check the attached SHA-256, and extract into a new directory. Do not overwrite an older data bundle.
- The manifest lists 124 processed data files: 48 import months (January 2016–May 2018 and January 2025–July 2026), 12 export months (August 2025–July 2026), and commodity indexes. Partner queries use all origins/destinations combined or China, with the United States as reporter.
- The ZIP also includes its manifest and a short Chinese guide. TradeShock in that guide is the project's old name. The archive is preserved byte-for-byte so its checksum remains valid.
- It does not include raw Census ZIPs, a policy-document database, MySQL data, source code or API credentials. Full installation was checked on macOS with Python 3.13.3. Session and report storage requires POSIX `fcntl`; native Windows is not supported.

Follow the [local guide](https://github.com/Yemyu/TradeIntel/blob/main/docs/LOCAL_RUN.md). Verify the bundle before starting; GitHub's automatic source archives do not include the large data files.
