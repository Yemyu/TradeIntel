# TradeShock AI：历史贸易政策研究助手

本项目将中文问题转为待确认的研究范围，查询美国官方贸易数据，并从2018年USTR政策公告中检索原文，生成带引用的中文草稿。金额和变化率由程序计算，模型负责理解需求和解释政策。

## 阅读成果

- [政策问答存档](policy-report.zh-CN.md)
- [政策与贸易组合报告存档](combined-report.zh-CN.md)

两份报告来自同一轮已完成的GLM-4.7开发演示，共6次真实调用、11,049个供应商报告tokens。AI辅助宿主审核核对了生效日期、额外25%关税、00:01时刻表述、原文引用及贸易金额。报告保持存档正文和“草稿”标签，审核说明没有回写模型答案。

组合报告展示：政策暴露范围内，不含中国的其他原产地2018年9月、10月美国消费进口额分别为36,587,820,118与41,012,723,839美元，增加4,424,903,721美元（12.09%）。该变化是描述性观察；目前没有可采纳的因果估计证明它由关税造成。

## AI实现与验证

应用集成结构化规划、执行前确认、BM25/词法政策检索、查询扩展、原文窗口、引用式生成和确定性数据工具。资料限定两份历史公告已索引的正文，不覆盖完整商品附件或现行政策。

之后另一组六个预先固定的开发验收场景使用7次GLM调用、14,640 tokens：业务请求2/3通过，缺参数及范围边界3/3通过。反向比较失败保留；随后程序增加有限句式的方向检查，并用离线反例验证。六题由助手设计和审核，样本不足以推出普遍准确率，离线修复也没有改写原模型成绩。

较早演示的无证据对照也回答对了重复的政策事实，因此没有证明检索提高准确率。尚未进行模型训练、微调或多智能体部署。当前定位为需要范围与引用复核的研究原型。
