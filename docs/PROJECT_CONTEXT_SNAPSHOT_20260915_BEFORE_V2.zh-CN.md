## 2. 不可默默改变的目标

**做一个由真实贸易数据支撑的贸易政策 AI 研究助手，不是新闻收集器，不是经济学因果论文，也不是保证预测未来的模型。**

目标用户：需要整理贸易政策简报的初级分析人员。核心任务：收到一份政策或提出贸易问题后，快速形成可以核查、供人审阅的研究初稿，并在后续政策或数据更新时跟踪变化。

必须贯通的业务流程：

1. 理解问题，缺少国家、商品或时间条件时明确追问，不私自替用户选范围。
2. 检索政策原文，提取商品范围、税率变化、生效时间、例外与出处。
3. 把政策商品范围映射到真实贸易数据；记录编码版本、未匹配项和覆盖限制。
4. 用确定性工具计算金额、同比、份额、市场依赖或来源集中度，分子分母及口径可回查。
5. AI 根据政策证据和计算结果形成报告，分开写事实、可能机制、情景假设和未知。
6. 数据或政策更新后，说明相较上次究竟改了什么，不机械重复摘要。

简报是输出形式；政策与数据的可靠连接、工具执行和证据解释才是核心能力。数据库不是展示 SQL 的摆设，AI 也不是给固定表格添加一段套话。

## 3. 已取消与必须保留的边界

- **取消自研因果识别作为产品功能、开发主线和完成门槛。** 不再搜索新对照组合、重跑匹配或为了成功结论更换研究问题。要重启必须由用户明确改变决定。
- 旧因果代码、数据、报告只保留作历史研究记录。路径名含 causal 不等于数据作废；已有贸易面板可能仍被描述性计算依赖，不可直接删除或改名。
- 可以检索、解释适用的外部历史研究，但不强制每份简报讲历史，不自动照搬历史效应。不是新建历史因果评估产品。
- 贸易暴露金额不是损失额；来源国份额上升不是政策造成的收益；存在供应不等于具备替代产能。
- 情景是明确假设下的分析，不是经过验证的走势预测。没有依据，不编造变化百分比。
- 不承诺全球覆盖、报关合规裁决、实时月度统计或自主采购决策。
- 不为堆技术增加微调、多智能体、向量库、dbt 或 Airflow。只有明确需求和验收收益才引入。

## 4. 数据与历史案例的角色

2016—2019 年数据及 2018 List 1 是已有历史原型，不是最终产品的永久边界，也不是训练 GLM 的训练集。

旧数据可验证代码和历史案例流程，不能用来声称今天的贸易结构。模拟历史发布当日判断时，仅用当时可获得的政策和数据，后续结果不能泄漏进当时的报告。

新政策报告必须使用覆盖对应商品与国家的最新可得数据，分别标注统计期、发布日期（可得时）、抓取时间和报告截止日。尚未发布的统计不能假装已有；历史回放缺少发布版本证据时不得称严格实时回测。
