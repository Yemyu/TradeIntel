项目功能

能做什么

商品查询

查询商品的美国进口或出口金额，查看可用月份、最新数值和逐月图表。名称不明确时，助手会先确认商品范围。

连续追问

问完大豆进口，可以继续问“出口呢？”。也可以换商品、改查中国伙伴或调整月份，不必每次重新交代整个问题。

政策资料

检索本地政策资料，查看相关原文、出处与适用条件。判断具体货物是否适用，需结合完整公告核对。

AGENT

如何工作

模型把问题转为查询步骤，并读取工具返回的结果；Python 核对范围、计算金额并保存报告。

  1. 01模型

    理解问题

    识别商品、方向、伙伴和时间；接着前一轮问题处理追问。

  2. 02模型与工具

    查找并查询

    查阅官方商品目录和可用月份，读取所选范围的数据。

  3. 03模型

    根据结果继续

    读取结果，决定是否补查其他方向或政策资料；澄清歧义后，提交本轮报告与引用。

  4. 04程序与网页

    保存并展示

    查看摘要、月度图表、详细数值和出处；继续追问时，仍可查阅已保存的报告。

需要更多资料时，第3步会回到第2步继续查询。报告摘要与图表按已核对的数据生成；缺失月份保留为缺口，改查其他月份需确认。

数据底座

数据来源与范围

贸易数据来自美国人口普查局逐月商品明细，商品名称与编码来自官方目录。项目将原始文件整理为按月查询的数据表，并保留来源、版本和文件校验信息。

  1. 官方原始文件

    逐月贸易明细及商品目录。

  2. 整理数据

    按商品、方向、月份与伙伴整理金额。

  3. 核对与登记

    检查金额、范围、文件摘要，登记可用版本。

  4. 查询用数据

    本地服务读取已登记的处理结果。

网页查询读取整理后的 CSV 文件；MySQL 镜像与核对脚本用于数据准备和复核。

当前版本先使用美国进出口数据。后续考虑加入中国及其他国家的数据，需要先完成数据采集，并核对商品分类和统计口径。
