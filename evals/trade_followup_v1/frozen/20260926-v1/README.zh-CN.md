# 贸易报告追问：四题评测包

这套材料用来回答一个具体问题：在已有贸易报告上追问，模型是否真的让答案更清楚，而不只是把图表换一种说法。

## 题目与边界

四道题使用同一段已发布数据（2025 年 8 月至 2026 年 7 月），先用自然语言提问，再对同一份报告追问：

| 编号 | 商品与方向 | 追问重点 |
| --- | --- | --- |
| F1 | 咖啡进口 | 一次月度回落能不能说成最近持续下降 |
| F2 | 玉米出口 | 2026 年 1—7 月哪次相邻月变化最大，七月回落排第几 |
| F3 | 电脑进出口 | 两方向金额都增加能不能说明贸易差额改善 |
| F4 | 稻米进口 | 金额上涨能不能判断数量或单价上涨 |

题目不让用户先提供商品编码或数据截止月。商品由官方商品目录确认，题包保存实际确认范围和报告。每题的程序参考答案、逐月金额及来源放在 `references/` 和 `host_artifacts/`，不属于模型请求；实际请求单独放在 `requests/`。

## 怎样判

先只看报告回答追问，再看隐藏模型名称的“报告＋模型回答”，对照参考核对。逐题记接口是否返回、格式和引用是否合格、范围和事实是否正确、有没有严重错误，以及帮助是“更清楚／差不多／更差”。严重错误包括错商品或方向、把一个月变化说成全期趋势、编造数量价格或原因，以及把不同统计口径的进出口金额直接相减。

过线条件：四题范围都正确、没有严重错误，且独立审阅者至少三题认为模型回答带来具体帮助。某配置发生严重错误后停止该配置剩余题目。最多每配置四次，不自动重试；接口失败单列，不给内容分。结果只描述这四题，不称为模型的普遍准确率。
