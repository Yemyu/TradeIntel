# 商品报告 v4：四题开发价值验证

本目录只保存当前 `trade-data-explanation-v4` 的**离线评测输入**。目标是检验：模型解释是否比页面已有的月度数据、图表、程序说明和关系卡更容易让人读懂，同时不增加错误。四题参与过开发选题，**不是盲测，也没有模型成绩**。

- 题目和已确认商品范围：[scenarios.json](scenarios.json)。普通问法可能匹配多个商品，冻结时显式选择其中的代码，不能把所选细分商品说成整个大类。
- 已冻结的 v1 输入：[frozen/20260928-v1/](frozen/20260928-v1/)。每题 `record.json` 是新建的 v4 记录；`page_state.json` 和 `baseline.zh-CN.txt` 是页面原有事实的对照；**只有** `messages.json` 可以发给模型。`reference.json`、评分表和其他题材料不得进入请求。
- 文件最后写入 `MANIFEST.json`，其中保存逐文件摘要、代码与数据清单摘要。没有清单、摘要不符、问题或商品范围变化，都不能继续使用该包。旧 v3/F1—F4 题包与原答不改。

在项目虚拟环境中只做离线校验：

```bash
PYTHONPATH=src:. .venv/bin/python scripts/freeze_trade_model_v4.py \
  --output evals/trade_model_v4/frozen/20260928-v1 --verify
```

该校验要求当前相关代码和数据清单仍与冻结时一致；如果之后修改了它们，应保留旧包并另建新版本，不覆盖 `20260928-v1`。本脚本不会调用模型。真实调用前还要另行确认服务商返回的型号、推理设置、费用上限和最多四题的停止规则；原答与人工审阅存入独立运行目录，不能写回冻结包。
