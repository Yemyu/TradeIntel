7 · 数仓分层（数据工程核心）

贸易数据的真实痛点：同一个商品在不同年份、不同国家，HS 编码会变（HS2012/2017/2022 三个版本），国家代码、币种、统计口径都不统一。把"乱数据"整理成"干净能分析的表"，就是数据工程。

层作用说明
ODS 原始层源数据原样存一个字不改
DWD 明细层清洗 + 统一★ HS 编码对齐 = 实体对齐真功夫，统一国家代码 / 币种 / 去重
DWS 汇总层预聚合按 国家×品类×月份 预先算好，查询快
ADS 应用层成品指标同比 / 占比 / 贸易转移指标，给 Agent 和看板
为什么 DWD 的 HS 对齐是亮点："实体对齐 / 数据一致性"是数据开发岗最核心、最通用的功夫。把不同来源、不同版本的同一商品对齐到一起，招聘方一眼就知道你懂真数据工程。

8 · AI Agent（AI 工程核心）

Agent 不是只会聊天的机器人，而是会自己调工具、分多步干活的程序。它有一组工具（每个工具就是一个 Python 函数）：

查数仓 算指标 异常检测 画图 写报告

多步推理示例

你问："2025 年中美关税调整对半导体贸易流向有什么影响？哪些国家受益？"

  • ① 查数仓 → 拿中美半导体品类近 3 年月度贸易额
  • ② 算指标 → 算同比、找突变点
  • ③ 异常检测 → 定位关税调整后哪个月开始断崖
  • ④ 再查 → 看其它国家同期对美半导体出口是否上升（贸易转移）
  • ⑤ 画图 + 写报告 → 给你一份带图的分析
当前已完成可审计的证据工具、模型工具循环和 GLM 适配；模型不能任意执行 SQL，也不能把描述性变化冒充因果结论。定时简报与交互界面属于后续扩展。
